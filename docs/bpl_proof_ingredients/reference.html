    §2.1 Input and output

    Definition

    D-INPUT Explicit binary branching programs

    An input of length \(n\) explicitly lists the layers, vertices, start vertex, accepting terminal vertices, and two labelled next-vertex indices for every nonterminal vertex of a binary read-once branching program. Each step consumes one fresh fair bit and goes to the next layer. Repeated destinations retain their edge labels. Vertices and edges are listed, not specified by a succinct circuit; in particular the number of layers is at most the description length. The zero-layer case is allowed. A malformed description receives output zero and halts. General rational transition probabilities are outside this root interface.

    Manuscript: §2, p. 5.

    Definition

    D-TARGET The estimator output and counted memory

    The proposed deterministic transducer has an endmarked read-only input and a write-only output. It outputs an integer \(a\in\{0,\ldots,512\}\) denoting \(a/512\), with

    \[\left|\frac a{512}-\Pr[\text{the given ROBP accepts}]\right|\le\frac1{16}.\]

    It must halt on every input in \(O(\log(n+2))\) ordinary work bits. All head positions, seeds, counters, address words, scratch, catalyst bits, arithmetic states and retained recursion records count. No separate time bound is asserted. This is a constant-error probability estimator, sufficient to distinguish the usual \(1/3\) and \(2/3\) gap. No variable accuracy parameter is silently free.

    Manuscript: §2, p. 5.

    Definition

    D-RELAXED-TARGET The same estimator with additional workspace

    The relaxed target has exactly the input, output, error, invalid-input and halting requirements of D-INPUT and D-TARGET. Its workspace bound is \(O(B\log(B+2))\), where \(B=\Theta(\log(n+2))\). This is \(O(\log n\log\log n)\) for large \(n\); the displayed form also covers bounded input lengths. Every bit counted in D-TARGET is still counted.

    Manuscript: §2, p. 5.

    §B Seed, graph, and stage definitions

    The base graph and copied names set the domain for the exact hierarchy. The remaining definitions specify the sampling law and the walk used in the averages.

    Definition

    D-NAMES The base graph and copied vertex names

    The paired graph of P-BASE has \(n_0=O(n+1)\) vertices, transition matrix \(S\), and terminal reward vector \(e\). It is forward, substochastic, and has incoming and outgoing degree at most two. Its exact continuation vector is \(p=(I-S)^{-1}e\in[0,1]^{V_0}\). A stage-\(l\) name is a base name followed by \(l\) copy labels in \(\{0,\ldots,d_0-1\}\); \(V_l\) denotes this set and \(f_l=16^{-l}\). Names of different lengths are encoded injectively with a length delimiter. Appending a fixed suffix is an affine map on its legal name interval. The field is chosen larger than all names; a suffix is never selected from the seed.

    Manuscript: §B, p. 51.

    Definition

    D-RANGES Fixed root parameters and precision ranges

    Choose

    \[L=\min\{j\ge0:8^j\ge48n_0\},\quad N=n_0d_0^L, \quad 2^{3r}\ge8N48^3,\]

    with the least integer \(r\ge1\). Let \(B\) be a padded power of two of order \(\log(n+2)\), and take statistical budget \(M=c(B+L+r)\). Constants, including \(c,d_0\) and the field exponent, are fixed program constants whose simultaneous effective selection is E-CONSTANTS; that assignment remains open. The requested root digit places are just \(0,\ldots,9\), but internal requests may have place \(O(B)\) and must be charged.

    Manuscript: §B, p. 51.

    Definition

    D-DIGITS Signed-digit streams and root truncation

    A normalized signed-digit stream has digits in \(\{-6,\ldots,6\}\) and value \(\sum_{j\ge0}a_j2^{-j}\). Truncation after place 9 incurs at most \(6\sum_{j=10}^\infty2^{-j}=3/256\). Clipping to \([0,1]\) cannot increase this error.

    Manuscript: §B, p. 51.

    Definition

    D-ROOTLAW The single event used by deterministic enumeration

    Let \(A_\sigma(v)\in[0,1]\) denote the reward returned by the selected logical estimator at stage \(L\), and let \(w_L(v)\) be its exact hierarchy target. The primary start is \(z_L\). The root event is

    \[H_0=\{X_{f_L}^0(z_L)=1\}.\]

    The required moment premise, for the same seed law, is

    \[\frac1N\mathbb E_\sigma\sum_{v\in V_L}\frac{X_{f_L}^0(v)}{f_L} |A_\sigma(v)-w_L(v)|^3\le2^{-3r}.\]

    Channels 1 and 2 are not conditioned at the root. An algorithm that filters either extra hit requires a different accuracy theorem.

    Manuscript: §B, p. 51.

    Definition

    D-EXPANDER The conditional seed-action interface

    The abstract input is a finite seed set with an explicitly specified conditional uniform measure. A condition names at most one fixed endpoint per channel and may fix a prescribed subset of auxiliary bits. The interface supplies a fixed constant number of symmetric generator slots, at least half lazy, a transition and inverse algorithm, a positive spectral gap independent of all size parameters, and a word description of \(O(h)\) bits for length \(h\). It must also supply an endpoint-independent bijective word expansion with exactly one valid variant per conditioned seed. This last requirement is separate from expansion. An arbitrary expander on an unconditioned space does not satisfy this interface.

    Manuscript: §B, p. 51.

    Definition

    D-SEEDS The common probability space

    A channel seed is \((a_0,a_1)\in\mathbb F_p^4\times(\mathbb F_p^4\setminus\{0\})\), uniform on this finite set. The three channels are independent. For \(a=16^{-j}\), set \(L_a=\lceil p2^{-j}\rceil\) and

    \[X_a^c(v)=\mathbf1\{a_0^c+v a_1^c\bmod p\in[0,L_a)^4\},\qquad \pi_a=(L_a/p)^4.\]

    An environment may also contain an independent uniform bit string of a fixed public length. In the exact configuration this length is zero. A task's probability space, including this choice, is fixed independently of its numerical precision and statistical budget. All expectations below refer to that space unless a conditioning event is displayed.

    Manuscript: §B, p. 52.

    Definition

    D-ACTION The concrete conditional action spaces

    At a specified hit endpoint, changing coordinates to \((a_1,w)\) identifies a conditioned channel with

    \[(\mathbb F_p^4\setminus\{0\})\times(\mathbb Z/L_a\mathbb Z)^4.\]

    The same integer elementary matrix acts on both factors and translations act on the second. An unrestricted channel uses endpoint zero and \(L=p\). For the free auxiliary bits, split their number into four \(\ell_{\rm aux}\)-bit integers and at most three residual bits. Use the affine action on \((\mathbb Z/2^{\ell_{\rm aux}}\mathbb Z)^4\) and lazy flips on the residual bits; fixed bits do not move. The number of factors stays bounded. P-SEEDSTEP is the concrete candidate; A-ACTION derives its uniform gap from the two Shalom inputs and the finite-action argument. A-MIX applies the explicitly imported finite interpolation contract. A-ACTION proves the finite-action specialization under the two external contracts. Identifying the same law at each estimator caller remains a separate analytical obligation.

    Manuscript: §B, p. 52.

    Definition

    D-WRAPS Endpoint-independent word variants

    For a channel letter \((A,c)\), P-WORD enumerates the bounded wrap choices \(z\) and uses the full-seed map \((a_1,a_0)\mapsto(Aa_1,Aa_0+c+Lz)\bmod p\). Its validity test is \(0\le Aw+c+Lz<L\) in integer representatives. Exactly one variant passes. All variants retain the original word weight; there is no extra wrap normalization. Failed variants contribute zero. A fixed variant is a full-seed permutation, but an adaptively selected valid variant need not preserve an unconditional distribution. All probability arguments must retain the declared condition and its measure.

    Manuscript: §B, p. 52.

    Definition

    D-SLOTS A concrete constant-size generator alphabet

    Use 512 equally weighted slots, indexed by a factor in \(\{0,\ldots,7\}\) and a local slot in \(\{0,\ldots,63\}\). Factors 0,1,2 are the three channel spaces; factor 3 is the four-integer free-bit space; factors 4,5,6 are the possible residual bits; factor 7 is identity. Absent factors are identity. In factors 0–3, slots 0–31 are identity, 32–55 are \(I\pm E_{ij}\) for \(i\ne j\) in lexicographic order, positive before negative, and 56–63 are translations \(\pm e_i\) in coordinate order, positive before negative. A translation leaves a channel slope unchanged. In each residual-bit factor, slots 0–31 are identity and slots 32–63 flip the bit. This fixes a symmetric alphabet with at least half its slots lazy. If there are \(4\ell_{\rm aux}+r\) free bits, \(0\le r<4\), factor 3 reads the first four consecutive \(\ell_{\rm aux}\)-bit blocks as integers modulo \(2^{\ell_{\rm aux}}\); factors 4 onward use the remaining bits. The public fixed-coordinate mask chooses these positions. A fixed generator acts on no frozen bit.

    Channel wraps have coordinates in \(\{-1,0,1\}\), zero in unchanged coordinates. The one valid wrap per channel letter is tested in integer representatives. Auxiliary factors use their directly invertible modular action and need no channel wrap guess. A length-\(h\) word has weight \(512^{-h}\), with no division by a wrap count. A-ACTION proves the uniform gap for this explicit specialization. It is a theorem about this conditional product action, not about arbitrary conditioned subgraphs.

    Manuscript: §B, p. 52.

    §C Row, task, and arrival definitions

    These definitions describe the finite data passed between the logical algorithms. They also give the fields that physical replay must recover.

    Definition

    D-POLICY Endpoint matching and the row that it defines

    A comparison policy \(\eta\) fixes an equivalence relation on endpoint names for each complete task and increment group, independently of requested digits. Exact mode uses equality of the injective names. Let \(O\) be the ordered old representatives, \(J\) the valid new arrivals and \((z,0)\) the old default. For an equivalence class \(C\), put

    \[v_C=\sum_{j\in J:\,\operatorname{endpoint}(j)\in C}\operatorname{increment}(j).\]

    L-GROUP keeps every \(o\in O\) separately with value \(O(o)+v_{[o]}\). A class containing no old representative creates its first valid arrival with value \((z,0)+v_C\). All other names retain the default. Compression and later gates use this precise row. No claim about its accuracy is part of this definition.

    Manuscript: §C, p. 53.

    Definition

    D-ORDER Padded ranks, holes and logical enumeration

    A rank is the \(k\)th largest value. Numerical row ranks are padded by the specified number of default values; incoming ranks are padded by zeros. A hole is an absent port, not a default-valued present port. Strict structural tests reject equality. The representation may retain a coordinate equal to the default. Logical array multiplication and padded rank computation are explicit calls to L-MATMUL and L-RANK. Finite expectations enumerate their stated seed sublist and divide its scalar sum by its count. Physical ranks and averages use the separately named request and sample procedures. No caller executes a mathematical definition as though it were a subroutine.

    Manuscript: §C, p. 53.

    Definition

    D-CUTOFFS Smooth cutoffs and fixed hierarchy constants

    For \(A<B\), define

    \[\chi(t)=\begin{cases}0&t\le0,\\10t^3-15t^4+6t^5&0<t<1,\\1&t\ge1,\end{cases} \qquad \chi_{A,B}(v)=\chi((v-A)/(B-A)).\]

    The hierarchy uses fixed rational thresholds \(0<\delta_0<\delta_1<\theta_1/100\) and \(0<\theta_1<\theta_2<1/512\), a fixed round count \(K\), and

    \[Q(v)=(v-\theta_1)_+\chi_{\theta_1,\theta_2}(v),\quad \phi(v)=\chi_{\delta_0,\delta_1}(v),\quad \gamma(v)=1-\chi_{1/2,4/5}(v).\]

    Let \(b_Q=K+2\), \(k_f=16^{\kappa_f}\ge2(K+1)\), and choose a positive fixed \(\zeta\le\min(1,\theta_1/2,\delta_0/2,1/4)\) satisfying the later compression inequalities. These symbols are constants, not additional procedures.

    Manuscript: §C, p. 53.

    Definition

    D-RAW Raw coordinates and their local gates

    A completed raw row is a pair \((v_{xy},v^2_{xy})\) with default \((z_x,0)\). The superscript 2 labels a coordinate; it is not a square. Let \(s_x\) be its \(k_{\rm row}\)th first-coordinate rank, with default padding. For the owner's threshold \(\theta\) set

    \[\begin{aligned}h_\theta(v)&=\chi_{\theta/2,3\theta/4}(v),& R_\theta(s)&=1-\chi_{\theta/1000,\theta/500}(s),\\ I_\theta(v,s)&=\chi_{\theta/8,\theta/4}(v) (1-\chi_{\theta/100,\theta/50}(s)),\\ J_\theta(v,s)&=\chi_{41\theta/500,9\theta/100}(v) (1-\chi_{13\theta/500,27\theta/1000}(s)).\end{aligned}\]

    The auxiliary \(J\) is a smooth witness for analysis, not a new runtime call. Corrections use \(\theta_1\), bins use \(1/2\), and scores use \(\delta_0\). The cubic cutoff convention follows Run 3/Run 7. The distinction between cubic and eighth-moment analyses is discussed in the full-space additions.

    Manuscript: §C, p. 53.

    Definition

    D-BINS Bin factors and routed residual factors

    For \(b=16^{-j}\) the bin factor is

    \[k_b(v)=\begin{cases} v_c\chi_{1/2,1}(v_c),\ v_c=\operatorname{clip}_{[0,1]}v,&j=0,\\ v\chi_{1/2,1}(v)(1-\chi_{1/2,1}(v/16)),&j>0. \end{cases}\]

    Correction mains use \(k_O(v)=Q(\operatorname{clip}_{[0,b_Q]}v)\). Transition and unrouted residual mains use \(k_a(v)\). A residual with route \(\beta\) multiplies by \(s_\beta((a/f_l)v)\) when \(a<1\); when \(a=1\) its routing argument is \(v_c/f_l\), using the clipped \(v_c\). The functions \(s_\beta\) are defined in L-SPLIT.

    Manuscript: §C, p. 54.

    Definition

    D-LOCAL Preparation, main and score formulas

    Local preparation is \(h_\theta(v)R_\theta(s)\); local main is \(Y_\tau k_O(v)R_\theta(s)/\operatorname{clip}_{[1/2,1]}(v^2/\zeta)\); score is \(\phi(v)R_{\delta_0}(s)\). Corrections multiply by their own incoming gate \(1-\chi_{1/4,1/2}(\operatorname{rank}_{k_c} I)\), and mains also by their specified detector multiplier. Bins and scores omit incoming gates. Fixed structural classes cover these supports on every seed, including inaccurate ones. An overfull correction column is deleted as a whole.

    Manuscript: §C, p. 54.

    Definition

    D-CERTIFICATE Canonical finite certificates and structural tests

    Let \(\widetilde v_t=2^{-t}N_t\) be the deterministic certificate produced by the fixed numerical request rules, with \(|N_t-2^tv|<2\). Ties, guards and residue order are fixed once. Logical reference algorithms may generate these finite certificates with unrestricted arithmetic; physical algorithms must implement the same rules. A structural test requests its prescribed place once for that kind, independent of later output precision. This replaces any ambiguous instruction to decide an exact real sign. The finite selector in P-SELECT and the class tests in P-CLASS define the representation used here. Agreement with source floor-prefix conventions is a proposed representation comparison, not an identity assumed without proof. Every comparison policy uses these same tests.

    Manuscript: §C, p. 54.

    Definition

    D-TASKS Finite task records, rates and analytic ranks

    A row task contains an owner, stage \(l\), round/route when applicable, a permutation \((\mathsf S,\mathsf T,\mathsf M)\) of channel roles, rates \((u;a,\tau)\), source and destination suffixes \((s,t)\), a budget, and its effective seed. The current source and destination vertices are arguments, not hidden fields of the semantic tuple. Legal suffixes satisfy \(l+|s|,l+|t|\le L\). A preparation always has \(\tau=a\); a main has \(\tau\le a\).

    OwnerAllowed rates and extra data
    Transition bin\(u\le f_l\), \(a\le f_l\); preparation or main.
    Pilot correction\(u\le f_l\), \(a=f_l\), round \(1\le i\le K\); preparation or main.
    Actual correctionSame rate domain and round range.
    Residual bin\(u\le f_l\), \(a\le\min(1,k_ff_l)\); route \(\perp\) or a copy label.
    Pilot score\(u=a=\tau=f_l\), round \(1\le i\le K\).
    Reward vector \(W_l\)One source channel/suffix, rate \(u\le f_l\).
    Detector vector \(U_{l,i}\)One source channel/suffix, intrinsic rate \(u=f_l\).

    Every row vanishes outside its source hit and broad destination hit; vectors vanish outside their source hit. Put

    \[k_{\max}=L+\left\lceil M/(2k_{\rm prec})+M/(4c_0)\right\rceil+2, \qquad\mathcal R=\{16^{-j}:0\le j\le k_{\max}\}.\]

    All rates lie in this finite grid and \(p>2^{k_{\max}}\). For \(a=16^{-k_a}\) and \(u=16^{-k_u}\), activity requires positive budget \(m\) and

    \[p_{\rm acc}=m/k_{\rm prec}-2k_a-2k_u-a_*i_*>0.\]

    For a vector use broad rate \(a=f_l\). Inactive tasks return zero, default zero, and empty access, making no child calls. With \(L_*=6K+6\), the analytic ranks \(i_*\) are \(L_*l\) plus these offsets:

    \(W_l\)1Transition prep/main2,3
    Score \(i\)\(4i\)\(U_{l,i}\)\(4i+1\)
    Pilot prep/main \(i\)\(4i+2,4i+3\)Actual prep/main \(i\)\(4K+2i+2,4K+2i+3\)

    Local functions of a completed raw row keep its owner's rank. This rank organizes analytic accuracy; it is not by itself a physical stack bound.

    Manuscript: §C, p. 54.

    Definition

    D-WEIGHTS Common child budgets and scale weights

    Write \(\tau_b=\min(a,b)\) and \(w_b=(b/a)\pi_a/\pi_{\tau_b}\). For one lower family budget \(r\), all factors share the same transformed seed. The complete child maps below replace a broad informal “recursive sample.” Only the named lower evaluator is a logical call; evaluating the scalar formula on its results is ordinary exact arithmetic in the logical algorithm.

    Manuscript: §C, p. 55.

    Definition

    D-ROWFAMILIES Row families and their complete child maps

    Brackets below give roles, source rate, usage rate, source suffix and destination suffix; a bin name supplies its broad rate. Write \(H\) for the indicated pilot or actual correction. The lower child budget is \(r\) in every displayed factor.

    \[\begin{aligned}T^{\rm dir}_{b,r}(x,y)&=w_b B^C_{l,b,r} [\mathsf S,\mathsf T,\mathsf M;u,\tau_b;s,t](x,y),\\ T^{\rm prod,H,j}_{b,r}(x,y)&=w_b\frac{f_l}{\pi_{f_l}} \sum_zX_{f_l}^{\mathsf M}(z) H_{l,j,r}[\mathsf S,\mathsf M,\mathsf T;u,f_l;s,\emptyset](x,z)\\ &\hspace{17mm}\cdot B^C_{l,b,r} [\mathsf M,\mathsf T,\mathsf S;f_l,\tau_b;\emptyset,t](z,y),\\ T^{\rm sub}_r(x,y)&=-w_{f_l}F_{l,K,r} [\mathsf S,\mathsf T,\mathsf M;u,\min(a,f_l);s,t](x,y).\end{aligned}\]

    In the product the right tuple contains no old source, old rate \(u\), old source suffix, or left port. It is one common right function at each midpoint. The left correction has broad and usage rates both \(f_l\). For \(l>0\), \(x=x_0\alpha\), \(y=y_0\beta\), set

    \[\bar r_{0,r}=1,\quad \bar r_{\alpha,r}=\chi_{1/4,1/2} (\max_{h\le K}U_{l-1,h,r}[\mathsf S,\alpha s](x_0))\ (\alpha>0),\]
    \[T^{\rm copy}_{b,r}(x_0\alpha,y_0\beta) =w_b\bar r_{\alpha,r}B^{D,\beta}_{l-1,b,r} [\mathsf S,\mathsf T,\mathsf M;u,\tau_b;\alpha s,\beta t](x_0,y_0).\]

    The detector has its intrinsic source rate \(f_{l-1}\) and no destination data. Define \(\mathcal B_l^C=\{16^{-j}:l\le j\le k_{\max}\}\) and \(\mathcal B_l^D=\{16^{-j}:\max(0,l-\kappa_f)\le j\le k_{\max}\}\).

    OwnerExact base at \(l=0\)First-coordinate families
    Transition\(S_{xy}/a\)At \(l>0\): copy for \(b\in\mathcal B_{l-1}^D\).
    Pilot prep/main or score \(i\)\(S_{xy}\)At \(l>0\): direct over \(\mathcal B_l^C\). At \(i>1\): product with pilot round \(i-1\) over the same scales.
    Actual prep/main \(i\)\(S_{xy}\)At \(l>0\): direct. At \(i>1\): product with actual round \(i-1\), both over \(\mathcal B_l^C\).

Preparations have no second-coordinate family. Every main has its own preparation signal \(\zeta P_r\) with usage changed to \(a\), conditioned at the original narrow destination rate \(\tau\), and multiplied by that original hit. There is no further importance factor in this signal.

    Definition

    D-GROUPS Increment groups and their conditional averages

    For a scale family the cost is \(c_b=c_0(1+|\log_2(b/a)|)\); a fixed family costs \(c_0\). Put \(D=2^{\lfloor\log_2m\rfloor}\). At groups \(d=D,D/2,\ldots,1\), each first-coordinate increment is its base (only at \(D\)) plus the finite sum

    \[\sum_{\rm families}\sum_{\substack{r\ge1,\ d\le m-r<2d\\c_b\le m-r}} \mathcal K_{H_{\rm broad}}^{\ell_{\rm mix}(m-r)}(T_{b,r}-T_{b,r-1}).\]

    Set every family at nonpositive budget to zero. \(H_{\rm broad}\) specifies the source and broad destination hits. The second coordinate uses the identical formula with the owner's preparation signal, cost \(c_0\), and narrow condition \(H_{\rm narrow}\), followed by the original narrow hit. Both signs use the same word and wrap tests. The aggregate formula expands into the signed records returned by L-AVERAGE. Each new row record retains its full code. The caller collects the families and the applicable Base records in that code order before choosing representatives. New terms are grouped by L-GROUP; every completed group is compressed by L-COMPRESS. Future increments do not read the current buffer. This condition is needed for the reverse removal of clamps.

    Manuscript: §C, p. 56.

    Definition

    D-VECTORS Detector and reward vector families

    For a detector vector \(U_{l,i,m}[c,s](y)\), its one family is the zero-padded \(j_{\rm det}\)th rank of

    \[\{\mathrm{Score}_{l,i,r}[c+1,c,c+2;f_l,f_l;\emptyset,s](x,y): X_{f_l}^{c+1}(x)=1\}.\]

    The rank is formed first, then averaged under the sole source hit at \(y\). For a reward \(W_{l,m}[c,u,s](x_0\alpha)\) with \(l>0\) and \(f=f_{l-1}\), its one family is

    \[\begin{aligned}\bar r_{\alpha,r}\bigg[W_{l-1,r}[c,u,\alpha s](x_0) +\frac f{\pi_f}\sum_zX_f^{c+1}(z)&F_{l-1,K,r} [c,c+1,c+2;u,f;\alpha s,\emptyset](x_0,z)\\ &\cdot W_{l-1,r}[c+1,f,\emptyset](z)\bigg].\end{aligned}\]

    At active stage zero the reward is \(e\) exactly. Vectors add scalar groups, clamp to \([-R_d,R_d]\) after each, and finally clip to \([0,1]\); they have no ports.

    Manuscript: §C, p. 56.

    Definition

    D-FINAL Final gates, multipliers and the root task

    Final correction assembly uses the incoming rank of \(I\) from its own raw row. A pilot main of round \(i\) uses \(\gamma(\max_{h\le i}U_{l,h,m-c_{\rm col}}[\mathsf T,t])\); an actual main uses \(h\le K\). These vectors have intrinsic rate \(f_l\) and no old-source data. Final bins use multiplier and incoming gate one. Scores omit signal, normalizer, cap and multiplier. The physical root uses the reward tuple \((W_L,c=0,u=f_L,s=\emptyset,m=M)\).

    Manuscript: §C, p. 57.

    Definition

    D-PRODUCT Domains and pointwise bounds for a shared-seed product

    Fix legal rates \(u\le f\) and \(b\le f\), integers \(k,k_c\ge1\), and the source, midpoint and destination channels. Use one finite name universe, extending tables by zero where necessary, with the same normalization \(N\) in every factor norm. On one common seed let \(\bar F,F^*\) be nonnegative correction tables at rates \((u,f)\) and \(\bar B,B^*\) bin tables at \((f,b)\), all bounded by the fixed final scale \(H_*\ge1\). Each left and right row has at most \(k\) nonzero entries; the ideal left relation has incoming degree at most \(k_c\) on every seed. Every right table is a function of \((z,y,\sigma)\) independent of the old source \(x\). Masks are the displayed source/midpoint/destination hits. Put

    \[V_{xy}=\frac f{\pi_f}\sum_z Z_f(z)\bar F_{xz}\bar B_{zy},\qquad V^*_{xy}=\frac f{\pi_f}\sum_z Z_f(z)F^*_{xz}B^*_{zy},\]

    with \(f/\pi_f\le1\), and set \(d_F=\|\bar F^{1/3}-(F^*)^{1/3}\|_{u,f}\) and \(d_B=\|\bar B^{1/3}-(B^*)^{1/3}\|_{f,b}\). The rate-\(f\) mask in both factor norms is \(Z_f\). These are the weighted norms of D-ERROR; the masks are retained even when errors and supports are correlated.

    Manuscript: §C, p. 57.

    Definition

    D-ERROR The weighted cubic error and its allocation

    For a signed row error \(H\) use the normalized cubic quantity

    \[\|H\|_{u,a}^3=\frac1N\mathbb E_\sigma\sum_x\frac{X_u(x)}u \sum_yY_a(y)|H_{xy}|^3.\]

    For a row statistic or vector omit the destination sum. For bounded nonnegative row outputs, apply this norm to the difference of their real cube roots. Raw bias/noise uses the ordinary norm. The allocation on an owner is \(\varepsilon=2^{-p_{\rm acc}}\); constants in the local estimates are independent of the input, rates and number of scale bins. Dummy default positions are not counted with the multiplicity of the ambient vertex universe.

    Manuscript: §C, p. 57.

    Definition

    D-DESCRIPTOR Complete relative arrival codes

    At dyadic slack \(d\), a code has these fields in this order: \(h\) in \(d\) bits; a signed-magnitude scale offset in \(d+1\) bits; one sign bit \(\epsilon\); a four-bit family tag; copy symbols \(\alpha,\beta\) of \(a_0=\lceil\log_2d_0\rceil\) bits each; two \(c_2\)-bit ports; and \(2\ell_{\rm mix}d\) word slots, each with nine letter bits and eight wrap bits. Unused fields and slots are zero. Negative zero and wrap code 11 are invalid; 00,01,10 represent \(0,1,-1\). A sufficient fixed width is \(C_{\rm desc}d\), with \(C_{\rm desc}=34\ell_{\rm mix}+8+2a_0+2c_2\).

    Tags 0–8 are Base, direct, product, subtraction, copy, signal, detector, direct reward and product reward. A nonbase code has \(d\le h<2d\), \(r=m-h\ge1\), child budget \(\mu=r-\epsilon\ge0\), and uses only its first \(\ell_{\rm mix}h\) word slots.     §D Physical state and finite arithmetic rules

    These definitions specify how to account for a physical call and which finite expression each query must compute.

    Definition

    D-MEMORY Shared and retained storage

    One root environment, master seed, current vertex, input-position counters and regeneration buffer occupy \(O(B)\) bits in total. Scratch is erased before a lower call. A caller retains only its relative task/word/code, numerical resume state, reserved argument cells, actual inverse tokens and owned terminal traces. These are separate from shared scratch. Let \(q\ge1\) be the metadata factor fixed in D-RESOURCE: every stated retained-length bound includes all delimiters, locators, flags, zero reservations and input-head positions. No full vertex or absolute tuple is saved in each frame. List terms, operand requests, visits and certificate passes are sequential.

    Manuscript: §D, p. 59.

    Definition

    D-ALLOWANCE The proposed space allowance and call decreases

    Let \(s\) be an operation stratum from a finite table, and let \(s_{\rm op}\) bound it. At slack \(d\) and budget \(m\) use the candidate allowance

    \[w=k_1(1+m)-(k_0+s)d, \qquad k_0>s_{\rm op}+1,\quad k_1>2(k_0+s_{\rm op}+1).\]

    At the same \((m,d)\) a child must have larger stratum. An old-prefix child uses \(2d\); a sample child decreases \(m\) by at least \(d\). A final multiplier decreases \(m\) by \(c_{\rm col}\) at fixed final slack. These are proposed forms, not a completed assignment of strata to every mode. A caller must not claim the old-prefix decrease for a visit to the current raw row.

    Manuscript: §D, p. 59.

    Definition

    D-RESOURCE A common space hypothesis with a metadata factor

    Fix an integer \(q\ge1\), a root allowance \(1\le w_0=O(B)\) and root place \(0\le t_0\le9\). Each genuine call has positive integer allowance \(w\) and place \(t\ge0\). For fixed constants \(A,D,c\), every child boundary must satisfy

    \[\Delta w=w-w'\ge1,\quad j-t\le c\Delta w,\quad R_e\le q[A\Delta w+D(t-j)].\]

    The bottom active region uses at most \(q(Aw+Dt)\) bits; all other simultaneously live storage, including root enumeration and shared scratch, uses \(O(B)\) bits. Regions are disjoint, and a fixed probe-copy overhead has already been included in \(R_e\). The largest visited tape address is at most a fixed multiple of this live extent. Both directions of cleanup obey the same hypotheses. These are requirements on an explicit finite source library, not admission tests used to reject a genuine computation.

    Manuscript: §D, p. 59.

    Definition

    D-CALLS Arguments, results and elementary work

    An assignment \(r\gets\Call{P}(q)\) names a call and binds its result. Tuple bindings name every returned component that is used; an unused component is written \(\bot\) or a named unused variable. A case-dispatched call names every possible target in its algorithm. A REQUEST is a returned message, not a call: the client must explicitly invoke its listed handler and send the answer back.

    Logical inputs are finite stored arrays, lists and exact rationals. Their elementary operations are scalar rational arithmetic, comparisons, assignments, array indexing and finite loops; matrix multiplication and a variable-length rank have named algorithms. Fixed-degree scalar polynomials and fixed-length min/max formulas use those scalar operations. Physical elementary operations are bounded-symbol edits, reads of already supplied fields, and finite integer arithmetic in the explicitly charged work area. A field that requires deriving a child tuple or transforming its seed is obtained from P-CHILD/P-REPLAY. A expression name is not permission to execute an unspecified program.

    Manuscript: §D, p. 60.

    Definition

    D-HANDLES Semantic tasks and physical argument views

    The symbol \(\mathcal T\) means the task record of D-TASKS, with immutable root parameters available. A logical caller may store that entire record. A physical caller passes a completed relative handle and mode-specific fields; it does not save an \(O(B)\) absolute tuple in every frame. Its semantic fields can be reconstructed in one shared \(O(B)\) buffer by P-REPLAY. Brackets such as \(\mathcal T[2d]\) denote a complete old-prefix request: same owner, budget and seed, slack replaced by \(2d\). They do not execute an evaluator. Child symbols \(Q.L,Q.R\) are the LEFT and RIGHT relative schemas returned by P-CHILD, not copied source vertices.

    A numerical port request adds a port, coordinate and place. A terminal request adds its mode and, for return/discard, the actual trace returned by that same terminal. A graph handle \(G\) owns one continuously allocated raw region and its cursor; a virtual view borrows a frozen region plus a bounded edit. The exact bit-level marked-field accessor, complete-link layout and per-phase slot assignment are not yet supplied: this is U-CATALOG. Field-view notation in the proposed schedules therefore carries an explicit unresolved implementation premise; it is not an uncounted completed access algorithm.

    Manuscript: §D, p. 60.

    Definition

    D-STATECONTRACT Restoration and child boundaries

    A restoring query returns a bounded answer and restores the cursor and every shared mutable register not explicitly designated as output. A successful paired move returns its actual opposite token:

    \[\Call{Fwd}_{\mathcal T}(x,p)=(y,r)\quad\Longleftrightarrow\quad\Call{Inv}_{\mathcal T}(y,r)=(x,p).\]

    Failure restores the starting cursor. A retained terminal trace owns its child records; its ancestor may perform only preallocated finite completion actions until RETURN or DISCARD consumes it. Complete invalid requests have local restoring failure; incomplete arguments authorize no call. At a genuine boundary \((w,t)\to(w',j)\), the proposed bound is

    \[0<w'<w,\quad j-t\le C_e(w-w'),\quad R_e\le q\{A_e(w-w')+D_e(t-j)\}.\]

    Here \(R_e\) is the entire caller-owned retained region. These inequalities must be proved before guards are installed. D-RESOURCE specifies their simultaneous use; a list of fields alone does not establish them.

    Definition

    D-RECIPES Closed numerical syntax and named leaves

    An expression is a finite tree built from rational/dyadic constants, named restoring digit leaves, affine sums, products, min/max, interval clipping, reciprocal after clipping to a fixed positive interval, and finite padded ranks. Only the following variable lists occur: descriptor sums, representative-pool ranks, raw-port ranks and the incoming rank provided by P-INCOMINGRANK. They have explicit finite lengths and defaults; a new arbitrary program cannot be inserted as a expression. All other expression depth and round maxima are fixed constants.

    Each node has a power-of-two scale enclosing its range for independent operands. Affine bounds use the sum of coefficient magnitudes times operand bounds; products use their product; min/max use the larger bound; projection first uses a common scale enclosing its input and both endpoints. A reciprocal has a fixed positive interval and a captured originating place. Its factor \(C\) is undone only after proving the adapted output normalized. A shift \(2^sx\) uses \(N_{t+s}(x)\), or zero for \(t+s<0\); its residue uses the last at most \(\kappa\) difference digits. This shift is legal only with the output range promise.

    A cutoff first clips its argument to \(r\in[0,1]\), computes \(a=r^2\), \(b=ar\), \(c=(10-15r+6a)/32\), then \(bc\), and finally projects \(32bc\) to \([0,1]\) at a common scale enclosing the input. Thus no oversized intermediate is passed as a unit stream. Maxima have increasing-index leaves and left ties. Public rational leaves use Euclidean signed-floor certificates; their numerator, denominator, remainder and bit scans are pure shared work, erased before an estimator call.

    D-NUMRECIPES Canonical certificate equations

    For \(|v|\le1\), the target certificate property is \(|N_t-2^tv|<2\). Digits are \(N_0\) and \(N_t-2N_{t-1}\), with residue decoding in \([-8,7]\); they have magnitude less than six. A primitive state returns either a named operand/place request or a completed residue, and retains the finite phase, loop indices, branch tags, markers, residues and pending bounded digits listed in its contract.

    For an affine sum \(v=2^{-e}\sum_i c_ix_i\), put \(A=\sum_i|c_i|\), \(h=\lceil\log_2(96A)\rceil+1\), \(T=\max(0,t-e+h)\), \(H=T+e-t\). Its certificate is

    \[N_t=\left\lfloor 2^{-H}\sum_i c_i\sum_{j=0}^T x_{i,j}2^{T-j}\right\rfloor.\]

    For a fixed continuous piecewise-affine expression with Lipschitz constant \(L_F\), use operand prefixes through \(t+h_F\) with \(6L_F2^{-h_F}<1\); choose the piece by those finite prefixes and the fixed tie rule, then take its scaled floor. Size/threshold/default use \(h_F=8\), compression \(h_F=10\), after the declared common-scale normalization. Differences of compression pieces have coefficient norm at most 48; with digit magnitude six the absorbing comparison threshold is 289. A simple two-prefix difference uses threshold 13. These are finite-prefix comparisons, never tests of equality of limiting reals.

    For multiplication, band zero has \(\min(i,j)=0\); positive dyadic band \(\delta\) has \(\delta\le\min(i,j)<2\delta\). With \(h_0=16\) and \(h_\delta=16+\lfloor\delta/4\rfloor\), set

    \[\begin{aligned}S_\delta=\sum_{\substack{(i,j)\text{ in band }\delta\\i+j\le t+h_\delta}} x_i y_j2^{t+h_\delta-i-j},&\\ F_\delta=S_\delta+\left\lfloor F_{\delta^+}/2^{h_{\delta^+}-h_\delta}\right\rfloor, &\qquad N_t=\lfloor F_0/2^{16}\rfloor.\end{aligned}\]

    The last included band has no successor term. For a reciprocal choose fixed \(C,c_r\) as in the source so the quadratic remainder is at most \(2^{-t}/16\); with \(k=\lfloor t/2\rfloor+c_r\), \(x_0=\sum_{j\le k}x_j2^{-j}\), \(\alpha=1/(Cx_0)\), \(\beta=-1/(Cx_0^2)\) and tail digits \(e_j=0\) for \(j\le k\), \(e_j=x_j\) otherwise, define

    \[N_t(1/(Cx))=\left\lfloor N_{t+3}\bigl(\operatorname{clip}_{[0,1]}(\alpha+\beta e)\bigr)/8 \right\rfloor.\]

    The inner certificate has its declared normalization; \(t\) remains captured in all coefficient requests. A largest-first rank compares prefixes through \(t+8\), with smaller-index ties, and floors the selected prefix at place \(t\). For an incoming score rank at place \(t\), multiply each score's prefix through \(t+8\) by \(2^t\), take its floor, and clip that integer to \([0,2^t]\). The certificate is the required order statistic of these integers with zero padding. These equations select actual finite certificates; merely supplying another sequence with error less than two would not preserve structural tests.

    Definition

    D-UNRESOLVED The remaining construction and proof boundaries

    U-CATALOG. Both modes need the exact finite terminal/query library: labels, legal raw slot shapes, partial-fill phases, bounded edits, predecessor certificates, complete links and restoring portals. Run 7 supplies a candidate instruction grammar with short address fields. Its audit did not establish the concrete source-library instantiation. The full mode additionally needs a layout without those per-record address costs.

    U-NUM. The equations and named operand handlers do not yet specify every resume transition, leaf schema and scale adapter. A reciprocal must preserve its originating place while rebuilding coefficients, and erase early words before late operand calls. These obligations apply in both modes.

    U-REF. The stored-tree logical reference and the reconstructed physical expressions must agree in finite certificates, padded default operands, port order and structural tests. Equality of limiting real values is insufficient.

    The normalization, compression, caller-law identifications and simultaneous constant choices also remain open. A-ACTION proves a gap for the specified finite product action under the two external Shalom contracts; it does not prove the estimator's conditional-mean identities. Full-space additions require adaptive block comparison and \(q=1\) field bounds. These premises remain open here.

    §E Fingerprint blocks and their obligations

    These definitions apply to the ordinary logarithmic-space proposal.

    Definition · Full space only

    D-HASHBLOCKS Hash blocks, effective keys and fixed masks

    For \(h_*=\lfloor\epsilon\log_2B\rfloor\ge1\), set \(\mathcal I_b=\{bh_*,\ldots,(b+1)h_*-1\}\) for \(b\ge0\), keeping blocks that meet \(\{0,\ldots,M\}\); pad small inputs so this holds. Each block has its own \(O(\log B)\) fair bits, for \(O(B)\) bits in total. A query's effective key is the block key after replaying its seed transformations. In comparisons at slack \(d>2h_*\) use exact endpoint-bit equality; otherwise use that key. A task in block \(b\) may inspect only effective keys with indices at most \(b\). Its conditional walk varies keys of index less than \(b\) and fixes every key of index at least \(b\). This rule covers values, port order, validity and predecessor tests. The mask is a public function of the budget block; no key value chooses it. The block reference changes comparisons, not this mask.

    Definition · Full space only

    D-BLOCKREFERENCE The exact within-block comparison

    The exact within-block reference replaces every same-block comparison by exact equality, recursively, while preserving lower-block actual computations. Its key-independent candidate/witness set is A-CANDIDATES. The fixed-pair collision estimate alone cannot establish adaptive accuracy. A-HASH asks for the cubic comparison with these candidates, including structural choices. The choice of cubic rather than eighth-root analysis is a substantive review decision and an open proof obligation.

    D-HASH-CANDIDATES Conditioning for the adaptive comparison

    For a block-\(b\) task use its effective seed coordinates. Let \(\mathcal G_b\) fix all coordinates except that block's original fair bits.     Definition · Full space only

    D-HASH-ERROR Error allocation within one block

    Let \(b h_*\le m<(b+1)h_*\) and choose fixed constants \(C,d_1,d_2>0\). For \(r\) in this block set \(\lambda_r=2^{-d_1h_*+d_2(r-bh_*)}\), and set \(\lambda_r=0\) below it, where the actual and reference children coincide. A child of slack \(d\) has \(r\le m-d\). All counts of descriptor types, budget layers, scale changes, witness transfers and final-gate comparisons must be included in \(2^{Cd}\). For a row, its per-source discrepancy is the cube root of the destination-weighted sum of cubed differences in the metric prescribed by D-ERROR; for a vector it is the absolute difference. The source-weighted norm of this quantity is exactly that D-ERROR norm. Let \(e_m\) be the maximum of \(2^{p_{\rm acc}}\) times this norm over the finitely many legal tasks and output types at budget \(m\). The required relative comparison recurrence is

    \[e_m\le \sum_{d=1}^{2h_*}2^{Cd}\max_{\substack{r\in\mathcal I_b\\r\le m-d}} e_r +2^{Ch_*}B^{-1/6},\]

    where an empty maximum is zero and the absolute D-ERROR discrepancy is \(2^{-p_{\rm acc}}e_m\). This is a quantitative requirement, not an established bound for the present source library.

    Definition · Full space only

    D-TIGHT What the full layout must save

    The full implementation uses D-RESOURCE at \(q=1\). Across a tight comparison it saves relative codes and finite phase/result bits, with no retained fingerprint or bit-position word. Replayed owner data, key arithmetic and pure scratch are erased before a child call. The one shared \(B\)-bit catalyst counts in full. Every other numerical, terminal, predecessor, partial-argument and cleanup field must satisfy the same signed bound; the comparison trick supplies no bound for these other fields.
