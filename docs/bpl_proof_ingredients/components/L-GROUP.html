    Logical routine · Both modes

    L-GROUP
    Distribute increments without merging stored values

    Manuscript: Algorithm L-GROUP, §8.1 Group arrivals under the chosen policy, p. 24.

    This component has full-space additions. Switch to Full space to show them.

    Input and output

    Explicit interface · Distribute increments without merging stored values

    \(\Call{L-GROUP}(O,J,z,d,\eta)\longrightarrow(W)\)

    \(O\) is the ordered old representative list with values; \(J\) is the ordered list of new records \((\mathrm{valid},\mathrm{endpoint},\mathrm{increment})\). \(z\) is the old default. The policy \(\eta\) specifies the endpoint equivalence in D-POLICY. Every record carries its owner, seed and endpoint; comparison labels are constructed here. The result preserves old representatives separately.

    State and cost. Logical full lists; Full space P-KEY receives a materialized endpoint and uses only pure scratch. All class sums are retained; no low-space claim.

    Algorithm

    Requires. Every old record is present; each record supplies its owner, seed and endpoint, and \(\eta\) fixes the selected comparison policy.

    1. Use \(\kappa(v)=v\) as the comparison label in exact mode. Full space In the full configuration use it also if \(d>2h_*\). Otherwise, for each record at endpoint \(v\), \((\kappa(v))\gets\) P-KEY\((\rho,v,b)\), with the invoking owner’ s block \(b\) and seed \(\rho\).
    2. For each comparison label \(k\) occurring in \(O\) or a valid member of \(J\), set \(v_k=(0,0)\).
    3. Scan all valid \(j\in J\) and add its increment to \(v_{\kappa(j)}\), including zero increments.
    4. For every \(o\in O\), output the same representative with value \(O(o)+v_{\kappa(o)}\).
    5. For a class with no old representative, output its first valid new record with value \((z,0)+v_k\).
    6. All other real endpoints receive default \((z,0)\); return the ordered represented row \(W\).

    What to prove

    Open proof obligation · §8.1

    Prove that the physical scan selects the same representatives and adds the same signed operands in the fixed order, for the selected policy.
