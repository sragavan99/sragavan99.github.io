    Physical routine · Both modes

    P-RAWNUM
    Row before gating presence, default and coordinate queries

    Manuscript: Algorithm P-RAWNUM, §8.2 Choose a default and retain exceptions, p. 28.

    Input and output

    Explicit interface · Row before gating presence, default and coordinate queries

    \(\Call{P-RAWNUM}(\mathcal T,p,\mathrm{mode},t)\longrightarrow(b)\)

    Modes are PRESENCE, COORDINATE\((\nu)\) and DEFAULT\((\nu)\). A hole coordinate is zero; DEFAULT is a distinct numerical request. Return one bit or signed digit with no endpoint motion. All zero cells reserved for the selected code count while SELECT is active.

    State and cost. Entire reserved code \(O(d)\) across selector calls, ordinal and fill frontier, or numerical default state. These branches do not keep each other's work.

    Algorithm

    Requires. Complete raw-prefix request with correct mode-specific fields.

    1. Reject invalid slack/mode and inactive tasks with the appropriate zero answer.
    2. For a port mode, reserve and zero its entire \(L\)-bit code slot. \((v)\gets\) P-SELECT\((\mathcal T,p,\mathrm{presence},0)\); if \(v=0\), erase the slot and return zero.
    3. In a present port mode only, for \(i=0,\ldots,L-1\), \((c_i)\gets\) P-SELECT\((\mathcal T,p,\mathrm{bit},i)\); fill the reserved slot. Interpret it only after it is complete.
    4. For COORDINATE, \((b)\gets\) P-COMPRESS\((\mathcal T,c,\nu,t)\); erase the slot and return \(b\). PRESENCE returns one after erasure.
    5. For DEFAULT set \(s=\varnothing,a=\bot\). Drive \((s',o)\gets\) P-NUMSTEP\((E_{\rm default},t,\mathrm{digit},s,a)\); answer each threshold request by \((a)\gets\) P-THRESHOLD\((\mathcal T,\mathrm{u\ or\ q},j)\) until DONE\((b)\), then erase state and return \(b\).

    What to prove

    Open proof obligation · §8.2

    Bound the number of retained entries and the distortion of the later row functions. Prove that the physical tests and streams agree with the logical finite certificates, padded operand lists, and ties. A later digit request must leave the chosen list fixed.
