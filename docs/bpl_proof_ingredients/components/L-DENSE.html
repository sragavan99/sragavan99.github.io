    L-DENSE
    Dense hard-threshold example

    Manuscript: Algorithm L-DENSE, §4.1 A dense threshold example, p. 10.

    Input and output

    Explicit interface · Dense hard-threshold example

    \(\Call{L-DENSE}(C,w,f,\theta,K)\longrightarrow(D,w^+)\)

    Return one dense hard-threshold correction stage. The parameter \(K\) is supplied, not chosen from an asymptotic slogan. The procedure makes no detector or sampling calls; its role is to explain the value-preserving correction identity.

    State and cost. Three full matrices, vectors and loop counters; finite \(K\) iterations. No physical estimator uses this routine.

    Algorithm

    Requires. Forward substochastic \(0\le C\le f\) and \(p=w+Cp\in[0,1]^V\) with \(w\ge0\).

    1. Set \(E=0\).
    2. For \(i=1,\ldots,K\): \((Z)\gets\) L-MATMUL\((E,C)\); for all \((x,y)\) set \(E_{xy}\gets\max(0,C_{xy}+Z_{xy}-\theta f)\).
    3. \((Z)\gets\) L-MATMUL\((E,C)\); set \(D=C-E+Z\) entry by entry.
    4. \((v)\gets\) L-MATMUL\((E,w)\); set \(w^+=w+v\) and return \((D,w^+)\).
