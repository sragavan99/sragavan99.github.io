    Physical routine · Both modes

    P-NODESTEP
    Advance one primitive numerical node

    Manuscript: Algorithm P-NODESTEP, §11.2 Stream digits through bounded requests, p. 45.

    Input and output

    Explicit interface · Advance one primitive numerical node

    \(\Call{P-NODESTEP}(F,t,\kappa,s,a)\longrightarrow(s^+,o)\)

    \(F\) is one normalized primitive node with its direct operands treated as named leaves. Return its complete primitive state and REQUEST or DONE result. This finite arithmetic dispatch does not evaluate a child expression or invoke an external leaf.

    State and cost. Finite tag and the one selected primitive state; no additional numerical stack.

    Algorithm

    Requires. One legal D-RECIPES node, valid normalization and matching state/answer.

    1. For affine, min/max, clipping or a scale adapter, \((s^+,o)\gets\) P-AFFINE\((F,t,\kappa,s,a)\).
    2. For a product, \((s^+,o)\gets\) P-MULTIPLY\((F,t,\kappa,s,a)\).
    3. For reciprocal, \((s^+,o)\gets\) P-RECIPROCAL\((F,t,\kappa,s,a)\).
    4. For padded rank, \((s^+,o)\gets\) P-RANK\((F,t,\kappa,s,a)\). Return the bound state and result.

    What to prove

    Open proof obligation · §11.2

    Prove agreement with the finite equations for every primitive and client, including ties and scale shifts. Instantiate the resume transitions, then count the fields across each operand call. For a reciprocal, keep the originating place available while erasing the long early word before a late operand request.
