    Physical routine · Both modes

    P-INTRINSICVALUE
    Answer one digit of a sample expression

    Manuscript: Algorithm P-INTRINSICVALUE, §7.1 Form one sample term, p. 19.

    Input and output

    Explicit interface · Answer one digit of a sample expression

    \(\Call{P-INTRINSICVALUE}(\mathcal T,c,\nu,t)\longrightarrow(b)\)

    Return one normalized digit of the complete descriptor contribution, with the coefficient and leaf expression specified in D-INTRINSIC. Wrong coordinates return the zero stream without changing presence. This interface assumes the caller has validated the outer descriptor; its own lower leaf accesses still validate their public ports.

    State and cost. Descriptor, fixed arithmetic continuation, one pending digit and at most one actual token. Coefficient/replay scratch is erased before child calls; signed arithmetic and structural charges compose in E-INTRINSICVALUE.

    Algorithm

    Requires. Valid descriptor, coordinate, normalized ranges; scalar families have no endpoint mode.

    1. Start \(s=\varnothing,a=\bot\) for expression \(E_{\mathcal T,c,\nu}\) at scale \(H_d\).
    2. Repeat \((s',o)\gets\) P-NUMSTEP\((E_{\mathcal T,c,\nu},t,\mathrm{digit},s,a)\); set \(s=s'\).
    3. For REQUEST\((\mathrm{row},j)\) call \((a)\gets\) P-ROW\((\mathcal T_{\rm leaf},p,j)\); for REQUEST\((\mathrm{vector},j)\) call \((a)\gets\) P-VECTOR\((\mathcal T_{\rm leaf},j)\).
    4. For REQUEST\((\mathrm{rank},j)\) call \((a)\gets\) P-INCOMING\((\mathcal T_{\rm score},\mathrm{detector},j)\).
    5. For a right-factor request first \((u,r)\gets\) P-CAP\((\mathcal T_L,p_1,\mathrm{forward})\). If \(u=0\), supply zero. Otherwise call \((a)\gets\) P-ROW\((\mathcal T_R,p_2,j)\) for a right row or \((a)\gets\) P-VECTOR\((\mathcal T_R,j)\) for a right vector, then \((v,p\prime)\gets\) P-CAP\((\mathcal T_L,r,\mathrm{inverse})\) before resuming.
    6. For copy leaves remove/restore the known source symbol around each call. On DONE\((b)\) erase \(s\) and return \(b\).

    What to prove

    Open proof obligation · §7.1

    Check each family's term and coefficient against D-ROWFAMILIES or D-VECTORS. Prove the conditional mean and the error transfer from child values. The product bound uses pointwise support counts and the common right tuple.

    Relationships

    Calls

    Runs another routine at runtime or in the explicit logical reference.

    • P-NUMSTEP Advance a numerical expression without calling its operands Step 2
    • P-ROW Final numerical row query Steps 3, 5
    • P-VECTOR Final reward or detector vector query Steps 3, 5
    • P-INCOMING Incoming score rank without a saved endpoint Step 4
    • P-CAP Delete an entire overfull incoming column Step 5

    Called by

    • P-ARRIVAL One validated increment value

    Depends on for proof

    From the proof note for §7.1 (What to prove, above).

    • D-ROWFAMILIES Row families and their complete child maps
    • D-VECTORS Detector and reward vector families

    • D-INTRINSIC Complete normalized arrival expressions
