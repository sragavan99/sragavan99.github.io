    Physical routine · Both modes

    P-BASE
    Local access to the paired base graph

    Manuscript: Algorithm P-BASE, §2.2 Paired base graph and continuation values, p. 6.

    Input and output

    Explicit interface · Local access to the paired base graph

    \(\Call{P-BASE}(x,\mathrm{mode},p)\longrightarrow(r)\)

    The current cursor is an original vertex or a merging-chain name \((y,i)\). Modes are size, start, reward, weight, presence, forward and inverse. The last two return a success bit and the actual opposite port, and move the cursor only on success. Pure modes do not move it. Parallel labels remain distinct.

    State and cost. Pure \(O(\log(n+2))\) scratch. A successful pair changes only the shared cursor and returns a bounded token; failure restores it. No recursive calls.

    Algorithm

    Requires. Well-formed input, or a bounded invalid-request branch.

    1. Scan labelled input edges in input order; for each destination \(y\) count its incoming edges \(e_1,\ldots,e_k\).
    2. The virtual vertices are the original vertices and \((y,i)\), \(1\le i\le k\). The redirected edge \(e_i\) ends at \((y,i)\) with weight \(1/2\); chain edges \((y,i)\to(y,i+1)\) and \((y,k)\to y\) have weight one.
    3. For size/start/reward/weight, rescan these finite records and return the requested scalar; invalid requests return zero.
    4. For presence/forward/inverse, enumerate the at most two incidences in the requested direction at the cursor in label order and check \(p\) before motion.
    5. On a valid move, compute its opposite incidence ordinal by the same scans, update the cursor, and return \((1,p')\). Otherwise return \((0,0)\) at the original cursor.

    What to prove

    Open proof obligation · §2.2

    Verify the probability-preserving base conversion, the name convention, and both directions of the port pairing. Check the setup ranges and halting behavior on malformed and zero-layer inputs.
