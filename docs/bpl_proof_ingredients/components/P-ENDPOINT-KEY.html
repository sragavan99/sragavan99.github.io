    Physical routine · Full space only

    P-ENDPOINT-KEY
    Read or toggle one fingerprint cell

    Manuscript: Algorithm P-ENDPOINT-KEY, §9.4 Compare names or fingerprints, p. 37.

    Full-space mode only. This component is part of the logarithmic-space evaluator's fingerprint comparison and is not used with exact name comparison.

    Input and output

    Explicit interface · One cell indexed by a recomputed fingerprint

    \(\Call{P-ENDPOINT-KEY}(\mathcal T,a)\longrightarrow(b)\)

    The action is READ-KEY or FLIP-KEY, and the owner, effective seed and block are fixed by the complete task. A counted shared array \(V\in\{0,1\}^{B}\) is available. READ-KEY returns its indexed bit without mutation. FLIP-KEY toggles that bit and returns zero. Neither action changes the cursor or makes an estimator query; its parent owns the obligation to undo a flip.

    Algorithm

    Input/Output. D-API-P-ENDPOINT-KEY; invalid actions return zero without mutation.

    1. \((Q)\gets\) P-REPLAY\((\mathcal T,\mathrm{comparison},0)\). Check the owner block and permitted effective coordinates.
    2. \((k)\gets\) P-KEY\((Q.\rho,\mathrm{cursor},Q.b)\). Verify \(1\le k\le B\) before indexing.
    3. If \(a=\mathrm{READ\!\!\!-KEY}\), set \(b=V_k\). If \(a=\mathrm{FLIP\!\!\!-KEY}\), set \(V_k\gets1-V_k\) and \(b=0\). Otherwise set \(b=0\).
    4. Erase \(Q,k\) and pure scratch; return \(b\).

    Distinct callees (2): P-REPLAY, P-KEY.

    What to prove

    Open proof obligation · §9.4

    Establish the predicate returned in each mode, restoration for arbitrary initial shared bits, and the retained fields at each visit. Analyze collision-induced changes on the logical side using Section §8.3.
