    Physical routine · Full space only

    P-MATCH-HASH
    Compare fingerprints using four restoring visits

    Manuscript: Algorithm P-MATCH-HASH, §9.4 Compare names or fingerprints, p. 38.

    Full-space mode only. This component is part of the logarithmic-space evaluator's fingerprint comparison and is not used with exact name comparison.

    Input and output

    Explicit interface · Restoring comparison of two fingerprints

    \(\Call{P-MATCH-HASH}(\mathcal T,c_1,c_2)\longrightarrow(b)\)

    The codes have the same owner and effective block key. Endpoint existence, paths and the final comparison answer are independent of the incoming contents of the counted \(B\)-bit catalyst. A visit may fail, but a repeated visit to the same code has the same presence and endpoint. Every nested call restores the catalyst it receives. Return zero if either endpoint is absent; otherwise return equality of the two fingerprints. Restore both cursor and catalyst.

    Algorithm

    Input/Output. D-API-P-MATCH-HASH. No branch may use a catalyst read to select a path.

    1. \((u,x)\gets\) P-VISITPOOL\((\mathcal T,c_1,\mathrm{READ\!\!\!-ID}(0))\); \((v,y)\gets\) P-VISITPOOL\((\mathcal T,c_2,\mathrm{READ\!\!\!-ID}(0))\). If \(u v=0\), return zero without a flip.
    2. \((u_1,z_1)\gets\) P-VISITPOOL\((\mathcal T,c_1,\mathrm{FLIP\!\!\!-KEY})\).
    3. \((u_2,z_2)\gets\) P-VISITPOOL\((\mathcal T,c_2,\mathrm{READ\!\!\!-KEY})\). Retain only \(z_2\) and finite phase flags.
    4. \((u_3,z_3)\gets\) P-VISITPOOL\((\mathcal T,c_1,\mathrm{FLIP\!\!\!-KEY})\).
    5. \((u_4,z_4)\gets\) P-VISITPOOL\((\mathcal T,c_2,\mathrm{READ\!\!\!-KEY})\). Return \(z_2\mathbin{\mathrm{xor}}z_4\) after every visit has unwound.

    Distinct callees (1): P-VISITPOOL.

    What to prove

    Open proof obligation · §9.4

    Establish the predicate returned in each mode, restoration for arbitrary initial shared bits, and the retained fields at each visit. Analyze collision-induced changes on the logical side using Section §8.3.
