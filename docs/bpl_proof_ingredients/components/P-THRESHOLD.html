    Physical routine · Both modes

    P-THRESHOLD
    Compute the two compression thresholds

    Manuscript: Algorithm P-THRESHOLD, §8.2 Choose a default and retain exceptions, p. 27.

    Input and output

    Explicit interface · Compute the two compression thresholds

    \(\Call{P-THRESHOLD}(\mathcal T,\mathrm{kind},t)\longrightarrow(b)\)

    Return a normalized digit of \(u=\max(z,2^{-c_1d},\operatorname{rank}_{n_d}M)\) or \(q=\max(0,\operatorname{rank}_{k_{\rm row}}W^1)\). The first argument wins a numerical tie. Old values are adapted from scale \(H_{2d}\) to \(H_d\).

    State and cost. Finite kind, arithmetic path and the current child request; no entire rank or threshold is stored. Scale shifts contribute to \(j-t\).

    Algorithm

    Requires. Raw-sum range and legal dyadic slack.

    1. Start the literal \(u\) or \(q\) expression in the empty numerical state. Set \(s=\varnothing,a=\bot\).
    2. Repeat \((s',o)\gets\) P-NUMSTEP\((E_{\mathrm{kind}},t,\mathrm{digit},s,a)\); set \(s=s'\).
    3. For a rank request call \((a)\gets\) P-INTERMEDIATERANK\((\mathcal T,\mathrm{size\ or\ first},j)\).
    4. For old default use zero at the top; otherwise \((a)\gets\) P-RAWNUM\((\mathcal T[2d],0,\mathrm{default},j+\lambda d)\) with the declared adapter.
    5. The floor \(2^{-c_1d}/H_d\) is a public dyadic leaf. On DONE\((b)\) return \(b\) after erasing state.

    What to prove

    Open proof obligation · §8.2

    Bound the number of retained entries and the distortion of the later row functions. Prove that the physical tests and streams agree with the logical finite certificates, padded operand lists, and ties. A later digit request must leave the chosen list fixed.

    Relationships

    Calls

    Runs another routine at runtime or in the explicit logical reference.

    • P-NUMSTEP Advance a numerical expression without calling its operands Step 2
    • P-INTERMEDIATERANK Rank the row before compression Step 3
    • P-RAWNUM Row before gating presence, default and coordinate queries Step 4
