    Physical routine · Both modes

    P-MEDIAN
    Median by repeated finite scans

    Manuscript: Algorithm P-MEDIAN, §12.2 Select the lower median by scans, p. 47.

    Input and output

    Explicit interface · Median by repeated finite scans

    \(\Call{P-MEDIAN}(\rho)\longrightarrow(a)\)

    Return the lower median of the multiset of grid numerators returned by TRIAL on the exact SEEDS sequence. Each restart uses frontier zero. No seed or value list is stored.

    State and cost. Constantly many \(O(B)\) counters plus one seed coexist with one TRIAL call. Iterator, trial scratch and returned stacks are freed on every iteration.

    Algorithm

    Requires. Legal \(\rho\) and total trial evaluation on every enumerated seed.

    1. Set \(n_{\rm trials}=0,c=0\). Repeatedly call \((\sigma,c',b)\gets\) P-SEEDS\((\rho,c)\); if \(b=0\) stop, otherwise set \(c=c'\) and increment \(n_{\rm trials}\).
    2. If \(n_{\rm trials}=0\), return \(0\) (a setup-contract failure branch).
    3. For \(a=0,\ldots,512\), set \(c=0,v=0\).
    4. Repeat \((\sigma,c',b)\gets\) P-SEEDS\((\rho,c)\); stop this scan at \(b=0\); otherwise set \(c=c'\) and call \((u)\gets\) P-TRIAL\((\rho,\sigma)\).
    5. Increment \(v\) iff \(u\le a\). After the full scan, if \(2v\ge n_{\rm trials}\), return \(a\).

    What to prove

    Open proof obligation · §12.2

    Use the root moment bound under the enumerated law and the hierarchy remainder to put a majority of grid values within the target error. Check the space of one trial together with the seed and median counters.
