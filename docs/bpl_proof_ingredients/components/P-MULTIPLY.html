    P-MULTIPLY
    Product-band arithmetic requests

    Manuscript: Algorithm P-MULTIPLY, §11.2 Stream digits through bounded requests, p. 43.

    Input and output

    Explicit interface · Product-band arithmetic requests

    \(\Call{P-MULTIPLY}(F,t,\kappa,s,a)\longrightarrow(s^+,o)\)

    \(F\) names two normalized operands \(x,y\). Return a certificate residue for \(xy\) through the exact band recurrence in D-NUMRECIPES. The state carries the band continuation, finite loop position, residues and at most one pending digit. Operand requests are returned to the client, not executed here.

    State and cost. Band residues and saved band continuations total \(O(\delta+1)\) at a band-\(\delta\) request, plus origin-restoration markers and one digit. Query-free work is \(O(t+1)\); no full convolution is stored.

    Algorithm

    Requires. \(x,y\in[-1,1]\), fixed modulus tag and normalized output.

    1. Set \(h_0=16\) and \(h_\delta=16+\lfloor\delta/4\rfloor\). List band \(0\) and dyadic \(\delta\le4(t+16)/7\).
    2. Process bands from largest to smallest. In band \(\delta\), initialize its residue with the already completed larger-band residue shifted down by \(h_{\delta^+}-h_\delta\) using signed floor.
    3. Enumerate \(k=0\) for band zero, or \(\delta\le k<2\delta\) otherwise, and \(a=0,\ldots,\kappa+h_\delta-1\); set \(u=t-\kappa+1+a\) and skip \(u<2k\).
    4. For pair \((i,j)=(k,u-k)\) and also \((u-k,k)\) when \(u>2k\), \(b\gets\mathrm{REQUEST}(x,i)\); \(c\gets\mathrm{REQUEST}(y,j)\); add \(bc2^{\kappa+h_\delta-1-a}\) modulo \(2^{\kappa+h_\delta}\).
    5. After band zero, return DONE\((\lfloor R_0/2^{16}\rfloor\bmod2^\kappa)\).

    What to prove

    Open proof obligation · §11.2

    Prove agreement with the finite equations for every primitive and client, including ties and scale shifts. Instantiate the resume transitions, then count the fields across each operand call. For a reciprocal, keep the originating place available while erasing the long early word before a late operand request.
