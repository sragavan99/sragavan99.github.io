    T-DESCRIPTOR
    Terminal program for a validated descriptor

    Manuscript: Algorithm T-DESCRIPTOR, §9.2 Expose a port and own its return path, p. 32.

    Input and output

    Explicit interface · Terminal program for a validated descriptor

    \(\Call{T-DESCRIPTOR}(\mathcal T,c,\mathrm{mode},\tau)\longrightarrow(b,\tau^+)\)

    This terminal adds original-owner validity to intrinsic motion. It returns the same endpoint as the intrinsic descriptor, even for numerical value zero. RETURN and DISCARD use the recorded intrinsic trace; they do not rerun a destination-dependent validity test at the wrong cursor.

    State and cost. Complete relative descriptor, entry mode and one terminal-child link. Validation work is erased before delegation.

    Algorithm

    Requires. Valid owner kind; scalar families reject terminal modes. RETURN/DISCARD enter their trace branch directly, skipping fresh-request steps.

    1. For a fresh request, \((v)\gets\) P-VALID\((\mathcal T,c)\); if \(v=0\), fail restoring.
    2. Erase validation-only fields, then \((b,\tau_1)\gets\) T-INTRINSIC\((\mathcal T,c,\mathrm{retain},\bot)\).
    3. RETAIN returns that owned trace/link. PRESENCE calls \((b',\bot)\gets\) T-INTRINSIC\((\mathcal T,c,\mathrm{return},\tau_1)\) before returning the presence bit.
    4. RETURN calls \((b',\bot)\gets\) T-INTRINSIC\((\mathcal T,c,\mathrm{return},\tau)\); DISCARD calls \((b',\bot)\gets\) T-INTRINSIC\((\mathcal T,c,\mathrm{discard},\tau)\). Erase the parent link after the child.
    5. STEP: the public schedule has no further target, but its phase/slot edit list remains U-CATALOG.

    What to prove

    Open proof obligation · §9.2

    Give the finite transition and field catalogue for the terminal programs. Check all presence, motion, return, discard, and failure cases, including synthetic states admitted to a probe.
