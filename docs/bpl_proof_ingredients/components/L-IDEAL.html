    Logical routine · Both modes

    L-IDEAL
    An ideal normalized sampled row

    Manuscript: Algorithm L-IDEAL, §6.1 Normalize the ideal sampled tables, p. 13.

    Input and output

    Explicit interface · An ideal normalized sampled row

    \(\Call{L-IDEAL}(d,g,u,a,\tau,\Omega,\theta)\longrightarrow(F)\)

    The inputs are the deterministic normalized entries \(d_{xy}\), a column multiplier, rates and an explicit seed/hit table. Return the full ideal normalized table at every seed. The conditional denominator includes precisely its numerator gates. This is an unbiasedness comparison object, not the implemented estimator.

    State and cost. Full arrays over seeds and vertices, unrestricted rational storage; finite loops.

    Algorithm

    Requires. \(a\sum_y d_{xy}\le m_0\); for corrections, \(g_y>0\) implies at most \(r_0/u\) entries above \(\theta/8\) in column \(y\).

    1. For every seed and row, form \(v=(d_{xz}:Y_a(z)=1)\); \((s_x)\gets\) L-RANK\((v,k_{\rm row},0)\); set \(I_{xy}=I_\theta(d_{xy},s_x)\).
    2. For each correction column form \(v=(I_{xy}:X_u(x)=1)\); \((r_y)\gets\) L-RANK\((v,k_c,0)\); set \(T_y=1-\chi_{1/4,1/2}(r_y)\). For bins set \(T_y=1\).
    3. For each \((x,y)\) sum \(h_\theta(d_{xy})R_\theta(s_x)T_y\) over \(X_u(x)Y_\tau(y)=1\) and divide by the number of these seed encodings; call the result \(q_{xy}\).
    4. For every seed return \(F_{xy}=X_u(x)Y_\tau(y)k(d_{xy})R_\theta(s_x)T_yg_y/\operatorname{clip}_{[1/2,1]}q_{xy}\).

    What to prove

    Open proof obligation · §6.1

    Bound the normalizer away from zero where it is used and check the conditional mean after dividing by it.
