    Physical routine · Both modes

    P-ROOT
    Deterministic ROBP probability estimator

    Manuscript: Algorithm P-ROOT, §13.2 Run the estimator in either comparison mode, p. 49.

    Input and output

    Explicit interface · Deterministic ROBP probability estimator

    \(\Call{P-ROOT}(x,\eta)\longrightarrow(a)\)

    \(x\) is the complete explicitly listed ROBP input. Return the integer numerator \(a\in\{0,\ldots,512\}\); the denominator is fixed by the public interface. Malformed input returns zero. The proposed numerical guarantee is D-TARGET; it is not established by this architecture.

    State and cost. Root environment, seed counter, one cursor and shared scratch occupy \(O(B)\) once. No lower frame owns a second copy.

    Algorithm

    Requires. Fixed constants satisfying E-CONSTANTS, still open.

    1. \((\rho,\mathrm{ok})\gets\) P-SETUP\((x,\eta)\). If \(\mathrm{ok}=0\), output \(0\) and halt.
    2. Initialize the shared registers prescribed by configuration \(\eta\); charge their full size once.
    3. \((a)\gets\) P-MEDIAN\((\rho)\).
    4. Output \(a\) and halt.

    What to prove

    Open proof obligation · §13.2

    The shared work is to prove the accuracy induction for the specified law, instantiate the terminal and arithmetic libraries, and prove that they realize the finite reference. The exact-name configuration additionally needs a complete retained-field assignment at the relaxed metadata cost. The full-space configuration needs the adaptive comparison estimates and a retained-field assignment at unit metadata cost. The signed space condition in D-RESOURCE counts the entire catalyst in shared storage and the other live fields at each boundary. Both unconditional conclusions remain open.
