    Physical routine · Both modes

    P-CAP
    Delete an entire overfull incoming column

    Manuscript: Algorithm P-CAP, §6.2 Assemble final values and ports, p. 16.

    Input and output

    Explicit interface · Delete an entire overfull incoming column

    \(\Call{P-CAP}(\mathcal T,p,\mathrm{direction})\longrightarrow(b,r)\)

    Forward maps a present source port to its destination and actual incoming rank; inverse maps that destination/rank back to the source and port. Delete an entire column when its number of precursor initials exceeds \(k_c\). Count present zero-valued ports. Failure restores the starting cursor.

    State and cost. One graph region, bounded counts/rank/direction and one finite status. The cap does not own a second graph or score payload; all failed scans are undone.

    Algorithm

    Requires. Common precursor graph; \(k_c\) fixed and PROBE/TOUR total.

    1. For FORWARD, \((v)\gets\) P-CLASS\((\mathcal T,p,A)\); if false fail. Initialize the canonical precursor initial \(I(x,p)\) in one graph region.
    2. From this initial repeat \((z)\gets\) P-TOUR\((G,\mathrm{backward})\) until sentinel or \(k_c+1\) jumps; count \(a\). Undo exactly those jumps by \((z)\gets\) P-TOUR\((G,\mathrm{forward})\). Then count forward distance \(b\) using \((z)\gets\) P-TOUR\((G,\mathrm{forward})\) and undo with \((z)\gets\) P-TOUR\((G,\mathrm{backward})\).
    3. If either scan overflowed or \(a+b-1>k_c\), erase the restored initial and fail. Otherwise repeat \((z)\gets\) P-TOUR\((G,\mathrm{forward})\) exactly \(b\) times to the sentinel; return success with token \(a\).
    4. For INVERSE initialize the success sentinel at the destination. Repeat \((z)\gets\) P-TOUR\((G,\mathrm{forward})\), counting initials until sentinel or \(k_c+1\) initials. On overflow undo exactly the recorded jumps with \((z)\gets\) P-TOUR\((G,\mathrm{backward})\).
    5. At the restored sentinel reject overflow or an out-of-range token. Otherwise repeat \((z)\gets\) P-TOUR\((G,\mathrm{forward})\) exactly \(p\) times; read the actual source port at the resulting initial, erase graph work and return it.

    What to prove

    Open proof obligation · §6.2

    Show that the fixed classes cover the gated support, that the cap deletes only zero gated values, and that each query agrees with the corresponding finite test or value. Check that successful pairs are inverse and that failure and cleanup restore all required state.
