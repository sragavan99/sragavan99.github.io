    P-RANK
    Finite-prefix order-statistic requests

    Manuscript: Algorithm P-RANK, §11.2 Stream digits through bounded requests, p. 44.

    Input and output

    Explicit interface · Finite-prefix order-statistic requests

    \(\Call{P-RANK}(F,t,\kappa,s,a)\longrightarrow(s^+,o)\)

    \(F\) gives list length \(Q\le2^{Cd}\), rank \(k\), and explicit numerical padding/default operands. Return a certificate residue for its largest-first rank. Invalid ranks return the declared default before requesting an operand. A hole contributes its specified default, never an endpoint.

    State and cost. Candidate, competitor, rank and count each \(O(d)\), one pending digit and signed remaining-place markers. Only selected index and fixed residue survive the last phase.

    Algorithm

    Requires. Complete fixed list semantics and normalized common scale.

    1. Set \(T=t+8\). For each candidate \(i=0,\ldots,Q-1\), initialize \(c=0\).
    2. For each competitor \(j\), run \((s'_1,o_1)\gets\) P-AFFINE\((\mathrm{compare}(i,j,T),0,\kappa,s_1,a_1)\), forwarding each digit request to the client and binding its answer.
    3. Increment \(c\) when the complete prefix of \(j\) is larger, or equal with \(j<i\).
    4. Select the unique \(i\) with \(c=k-1\); finish finite loops, then erase competitor and count fields.
    5. Accumulate only the last \(\kappa+8\) digits of candidate \(i\) through \(T\) using \(b\gets\mathrm{REQUEST}(i,j)\); return its floor certificate residue as DONE\((R)\).

    What to prove

    Open proof obligation · §11.2

    Prove agreement with the finite equations for every primitive and client, including ties and scale shifts. Instantiate the resume transitions, then count the fields across each operand call. For a reciprocal, keep the originating place available while erasing the long early word before a late operand request.
