    Logical routine · Both modes

    L-CERT
    Evaluate a canonical certificate in the reference computation

    Manuscript: Algorithm L-CERT, §11.1 Define the finite arithmetic result, p. 41.

    Input and output

    Explicit interface · Evaluate a canonical certificate in the reference computation

    \(\Call{L-CERT}(E,t)\longrightarrow(N)\)

    \(E\) is a finite canonical expression tree with the normalized leaf streams and scales in D-RECIPES. Return the integer \(N_t(E)\) defined by D-NUMRECIPES and the specified score quantization for an incoming rank. The primitive formulas determine the rounding and ties.

    State and cost. Explicit operands, prefixes, and integers. Evaluation of an operand descends the expression tree. The finite auxiliary expression for a reciprocal is evaluated above the already specified operand stream.

    Algorithm

    Requires. Finite acyclic expression tree, normalized leaves, valid ranges.

    1. At a rational leaf return its signed-floor certificate. At an incoming-rank leaf, materialize the specified score list. For each score tree \(E'\) call \((U)\gets\) L-CERT\((E',t+8)\) and use prefix \(2^{-(t+8)}U\). Apply the incoming-score rule of D-NUMRECIPES and return the rank certificate.
    2. For each operand place required by D-NUMRECIPES, call \((U)\gets\) L-CERT\((E',j)\) on the operand tree \(E'\). A prefix through \(j\) is \(2^{-j}U\). If a digit is required and \(j>0\), call \((V)\gets\) L-CERT\((E',j-1)\) and use \(U-2V\). At \(j=0\) use \(U\).
    3. For a sum, minimum, maximum, clip, scale adapter, product, or padded rank, return its displayed finite integer formula on those operands with the stated order, scale, and ties.
    4. For a reciprocal, use the prefix at the prescribed earlier place to form the two coefficients and the virtual tail stream. Evaluate the displayed affine and clipping certificate at \(t+3\) on that stream. Divide its integer result by eight and take the floor. Return the resulting \(N_t(E)\).
