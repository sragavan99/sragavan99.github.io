    T-FINAL
    Final table presence and terminal access

    Manuscript: Algorithm T-FINAL, §9.2 Expose a port and own its return path, p. 33.

    Input and output

    Explicit interface · Final table presence and terminal access

    \(\Call{T-FINAL}(\mathcal T,p,\mathrm{mode},\tau)\longrightarrow(b,\tau^+)\)

    Public terminal access to a final row. Dense rows use raw traces; corrections use the whole-column cap's actual paired token. No numerical row value is evaluated here. A vector or invalid port request fails before motion.

    State and cost. Finite row kind/mode and one trace or bounded token; no numerical continuation or saved source. All failed calls restore.

    Algorithm

    Requires. Complete row task, canonical trace and matching mode. RETURN/DISCARD enter their trace branch directly, skipping fresh-request steps.

    1. \((Q)\gets\) P-REPLAY\((\mathcal T,\mathrm{row\ terminal\ kind},\mathrm{mode})\).
    2. For a fresh dense request, \((v)\gets\) P-CLASS\((\mathcal T,p,A)\); if false fail; otherwise \((b,\tau_1)\gets\) T-RAW\((\mathcal T[1],p,\mathrm{retain},\bot)\).
    3. For a fresh correction request, \((b,r)\gets\) P-CAP\((\mathcal T,p,\mathrm{forward})\); record \(r\) on success.
    4. PRESENCE: for dense mode \((b\prime,\bot)\gets\) T-RAW\((\mathcal T[1],p,\mathrm{return},\tau_1)\); for correction mode \((b\prime,p\prime)\gets\) P-CAP\((\mathcal T,r,\mathrm{inverse})\). RETAIN returns the actual trace/token without another opaque call.
    5. For cleanup mode \(M\in\{\mathrm{return},\mathrm{discard}\}\), dense mode calls \((b,\bot)\gets\) T-RAW\((\mathcal T[1],p,M,\tau)\). Correction RETURN calls \((b,p\prime)\gets\) P-CAP\((\mathcal T,r,\mathrm{inverse})\); correction DISCARD erases its bounded token at the endpoint. Consume the parent link after its child.
    6. STEP's exact label/slot catalogue remains U-CATALOG; it must preserve this dense/capped distinction.

    What to prove

    Open proof obligation · §9.2

    Give the finite transition and field catalogue for the terminal programs. Check all presence, motion, return, discard, and failure cases, including synthetic states admitted to a probe.
