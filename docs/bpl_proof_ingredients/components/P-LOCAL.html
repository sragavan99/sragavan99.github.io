    Physical routine · Both modes

    P-LOCAL
    Pre-incoming row functions

    Manuscript: Algorithm P-LOCAL, §6.2 Assemble final values and ports, p. 15.

    Input and output

    Explicit interface · Pre-incoming row functions

    \(\Call{P-LOCAL}(\mathcal T,p,\mathrm{kind},t)\longrightarrow(b)\)

    Return a digit of the specified local pre-incoming quantity: witness \(I\), preparation, pilot score, or main prevalue. The first three have scale one; main prevalue has scale \(H_*\). The denominator uses this owner's completed second coordinate before gating, not a fresh preparation call.

    State and cost. Port, kind, fixed expression path and bounded pending digits; each endpoint mask is a restoring visit. No completed coordinate before gating is retained.

    Algorithm

    Requires. Correct owner/kind combination; fixed ranges and scale at every expression node.

    1. \((v)\gets\) P-CLASS\((\mathcal T,p,A_I\text{ for }I\text{, else }A)\); if \(v=0\), return zero.
    2. Set \(s=\varnothing,a=\bot\) for the local expression. Repeat \((s\prime,o)\gets\) P-NUMSTEP\((E_{\rm local},t,\mathrm{digit},s,a)\); set \(s=s\prime\).
    3. For coordinate before gating leaves call \((a)\gets\) P-RAWNUM\((\mathcal T[1],p,\mathrm{coordinate}(\nu),j)\), using the explicit scale adapter in \(E\).
    4. For rank leaves call \((a)\gets\) P-RAWRANK\((\mathcal T,k_{\rm row},j)\).
    5. For the narrow mask call \((u,a)\gets\) P-VISITRAW\((\mathcal T[1],p,\mathrm{HIT}(\mathsf T,\tau,t_{\rm suffix}))\); a failed visit supplies zero.
    6. On DONE\((b)\) erase the numerical state and return \(b\).

    What to prove

    Open proof obligation · §6.2

    Show that the fixed classes cover the gated support, that the cap deletes only zero gated values, and that each query agrees with the corresponding finite test or value. Check that successful pairs are inverse and that failure and cleanup restore all required state.
