    P-TOUR
    Reversible contour around one success halt

    Manuscript: Algorithm P-TOUR, §10.1 Traverse a terminal computation graph, p. 40.

    Input and output

    Explicit interface · Reversible contour around one success halt

    \(\Call{P-TOUR}(G,\mathrm{direction})\longrightarrow(\mathrm{mark})\)

    \(G\) is the current graph/incidence state in the component of one specified success halt, with a sentinel at that halt. Return at the next canonical initial or sentinel in the requested contour direction. The graph state and cursor move together; no initial endpoint copy is retained.

    State and cost. One continuously allocated graph state and bounded incidence token; no second destination or graph copy in the wrapper.

    Algorithm

    Requires. Finite deterministic graph, total ordered PROBE access and a genuine halt component.

    1. First scan the finite incidence alphabet with \((b,e)\gets\) P-PROBE\((G,i,\mathrm{TEST})\). If no edge exists, return the isolated success sentinel, in either direction. Restore the starting incidence label after this existence scan. For forward motion, scan cyclically from it until the next present incidence.
    2. For forward direction only, \((b,e)\gets\) P-PROBE\((G,i,\mathrm{CROSS})\); update the incidence to its opposite label.
    3. For reverse direction, first \((b,e)\gets\) P-PROBE\((G,i,\mathrm{CROSS})\); update to the opposite label, then scan cyclically backward with \((b,e)\gets\) P-PROBE\((G,i,\mathrm{TEST})\) until the previous present incidence.
    4. Repeat until the complete canonical-initial format or the success sentinel is reached. Return that mark; an entry tag with nonempty work fields is not a mark.

    What to prove

    Open proof obligation · §10.1

    Show that the admitted incidence rules are consistent, that the contour directions are inverse, and that it visits precisely the required initials. Count the shared graph state and each probe's additional live fields.
