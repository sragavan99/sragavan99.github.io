    Physical routine · Both modes

    P-MATCH
    Compare endpoints under the selected policy

    Manuscript: Algorithm P-MATCH, §9.4 Compare names or fingerprints, p. 36.

    This component has full-space additions. Switch to Full space to show them.

    Input and output

    Explicit interface · Matching two described endpoints

    \(\Call{P-MATCH}(\mathcal T,c_1,c_2)\longrightarrow(b)\)

    The complete task and codes describe two repeatable endpoint visits. An absent endpoint never matches. Exact mode returns equality of the padded injective names and restores the cursor. Its live comparison state consists of two relative codes, one \(O(\log B)\) position counter, one pending bit and finite flags. These costs count in D-RESOURCE. The policy is fixed before the call. Full space The full mode uses the exact branch when \(d>2h_*\) and P-MATCH-HASH otherwise. It returns the policy's equality, which need not be endpoint equality.

    Algorithm

    Input/Output. D-API-P-MATCH. Requires repeatable restoring visits, including absent codes.

    1. \((Q)\gets\) P-REPLAY\((\mathcal T,\mathrm{comparison},0)\). Read the prescribed comparison mode and padded name length \(L_{\rm id}\); erase the reconstruction buffer.
    2. Full space L only: If the full policy selects the short comparison, \((b)\gets\) P-MATCH-HASH\((\mathcal T,c_1,c_2)\) and return \(b\).
    3. Set \(b=1\). For \(i=0,\ldots,L_{\rm id}-1\), call \((u,x)\gets\) P-VISITPOOL\((\mathcal T,c_1,\mathrm{READ\!\!\!-ID}(i))\), then \((v,y)\gets\) P-VISITPOOL\((\mathcal T,c_2,\mathrm{READ\!\!\!-ID}(i))\).
    4. Set \(b\gets b\wedge u\wedge v\wedge(x=y)\); erase \(x,y,u,v\) before the next position. Finish the loop even after a mismatch.
    5. Return \(b\) at the starting cursor.

    Distinct callees: 2 in exact mode; 3 over both modes.

    What to prove

    Open proof obligation · §9.4

    Establish the predicate returned in each mode, restoration for arbitrary initial shared bits, and the retained fields at each visit. Analyze collision-induced changes on the logical side using Section §8.3.
