    P-PROBE
    Successor and predecessor access to a terminal program

    Manuscript: Algorithm P-PROBE, §10.1 Traverse a terminal computation graph, p. 39.

    Input and output

    Explicit interface · Successor and predecessor access to a terminal program

    \(\Call{P-PROBE}(G,i,\mathrm{mode})\longrightarrow(b,e)\)

    \(G\) is one frozen raw graph view; \(i\) is a finite ordered incidence/certificate token. Modes TEST and CROSS inspect or cross one edge. TEST restores cursor and graph even after a paired candidate is rejected. CROSS repeats the validated transition and commits only its bounded edit after lower work is erased. This interface is conditional on the missing five STEP catalogues.

    State and cost. Frozen raw view, bounded virtual edit and restoration portal, plus one disjoint lower arena. All raw copies and locators must fit E-CATALOG/E-STACK; no depth-multiplied copied stack.

    Algorithm

    Requires. Finite STEP catalogues, complete-link validation and all-input local bounds: unresolved U-CATALOG.

    1. Construct the candidate predecessor/successor virtual view by the bounded edit encoded by \(i\); reject malformed edits or incomplete links by finite scans.
    2. Select the active handler and call exactly one of \((b,e)\gets\) T-RAW\((\mathcal T,p,\mathrm{STEP},G_i)\), \((b,e)\gets\) T-DESCRIPTOR\((\mathcal T,c,\mathrm{STEP},G_i)\), \((b,e)\gets\) T-INTRINSIC\((\mathcal T,c,\mathrm{STEP},G_i)\), \((b,e)\gets\) T-FINAL\((\mathcal T,p,\mathrm{STEP},G_i)\), or \((b,e)\gets\) T-SCORE\((\mathcal T,p,\mathrm{STEP},G_i)\).
    3. The selected STEP contract must validate both restoration directions before motion, recompute its bounded answer/token, and restore using the actual token on rejection.
    4. Compare every produced field with the frozen target by a finite scan; reject unless the normalized certificate also equals \(i\).
    5. TEST returns the bit after restoration. CROSS repeats the same accepted STEP in crossing mode, erases its opaque arena, then installs its bounded edit and returns the opposite incidence.
    6. No candidate may guess an erased word or copy an opaque child stack. Until U-CATALOG is supplied, these are specified obligations, not executable incidence rules.

    What to prove

    Open proof obligation · §10.1

    Show that the admitted incidence rules are consistent, that the contour directions are inverse, and that it visits precisely the required initials. Count the shared graph state and each probe's additional live fields.
