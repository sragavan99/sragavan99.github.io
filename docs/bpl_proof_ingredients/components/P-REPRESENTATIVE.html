    Physical routine · Both modes

    P-REPRESENTATIVE
    Choose representatives without losing arrivals

    Manuscript: Algorithm P-REPRESENTATIVE, §8.1 Group arrivals under the chosen policy, p. 24.

    Input and output

    Explicit interface · Choose representatives without losing arrivals

    \(\Call{P-REPRESENTATIVE}(\mathcal T,c)\longrightarrow(b)\)

    Return whether pool code \(c\) is an old representative or the first valid new record in a equivalence class without an earlier record. Old representatives are kept separately even when the policy identifies their endpoints. This test does not decide whether a new arrival is added numerically.

    State and cost. Candidate, scan index and finite flag use \(O(d)\) bits. Old calls increase slack to \(2d\) and are suppressed at the top.

    Algorithm

    Requires. Fixed pool order and comparison policy.

    1. For an old code, return zero at the top; otherwise \((b)\gets\) P-RAWNUM\((\mathcal T[2d],p,\mathrm{presence},0)\) and return \(b\).
    2. For a new code, \((v)\gets\) P-VALID\((\mathcal T,c)\); if \(v=0\), return zero.
    3. Set \(b=1\). For each earlier pool code \(h<c\), \((v)\gets\) P-MATCH\((\mathcal T,c,h)\); if \(v=1\) set \(b=0\).
    4. Finish the entire scan and return \(b\).

    What to prove

    Open proof obligation · §8.1

    Prove that the physical scan selects the same representatives and adds the same signed operands in the fixed order, for the selected policy.
