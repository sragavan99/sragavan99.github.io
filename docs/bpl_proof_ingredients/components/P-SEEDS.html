    P-SEEDS
    Enumerate exactly the root conditional law

    Manuscript: Algorithm P-SEEDS, §12.1 Evaluate one trial for each admitted seed, p. 46.

    Input and output

    Explicit interface · Enumerate exactly the root conditional law

    \(\Call{P-SEEDS}(\rho,c)\longrightarrow(\sigma,c^+,b)\)

    \(c\) is the next fixed-length encoding index, initially zero. Return the next admitted seed \(\sigma\), its successor index \(c^+\), and \(b=1\); return \((\bot,\mathrm{end},0)\) when exhausted. Only channel 0 is conditioned at \(z_L\). The exact configuration has no auxiliary bits. Every valid encoding is emitted once; any auxiliary bit-string multiplicity is preserved.

    State and cost. One \(O(B)\) encoding and inclusive frontier; pure scratch erased. The consumer owns the frontier between calls.

    Algorithm

    Requires. \(0\le c\le2^{s(\rho)}\); setup supplies the fixed encoding length.

    1. For encoding indices \(i=c,\ldots,2^{s(\rho)}-1\), decode three affine channel seeds and the auxiliary bit string declared by \(\rho\) (empty in the exact configuration).
    2. Skip out-of-range field coordinates and any zero slope vector.
    3. \((b)\gets\) P-MEMBER\((\sigma,0,z_L,f_L)\).
    4. If \(b=1\), return \((\sigma,i+1,1)\).
    5. Return \((\bot,2^{s(\rho)},0)\).

    What to prove

    Open proof obligation · §12.1

    Check that enumeration realizes the single conditioned law in D-ROOTLAW and that each trial implements the fixed stream and grid truncation.
