    Logical routine · Both modes

    L-AVERAGE
    Average successive improvements

    Manuscript: Algorithm L-AVERAGE, §7.2 Average differences and expose ordered arrivals, p. 20.

    Input and output

    Explicit interface · Average successive improvements

    \(\Call{L-AVERAGE}(F,H,G,M,c)\longrightarrow(\Delta,J)\)

    \(F_r(\sigma)\) is the materialized family at budget \(r\), including its contributing records and canonical expressions, with \(F_0=0\). \(H\) gives the endpoint conditions for each output slice and the public fixed-bit mask. \(G\) specifies the D-SLOTS action. Return the aggregate increment \(\Delta\) in each dyadic group, zero outside \(H\). For a row task also return \(J\), the ordered, signed arrival records for each group, seed, and source. Each record includes its complete D-DESCRIPTOR code, endpoint, and weighted expression. The full code order fixes the order within a row. Retain valid zero contributions and distinct codes with the same endpoint or effective seed. For vectors the aggregate is scalar at each source and the record-list output is empty.

    State and cost. Complete finite arrays and explicit word and record lists. The caller provides all queried lower-budget values.

    Algorithm

    Requires. Fixed legal \(H,G\) and integer cost \(c\ge1\); the finite seed encoding domain is explicit.

    1. For each output slice, initialize its kernel \(K\), aggregate arrays, and record lists to zero or empty, then do the following.

      1. For every admitted seed \(\sigma\) and one-letter variant \(w\), call \((\sigma',b,\omega)\gets\) P-WORD\((\sigma,H,w,\mathrm{TEST})\). Add \(\omega\) to \(K_{\sigma,\sigma'}\) when \(b=1\).
      2. For \(r=1,\ldots,M-c\), set \(h=M-r\) and choose the group \(d\) with \(d\le h<2d\). Form the column \(v=F_r-F_{r-1}\). Apply \((v')\gets\) L-MATMUL\((K,v)\) for \(\ell_{\rm mix}h\) steps, replacing \(v\) by \(v'\) each time. Add \(v\) to group \(d\).
      3. For a row, expand each of those walk sums. At budget \(r\) and seed \(\sigma\), enumerate every length-\(\ell_{\rm mix}(M-r)\) variant \(w\) and call \((\sigma',b,\omega)\gets\) P-WORD\((\sigma,H,w,\mathrm{TEST})\). For a passing variant, use the present records in \(F_r(\sigma')\) with weight \(\omega\) and in \(F_{r-1}(\sigma')\) with weight \(-\omega\). Attach the corresponding code, sign, and weighted expression to each record in group \(d\).
    2. Return \(\Delta\) and \(J\) with row records ordered by complete code and with zero aggregates and empty lists outside the slice.

    What to prove

    Open proof obligation · §7.2

    Identify the finite average with the valid word expansion and bound its bias and centered error. Verify that the physical descriptors give the same ordered records, including valid zero contributions.
