    P-INTERMEDIATERANK
    Rank the row before compression

    Manuscript: Algorithm P-INTERMEDIATERANK, §8.2 Choose a default and retain exceptions, p. 26.

    Input and output

    Explicit interface · Rank the row before compression

    \(\Call{P-INTERMEDIATERANK}(\mathcal T,\mathrm{kind},t)\longrightarrow(b)\)

    Return a digit of the magnitude rank \(n_d\) or first-coordinate rank \(k_{\rm row}\), at scale \(H_d\). The numerical list has one slot per pool code plus \(k\) copies of the old default. Nonrepresentatives also supply that default. These added operands are not graph ports.

    State and cost. Rank/list indices \(O(d)\) plus numerical continuation; default and real operand phases share the same scratch. Old prefix is never called at the top.

    Algorithm

    Requires. All nondefault intermediate values are represented; nonnegative old default.

    1. Choose \(k=n_d\) for magnitude or \(k=k_{\rm row}\) for coordinate one; start the rank expression state \(s\). Set \(s=\varnothing,a=\bot\).
    2. Repeat \((s',o)\gets\) P-NUMSTEP\((E_{\rm rank},t,\mathrm{digit},s,a)\); set \(s=s'\).
    3. For a pool REQUEST\((c,j)\), \((v)\gets\) P-REPRESENTATIVE\((\mathcal T,c)\); if \(v=1\), \((a)\gets\) P-MERGE\((\mathcal T,c,\mathrm{kind},j)\).
    4. For a nonrepresentative or padding request use zero at the top, otherwise \((a)\gets\) P-RAWNUM\((\mathcal T[2d],0,\mathrm{default},j+\lambda d)\) through the explicit scale adapter.
    5. On DONE\((b)\) erase the state and return \(b\).

    What to prove

    Open proof obligation · §8.2

    Bound the number of retained entries and the distortion of the later row functions. Prove that the physical tests and streams agree with the logical finite certificates, padded operand lists, and ties. A later digit request must leave the chosen list fixed.

    Relationships

    Calls

    Runs another routine at runtime or in the explicit logical reference.

    • P-NUMSTEP Advance a numerical expression without calling its operands Step 2
    • P-REPRESENTATIVE Choose representatives without losing arrivals Step 3
    • P-MERGE Sum all new increments for one representative Step 3
    • P-RAWNUM Row before gating presence, default and coordinate queries Step 4

    Called by

    • P-THRESHOLD Compute the two compression thresholds
