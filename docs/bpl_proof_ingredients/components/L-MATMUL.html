    Logical routine · Both modes

    L-MATMUL
    Multiply explicit rational arrays

    Manuscript: Algorithm L-MATMUL, §A.1 Matrix products and padded ranks, p. 50.

    Input and output

    Explicit interface · Multiply explicit rational arrays

    \(\Call{L-MATMUL}(A,B)\longrightarrow(Z)\)

    \(A\) is an explicitly stored \(r\times s\) rational array and \(B\) an \(s\times t\) rational array; a vector is a one-column array. The result has \(Z_{ij}=\sum_{k=1}^sA_{ik}B_{kj}\). Empty inner dimension gives the zero array.

    State and cost. Input and output arrays plus one rational accumulator; logical resources only.

    Algorithm

    Requires. Compatible finite dimensions.

    1. Allocate an \(r\times t\) zero array \(Z\).
    2. For \(i=1,\ldots,r\) and \(j=1,\ldots,t\), set \(z=0\).
    3. For \(k=1,\ldots,s\), set \(z\gets z+A_{ik}B_{kj}\); store \(Z_{ij}=z\).
    4. Return \(Z\).
