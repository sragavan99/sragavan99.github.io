    Physical routine · Both modes

    P-SETUP
    Validate and choose finite root ranges

    Manuscript: Algorithm P-SETUP, §2.2 Paired base graph and continuation values, p. 6.

    Input and output

    Explicit interface · Validate and choose finite root ranges

    \(\Call{P-SETUP}(x,\eta)\longrightarrow(\rho,\mathrm{ok})\)

    Return \(\rho=(x,n,n_0,z_0,L,N,r,B,M,p,k_{\max},\eta,q,\text{constant tags})\) as immutable root data, or \((\bot,0)\). The input \(x\) remains read-only, represented by access to its actual tape, not copied into \(\rho\). All variable integer fields have \(O(B)\) bits.

    State and cost. A fixed number of \(O(B)\) integers during pure work; scratch is erased before the root evaluator. No recursive estimator call.

    Algorithm

    Requires. Endmarked input; the numerical program constants are fixed, not advice.

    1. Count the actual input length \(n\) and scan every listed record. Reject malformed layers, labels, terminals or indices, using counters saturated at \(n+1\) before arithmetic use.
    2. \((n_0)\gets\) P-BASE\((x,\mathrm{size},0)\); \((z_0)\gets\) P-BASE\((x,\mathrm{start},0)\).
    3. By bounded integer loops choose the least \(L\) with \(8^L\ge48n_0\), set \(N=n_0d_0^L\), and choose the least \(r\ge1\) with \(2^{3r}\ge8N48^3\).
    4. Set padded power-of-two \(B=\Theta(\log(n+2))\), \(M=c(B+L+r)\) and \(k_{\max}\) as in D-TASKS. Compute the maximum legal name/rate bound. In exact mode choose \(q\) by E-ADDRESSES with \(X=C_X(B+L+M+r+2)\); the fixed layout constant \(C_X\) encloses every root allowance and place. In full mode set \(q=1\).
    5. Scan \(p\in[2^{c_pB},2^{c_pB+1}]\); test all divisors \(2,\ldots,\lfloor\sqrt p\rfloor\) by integer division and select the first prime. If the interval is exhausted, return \((\bot,0)\).
    6. Return \((\rho,1)\) only if this prime exceeds every checked bound.

    What to prove

    Open proof obligation · §2.2

    Verify the probability-preserving base conversion, the name convention, and both directions of the port pairing. Check the setup ranges and halting behavior on malformed and zero-layer inputs.
