    T-RAW
    Terminal program for a raw-row port

    Manuscript: Algorithm T-RAW, §9.2 Expose a port and own its return path, p. 33.

    Input and output

    Explicit interface · Terminal program for a raw-row port

    \(\Call{T-RAW}(\mathcal T,p,\mathrm{mode},\tau)\longrightarrow(b,\tau^+)\)

    Public modes are PRESENCE, RETAIN, RETURN and DISCARD. RETAIN moves to a raw port endpoint and returns its owned trace; RETURN consumes that trace and restores; DISCARD consumes it at the endpoint. Failure restores with no trace. STEP is a separate proposed graph-transition mode whose missing label/slot catalogue is U-CATALOG.

    State and cost. Full reserved code \(O(d)\) while selecting, then selected relative code and one terminal link/trace. No opaque child work is copied into the raw graph state.

    Algorithm

    Requires. Complete raw request; trace mode and token must match their originating terminal. RETURN/DISCARD enter their trace branch directly, skipping fresh-request steps.

    1. \((Q)\gets\) P-REPLAY\((\mathcal T,\mathrm{terminal\ request},(p,\mathrm{mode}))\); reject malformed complete requests.
    2. For a fresh visit reserve the entire selected-code slot. \((b)\gets\) P-SELECT\((\mathcal T,p,\mathrm{presence},0)\); if absent erase it and fail. For each bit \(i\), \((c_i)\gets\) P-SELECT\((\mathcal T,p,\mathrm{bit},i)\).
    3. After the code is complete erase selector-only fields. For old code call \((b,\tau_1)\gets\) T-RAW\((\mathcal T[2d],p_{\rm old},\mathrm{retain},\bot)\); for new code call \((b,\tau_1)\gets\) T-DESCRIPTOR\((\mathcal T,c,\mathrm{retain},\bot)\).
    4. RETAIN returns \((1,\tau_1)\) with the parent link. For PRESENCE on an old code, \((b\prime,\bot)\gets\) T-RAW\((\mathcal T[2d],p_{\rm old},\mathrm{return},\tau_1)\); on a new code, \((b\prime,\bot)\gets\) T-DESCRIPTOR\((\mathcal T,c,\mathrm{return},\tau_1)\). Erase the link and return the presence bit.
    5. For cleanup mode \(M\in\{\mathrm{return},\mathrm{discard}\}\), read the trace’ s old/new tag. Call \((b,\bot)\gets\) T-RAW\((\mathcal T[2d],p_{\rm old},M,\tau_1)\) or \((b,\bot)\gets\) T-DESCRIPTOR\((\mathcal T,c,M,\tau_1)\), respectively, before erasing the parent link. A failed fresh child has no trace; erase its empty link and restore.
    6. STEP: U-CATALOG must supply the finite labels, slot shapes and bounded edits for exactly these phases. No completed STEP implementation is claimed here.

    What to prove

    Open proof obligation · §9.2

    Give the finite transition and field catalogue for the terminal programs. Check all presence, motion, return, discard, and failure cases, including synthetic states admitted to a probe.
