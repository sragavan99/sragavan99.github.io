    Physical routine · Both modes

    P-ARRIVAL
    One validated increment value

    Manuscript: Algorithm P-ARRIVAL, §7.2 Average differences and expose ordered arrivals, p. 22.

    Input and output

    Explicit interface · One validated increment value

    \(\Call{P-ARRIVAL}(\mathcal T,c,\nu,t)\longrightarrow(b)\)

    Return a signed digit of one complete signed arrival. Its candidate identity is retained even if another candidate has the same endpoint or effective seed. The canonical zero stream is returned for invalid descriptors and wrong coordinates.

    State and cost. One descriptor and finite validity flag coexist with the numerical child; no second value or endpoint is retained.

    Algorithm

    Requires. Complete owner handle; no cached validity promise is accepted.

    1. \((v)\gets\) P-VALID\((\mathcal T,c)\); if \(v=0\), return zero.
    2. \((b)\gets\) P-INTRINSICVALUE\((\mathcal T,c,\nu,t)\).
    3. Return \(b\) after the intrinsic query restores.

    What to prove

    Open proof obligation · §7.2

    Identify the finite average with the valid word expansion and bound its bias and centered error. Verify that the physical descriptors give the same ordered records, including valid zero contributions.
