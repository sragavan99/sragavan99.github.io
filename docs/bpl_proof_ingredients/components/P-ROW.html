    Physical routine · Both modes

    P-ROW
    Final numerical row query

    Manuscript: Algorithm P-ROW, §6.2 Assemble final values and ports, p. 17.

    Input and output

    Explicit interface · Final numerical row query

    \(\Call{P-ROW}(\mathcal T,p,t)\longrightarrow(b)\)

    Return one digit of the final row value at public scale \(H_*\). Dense bins/scores have only their local factor. Correction preparations multiply by their incoming gate, and correction mains additionally multiply by the detector cutoff. Missing capped ports return zero.

    State and cost. Port, numerical continuation and one actual bounded inverse token; no source identifier or complete left value. The detector child decreases budget by \(c_{\rm col}\).

    Algorithm

    Requires. Complete row task; both directions of the common cap are total.

    1. For a dense owner choose the local-only expression with its scale adapter and skip the cap test; for a correction choose its local/gate/multiplier product.
    2. For a correction only, \((v,r)\gets\) P-CAP\((\mathcal T,p,\mathrm{forward})\); on failure return zero; otherwise \((v',p')\gets\) P-CAP\((\mathcal T,r,\mathrm{inverse})\).
    3. Set \(s=\varnothing,a=\bot\). Drive \((s\prime,o)\gets\) P-NUMSTEP\((E_{\rm row},t,\mathrm{digit},s,a)\), replacing \(s\) by \(s\prime\).
    4. For a local leaf call \((a)\gets\) P-LOCAL\((\mathcal T,p,\mathrm{owner\ kind},j)\).
    5. For a gate or detector leaf, freshly call \((v,r)\gets\) P-CAP\((\mathcal T,p,\mathrm{forward})\). On success call \((a)\gets\) P-INCOMING\((\mathcal T,\mathrm{gate},j)\), or \((a)\gets\) P-VECTOR\((\mathcal T[U_{l,h};\mathsf T,f_l,t_{\rm suffix};m-c_{\rm col}],j)\), as selected by the literal expression; then \((v',p')\gets\) P-CAP\((\mathcal T,r,\mathrm{inverse})\).
    6. A failed visit supplies zero. On DONE\((b)\) return only after all visits have restored.

    What to prove

    Open proof obligation · §6.2

    Show that the fixed classes cover the gated support, that the cap deletes only zero gated values, and that each query agrees with the corresponding finite test or value. Check that successful pairs are inverse and that failure and cleanup restore all required state.
