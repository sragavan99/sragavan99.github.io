    L-PILOT
    Sampled detector and frozen multiplier

    Manuscript: Algorithm L-PILOT, §4.2 Detect crowded correction columns, p. 10.

    Input and output

    Explicit interface · Sampled detector and frozen multiplier

    \(\Call{L-PILOT}(C,f,\Omega,K)\longrightarrow(g,u)\)

    \(\Omega\) explicitly lists the independent channel seeds, their hit bits at every vertex, and their uniform multiplicities. This call returns all exact detector values and the final column multiplier. Every expectation below is computed by summing over the indicated nonempty sublist, including duplicate encodings.

    State and cost. All pilot matrices, seed tables and detector arrays may be stored. Finite rounds, seeds, vertices and ranks ensure termination.

    Algorithm

    Requires. Finite sampler table with positive one-hit probabilities; legal rank constants.

    1. Set \(\widehat E=0\) and \(u_{0,y}=0\).

    2. In each round \(i=1,\ldots,K\) do the following.

      1. \((Z)\gets\) L-MATMUL\((\widehat E,C)\). Set \(G=C+Z\).
      2. For every seed \(\sigma\) and row \(x\), form \(v=(G_{xz}/f:Y_f(z)=1)\); \((s)\gets\) L-RANK\((v,k_{\rm row},0)\); set \(r_x(\sigma)=\rho(s)\).
      3. For every \((\sigma,y)\) form \(v=(\phi(G_{xy}/f)r_x(\sigma):X_f(x)=1)\); \((b_{\sigma,y})\gets\) L-RANK\((v,j_{\rm det},0)\).
      4. For each \(y\), sum \(b_{\sigma,y}\) over \(Y_f(y)=1\) and divide by that sublist's length to obtain \(u_{i,y}\).
      5. Scan \(h=1,\ldots,i\) for the largest \(u_{h,y}\); set \(\widehat g_{i,y}=\gamma(\max_hu_{h,y})\) and \(\widehat E_{xy}=fQ(G_{xy}/f)\widehat g_{i,y}\).
    3. Return \((\widehat g_K,u)\) and discard \(\widehat E\).

    What to prove

    Open proof obligation · §4.2

    Show that each enabled column has a bounded number of substantial candidates at its scale, and that the columns requiring copies can be counted from the total incidence bound.
