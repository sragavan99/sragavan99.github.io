    Physical routine · Both modes

    P-VISITPOOL
    Visit one old or new representative and return

    Manuscript: Algorithm P-VISITPOOL, §9.3 Visit an endpoint and perform one action, p. 35.

    Input and output

    Explicit interface · Visit one old or new representative and return

    \(\Call{P-VISITPOOL}(\mathcal T,c,\alpha)\longrightarrow(b,v)\)

    \(c\) is an old/new pool code at slack \(d\). Return presence \(b\) and the bounded action answer \(v\); on absence return \((0,0)\). Success visits its endpoint, executes only the declared endpoint action, and returns to the original cursor. The terminal trace is consumed on every branch.

    State and cost. Pool code \(O(d)\), finite mode/action and answer; one child trace under the signed boundary contract. Failure retains no trace.

    Algorithm

    Requires. Completed pool code and bounded endpoint action.

    1. Decode the old/new tag and reject holes; old codes are absent at the top group.
    2. For an old code, \((b,\tau)\gets\) T-RAW\((\mathcal T[2d],c,\mathrm{retain},\bot)\); for a new code, \((b,\tau)\gets\) T-DESCRIPTOR\((\mathcal T,c,\mathrm{retain},\bot)\).
    3. If \(b=0\), return \((0,0)\) after the callee's restoring failure.
    4. \((v)\gets\) P-ENDPOINT\((\mathcal T,\alpha)\).
    5. For an old code call \((b\prime,\bot)\gets\) T-RAW\((\mathcal T[2d],c,\mathrm{return},\tau)\); for a new code call \((b\prime,\bot)\gets\) T-DESCRIPTOR\((\mathcal T,c,\mathrm{return},\tau)\). Each consumes its trace and restores the source.
    6. Return \((1,v)\) even when \(v=0\).

    What to prove

    Open proof obligation · §9.3

    Prove that the actions are repeatable at the selected endpoint and that their paths and cleanup meet the restoration contract.
