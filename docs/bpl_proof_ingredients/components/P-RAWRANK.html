    Physical routine · Both modes

    P-RAWRANK
    Rank the completed row before gating

    Manuscript: Algorithm P-RAWRANK, §6.2 Assemble final values and ports, p. 15.

    Input and output

    Explicit interface · Rank the completed row before gating

    \(\Call{P-RAWRANK}(\mathcal T,k,t)\longrightarrow(b)\)

    Return a digit of the completed raw first-coordinate rank at final slack 1, using \(k\) additional default operands. The raw port alphabet has fixed size \(2^{c_2}\). Final gates, column caps and detector multipliers are not consulted.

    State and cost. Constant-size port/rank indices and numerical state; all operands at final slack. No stored list.

    Algorithm

    Requires. \(k\) is one of the fixed local ranks; completed raw representation.

    1. Start the finite padded-rank expression in an empty numerical state. Set \(s=\varnothing,a=\bot\).
    2. Repeat \((s',o)\gets\) P-NUMSTEP\((E_{\rm rawrank},t,\mathrm{digit},s,a)\); set \(s=s'\).
    3. For each port operand, \((v)\gets\) P-RAWNUM\((\mathcal T[1],p,\mathrm{presence},0)\); on success \((a)\gets\) P-RAWNUM\((\mathcal T[1],p,\mathrm{coordinate}(1),j)\).
    4. For absent/padding operands, \((a)\gets\) P-RAWNUM\((\mathcal T[1],0,\mathrm{default}(1),j)\).
    5. On DONE\((b)\) erase state and return \(b\).

    What to prove

    Open proof obligation · §6.2

    Show that the fixed classes cover the gated support, that the cap deletes only zero gated values, and that each query agrees with the corresponding finite test or value. Check that successful pairs are inverse and that failure and cleanup restore all required state.
