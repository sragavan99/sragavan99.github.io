    L-ASSEMBLE
    Assemble final tables from completed row before gatings

    Manuscript: Algorithm L-ASSEMBLE, §6.2 Assemble final values and ports, p. 14.

    Input and output

    Explicit interface · Assemble final tables from completed row before gatings

    \(\Call{L-ASSEMBLE}(\mathcal T,C,z,O,\eta)\longrightarrow(R)\)

    \(C,z,O\) are completed raw arrays, defaults and lists for all rows of one task. Return final values and the fixed outgoing relation. This call performs no further raw-row construction. It may compute the strictly lower-budget detector vectors needed by a correction main.

    State and cost. Complete raw arrays, incoming lists and detector arrays; finite ranks and lower-budget calls.

    Algorithm

    Requires. Completed row before gatings; preparation, main, score and vector owner cases are distinct.

    1. For a vector return its clipped scalar and no ports immediately; the remaining steps are row cases.
    2. For each row, \((s_x)\gets\) L-RANK\(((C^1_{xy}:y\text{ on the broad hit}),k_{\rm row},z_x)\).
    3. For each class test, \((N_v)\gets\) L-CERT\((E_{C^1/H_1},P_*)\); \((N_s)\gets\) L-CERT\((E_{s/H_1},P_*)\); put \(\widetilde v=H_1N_v2^{-P_*}\) and \(\widetilde s=H_1N_s2^{-P_*}\). Form \(A\) using \(\widetilde v>3\theta/8\), \(\widetilde s<\theta/200\), and \(A_I\) using \(\widetilde v>\theta/10\), \(\widetilde s<\theta/40\), together with the broad hit.
    4. For each correction column, form its \(I_\theta(C^1_{xy},s_x)\) list; \((r_y)\gets\) L-RANK\((v,k_c,0)\); set \(T_y=1-\chi_{1/4,1/2}(r_y)\). Count \(A\) entries and delete the whole column when the count exceeds \(k_c\).
    5. For each required detector round \(h\), \((U_h)\gets\) L-ESTIMATE\((\mathcal T[U_{l,h};\mathsf T,f_l,t;m-c_{\rm col}],\eta)\); set \(g_y=\gamma(\max_hU_h(y))\) by a finite scan.
    6. Set score \(=\phi(v)R(s)\); preparation \(=h(v)R(s)T\); main \(=X_\tau k_O(v)R(s)Tg/\operatorname{clip}_{[1/2,1]}(C^2/\zeta)\), on its final relation. Omitted bin factors equal one.
    7. Return all final values, canonical expressions and fixed relations.

    What to prove

    Open proof obligation · §6.2

    Show that the fixed classes cover the gated support, that the cap deletes only zero gated values, and that each query agrees with the corresponding finite test or value. Check that successful pairs are inverse and that failure and cleanup restore all required state.
