    P-INTRINSICVALID
    Check a candidate before outer wrap tests

    Manuscript: Algorithm P-INTRINSICVALID, §9.2 Expose a port and own its return path, p. 30.

    Input and output

    Explicit interface · Check a candidate before outer wrap tests

    \(\Call{P-INTRINSICVALID}(\mathcal T,c)\longrightarrow(b)\)

    Return whether the descriptor has an intrinsic port, before its outer hit/wrap checks. The cursor and shared mutable registers restore on both answers. Scalar detector and direct-reward records are present after their local checks even when their numerical value is zero.

    State and cost. Complete descriptor \(O(d)\), finite case, stable LEFT handle and actual bounded token; no old source address. All replay scratch is erased before motion.

    Algorithm

    Requires. Completed descriptor and restoration-safe child portals.

    1. \((Q)\gets\) P-REPLAY\((\mathcal T,\mathrm{children},c)\); reject INVALID and nonbase zero-budget records.
    2. For Base, \((b)\gets\) P-BASE\((x,\mathrm{presence},Q.p)\); return \(b\).
    3. For direct, signal, subtraction or copy, remove the known source copy symbol if needed; \((b,\bot)\gets\) T-FINAL\((Q.\mathcal T,Q.p,\mathrm{presence},\bot)\); restore that symbol and return \(b\).
    4. For a product, \((b,r)\gets\) P-CAP\((Q.L,Q.p_1,\mathrm{forward})\); on failure return zero.
    5. At the midpoint, \((v,\bot)\gets\) T-FINAL\((Q.R,Q.p_2,\mathrm{presence},\bot)\); then \((b',p')\gets\) P-CAP\((Q.L,r,\mathrm{inverse})\) and return \(v\).
    6. For detector/direct reward return one; for product reward use the same left forward/inverse pair without testing the right vector's value.

    What to prove

    Open proof obligation · §9.2

    Give the finite transition and field catalogue for the terminal programs. Check all presence, motion, return, discard, and failure cases, including synthetic states admitted to a probe.
