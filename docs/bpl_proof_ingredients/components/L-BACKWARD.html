    L-BACKWARD
    Exact continuation values

    Manuscript: Algorithm L-BACKWARD, §2.2 Paired base graph and continuation values, p. 5.

    Input and output

    Explicit interface · Exact continuation values

    \(\Call{L-BACKWARD}(S,e)\longrightarrow(p)\)

    An explicitly stored rational strictly forward matrix \(S\) and terminal indicator \(e\) determine one rational vector \(p\). The result is the complete continuation vector, not an entry oracle. Repeated labelled edges have already been added to the corresponding matrix entry.

    State and cost. Full vector and exact rational accumulator; no bit-space bound. Both finite loops decrease their remaining counts.

    Algorithm

    Requires. \(S\ge0\), \(S\mathbf1\le\mathbf1\), terminal rewards only.

    1. Set every coordinate of \(p\) to zero.
    2. For \(x\) in reverse vertex order, set \(v=e(x)\).
    3. For each \(y>x\), update \(v\gets v+S_{xy}p(y)\); then set \(p(x)=v\).
    4. Return \(p\).

    What to prove

    Open proof obligation · §2.2

    Verify the probability-preserving base conversion, the name convention, and both directions of the port pairing. Check the setup ranges and halting behavior on malformed and zero-layer inputs.
