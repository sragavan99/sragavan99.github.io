    Physical routine · Both modes

    P-VISITRAW
    Visit a final raw-row port and return

    Manuscript: Algorithm P-VISITRAW, §9.3 Visit an endpoint and perform one action, p. 36.

    Input and output

    Explicit interface · Visit a final raw-row port and return

    \(\Call{P-VISITRAW}(\mathcal T,p,\alpha)\longrightarrow(b,v)\)

    Visit a port of the current raw prefix, execute the bounded action, and return. This interface never silently changes slack to \(2d\). Missing ports return \((0,0)\) with no action and no motion.

    State and cost. Raw ordinal, finite action and answer plus one counted trace; all temporary fields are erased on return.

    Algorithm

    Requires. Raw-prefix task; action allowed by P-ENDPOINT.

    1. \((b,\tau)\gets\) T-RAW\((\mathcal T,p,\mathrm{retain},\bot)\). If \(b=0\), return \((0,0)\).
    2. \((v)\gets\) P-ENDPOINT\((\mathcal T,\alpha)\).
    3. \((b',\bot)\gets\) T-RAW\((\mathcal T,p,\mathrm{return},\tau)\).
    4. Return \((1,v)\).

    What to prove

    Open proof obligation · §9.3

    Prove that the actions are repeatable at the selected endpoint and that their paths and cleanup meet the restoration contract.
