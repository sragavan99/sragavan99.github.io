    P-SELECT
    Regenerate a retained code one bit at a time

    Manuscript: Algorithm P-SELECT, §8.2 Choose a default and retain exceptions, p. 28.

    Input and output

    Explicit interface · Regenerate a retained code one bit at a time

    \(\Call{P-SELECT}(\mathcal T,p,\mathrm{mode},i)\longrightarrow(b)\)

    Return presence of retained ordinal \(p<n_d\), or bit \(i\) of its selected pool code. The selector uses one fixed finite test independent of later value precision. A missing ordinal returns zero. The caller must reserve the entire returned code before asking for any bit.

    State and cost. Two \(O(d)\) indices, inclusive count, fixed-place loop markers, one pending digit and a bounded sign. The full selected code is owned by the caller, not hidden here.

    Algorithm

    Requires. Fixed canonical streams and selector margin hypotheses; \(0\le p<n_d\).

    1. Set passing count \(h=0\), found bit \(b=0\), and fixed place \(P=(\lambda+c_1)d+8\).
    2. For each pool code \(c\) in order, \((v)\gets\) P-REPRESENTATIVE\((\mathcal T,c)\); skip its numerical test only when \(v=0\).
    3. For a representative set \(z=0\). For \(j=0,\ldots,P\), call \((a_j)\gets\) P-MERGE\((\mathcal T,c,\mathrm{size},j)\), then \((b_j)\gets\) P-THRESHOLD\((\mathcal T,\mathrm{u},j)\); update \(z\gets2z+2a_j-3b_j\), retaining \(|z|\le30\) or an absorbing sign \(\pm31\).
    4. After all places, pass iff the sign is positive, rejecting equality. If passing and \(h=p\), set \(b\) to one in presence mode or to code bit \(i\) in bit mode. Increment \(h\) on every pass.
    5. Finish every pool code and return \(b\).

    What to prove

    Open proof obligation · §8.2

    Bound the number of retained entries and the distortion of the later row functions. Prove that the physical tests and streams agree with the logical finite certificates, padded operand lists, and ties. A later digit request must leave the chosen list fixed.
