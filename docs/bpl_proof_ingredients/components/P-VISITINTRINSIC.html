    Physical routine · Both modes

    P-VISITINTRINSIC
    Visit an intrinsic candidate for its deferred tests

    Manuscript: Algorithm P-VISITINTRINSIC, §9.3 Visit an endpoint and perform one action, p. 35.

    Input and output

    Explicit interface · Visit an intrinsic candidate for its deferred tests

    \(\Call{P-VISITINTRINSIC}(\mathcal T,c,\alpha)\longrightarrow(b,v)\)

    Visit the intrinsic endpoint of a descriptor before its outer owner wrap tests. Return presence and the action bit, restoring the cursor. This is needed because destination wrap validity can be tested only after the destination is known.

    State and cost. One \(O(d)\) descriptor, finite action and answer, plus the terminal-owned trace. No other query survives or occurs above the trace.

    Algorithm

    Requires. Legal descriptor and a declared original-owner action.

    1. \((b,\tau)\gets\) T-INTRINSIC\((\mathcal T,c,\mathrm{retain},\bot)\). If \(b=0\), return \((0,0)\).
    2. \((v)\gets\) P-ENDPOINT\((\mathcal T,\alpha)\) at the final endpoint, using the original owner's action.
    3. \((b',\bot)\gets\) T-INTRINSIC\((\mathcal T,c,\mathrm{return},\tau)\).
    4. Return \((1,v)\) after the trace and link are erased.

    What to prove

    Open proof obligation · §9.3

    Prove that the actions are repeatable at the selected endpoint and that their paths and cleanup meet the restoration contract.

    Relationships

    Calls

    Runs another routine at runtime or in the explicit logical reference.

    • T-INTRINSIC Terminal schedules for primitive paths Steps 1, 3
    • P-ENDPOINT Read a name bit or test endpoint membership Step 2

    Called by
