    Logical routine · Both modes

    L-ESTIMATE
    One finite estimator, with all structural choices fixed

    Manuscript: Algorithm L-ESTIMATE, §13.1 The complete finite reference, p. 48.

    Input and output

    Explicit interface · One finite estimator, with all structural choices fixed

    \(\Call{L-ESTIMATE}(\mathcal T,\eta)\longrightarrow(R)\)

    \(\mathcal T\) is the complete finite task of D-TASKS; \(\eta\) is the selected comparison policy. Return its complete rational values, expression trees, representative lists and fixed access relations. Numerical output precision is absent. For vector tasks the result has no endpoint list.

    State and cost. Unlimited finite arrays over seeds and vertices. Recursion on \(m\), then finite group/seed/family loops.

    Algorithm

    Requires. Fixed legal parameters, the explicit seed domain and D-SLOTS action; all group costs checked.

    1. Return zero and empty relations if inactive or outside the source hit. Return the explicit reward for active \(W_0\). Otherwise initialize the raw arrays, scalar, and default \(z\) to zero and set the old list \(O=\emptyset\).
    2. For each family and permitted lower budget, call \((F_{\tau,r})\gets\) L-FAMILY\((\mathcal T,\tau,r,\eta)\). Materialize the result at each effective seed used by its average.
    3. For each family call \((\Delta_\tau,J_\tau)\gets\) L-AVERAGE\((F_\tau,H_\tau,G,m,c_\tau)\).

    4. For \(d=D,D/2,\ldots,1\) perform the update for that group. Include the Base term only at \(d=D\).

      1. For rows collect the valid new records in \(J_d\) in complete code order. Call \((W)\gets\) L-GROUP\((O,J_d,z,d,\eta)\), then \((C,z,O)\gets\) L-COMPRESS\((W,z,d)\).
      2. For vectors add the scalar group increment and clamp to \([-R_d,R_d]\).
    5. For a vector put the final scalar in \(C\) with \(z=0\) and \(O=\emptyset\). Call \((R)\gets\) L-ASSEMBLE\((\mathcal T,C,z,O,\eta)\) and return \(R\).
