    Logical routine · Full space only

    L-BLOCK
    Reference calculation for one hash block

    Manuscript: Algorithm L-BLOCK, §8.3 Use an exact reference within a fingerprint block, p. 29.

    Full-space mode only. This component is part of the logarithmic-space evaluator's fingerprint comparison and is not used with exact name comparison.

    Input and output

    Explicit interface · Reference calculation for one hash block

    \(\Call{L-BLOCK}(\mathcal T,b)\longrightarrow(R)\)

    \(\mathcal T\) is a complete logical task including the seed and the actual grouping mode. Return its reference result with exact comparisons throughout block \(b\), including all structural decisions of same-block descendants. Below block \(b\) the actual hash policy remains in force.

    State and cost. Idealized full computation. The policy is fixed for the call; lower budgets provide termination.

    Algorithm

    Requires. \(b=\lfloor m(\mathcal T)/h_*\rfloor\).

    1. Set a policy \(\eta\) that uses exact names at budgets in block \(b\) and the actual rule at lower budgets.
    2. \((R)\gets\) L-ESTIMATE\((\mathcal T,\eta)\).
    3. Return \(R\), including the representative list and fixed access relations.

    What to prove

    Open proof obligation · §8.3

    Prove current-key independence of the reference candidates and bound escaped candidates and propagated child errors. The fixed-pair collision estimate is used only with the stated conditioning.
