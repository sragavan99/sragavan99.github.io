    Physical routine · Both modes

    P-TRIAL
    Evaluate one seed on a fixed grid

    Manuscript: Algorithm P-TRIAL, §12.1 Evaluate one trial for each admitted seed, p. 47.

    Input and output

    Explicit interface · Evaluate one seed on a fixed grid

    \(\Call{P-TRIAL}(\rho,\sigma)\longrightarrow(a)\)

    Return the clipped numerator of the first ten signed digits of the same root reward estimator, using channel 0, suffix empty, source rate \(f_L\), stage \(L\) and budget \(M\). The seed and task do not change between digit requests.

    State and cost. Constant-size digit index and bounded accumulator outside one evaluator call; the \(O(B)\) seed/cursor and any declared auxiliary register are shared once.

    Algorithm

    Requires. \(\sigma\) is a valid seed in the setup range; root hit is enforced by SEEDS.

    1. Set the cursor to \(z_L\); set the integer accumulator \(v=0\) and the root vector tuple \(\mathcal T=(W_L,0,f_L,\emptyset,M,\sigma)\).
    2. For \(j=0,\ldots,9\): \((b_j)\gets\) P-VECTOR\((\mathcal T,j)\); set \(v\gets v+b_j2^{9-j}\).
    3. Return \(a=\min(512,\max(0,v))\).

    What to prove

    Open proof obligation · §12.1

    Check that enumeration realizes the single conditioned law in D-ROOTLAW and that each trial implements the fixed stream and grid truncation.
