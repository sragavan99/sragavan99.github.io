    Physical routine · Both modes

    P-WORD
    Endpoint-independent word variants

    Manuscript: Algorithm P-WORD, §3.2 Walk on the conditioned seed set, p. 8.

    Input and output

    Explicit interface · Endpoint-independent word variants

    \(\Call{P-WORD}(\sigma,H,w,\mathrm{mode})\longrightarrow(\sigma^+,b,\omega)\)

    \(w\) is a complete word/variant description: each of its \(h\) slots carries a 512-letter index and the bounded channel wrap. Return its resulting seed, conjunction of tests in TEST mode, and weight \(\omega=512^{-h}\). RAW replay is endpoint independent. Reverse mode inverts the fixed variant, not an adaptively selected wrap.

    State and cost. Word descriptor \(O(h)\) bits belongs to the caller; reconstructed seed and field scratch are shared and erased before recursive evaluation. The reverse scan restores the seed.

    Algorithm

    Requires. \(h=O(d)\); complete word, legal factor mask and original owner conditions.

    1. Set \(\sigma^+=\sigma\), \(b=1\) and \(\omega=512^{-h}\); reject malformed or unused nonzero fields.
    2. For each letter in forward order, \((\sigma',\bar g_i,b_i)\gets\) P-SEEDSTEP\((\sigma^+,H,g_i,z_i,\mathrm{mode})\); set \(\sigma^+=\sigma'\) and conjoin the defined test bits.
    3. In reverse mode instead scan letters in reverse order and call \((\sigma\prime,\bar g_i,b_i)\gets\) P-SEEDSTEP\((\sigma^+,H,g_i,z_i,\mathrm{inverse})\); replace \(\sigma^+\) by \(\sigma\prime\).
    4. Return \((\sigma^+,b,\omega)\); failed tests retain zero contribution without changing the weight.

    What to prove

    Open proof obligation · §3.2

    For use in the estimator, prove the exact word lift, weight preservation, and identification of the conditional law at each caller.
