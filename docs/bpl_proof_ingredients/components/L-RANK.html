    Logical routine · Both modes

    L-RANK
    Rank with an explicit padding value

    Manuscript: Algorithm L-RANK, §A.1 Matrix products and padded ranks, p. 50.

    Input and output

    Explicit interface · Rank with an explicit padding value

    \(\Call{L-RANK}(v,k,z)\longrightarrow(r)\)

    \(v\) is a finite ordered rational list, \(k\ge1\), and \(z\) is the padding value. Return the \(k\)th largest member of \(v\) with \(k\) additional copies of \(z\). Equal values are ordered by their original list index. Padding is numerical data and never creates a graph port.

    State and cost. Explicit list, two indices, count and scalar comparisons; no physical-space claim.

    Algorithm

    Requires. \(k\) is a positive integer.

    1. Append \(k\) copies of \(z\) to \(v\), obtaining \(v'\).
    2. For each index \(i\), set \(c=0\) and scan all indices \(j\).
    3. Increment \(c\) if \(v'_j>v'_i\), or if \(v'_j=v'_i\) and \(j<i\).
    4. If \(c=k-1\), return \(r=v'_i\).
