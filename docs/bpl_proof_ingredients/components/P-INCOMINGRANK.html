    P-INCOMINGRANK
    Recover an incoming rank from score contours

    Manuscript: Algorithm P-INCOMINGRANK, §10.2 Recover the padded incoming score rank, p. 41.

    Input and output

    Explicit interface · Recover an incoming rank from score contours

    \(\Call{P-INCOMINGRANK}(\mathcal T,\mathrm{kind},t)\longrightarrow(b)\)

    Return a canonical digit of the zero-padded incoming rank: \(k_c\) for incoming-\(I\) or \(j_{\rm det}\) for a pilot detector. At certificate place \(r\), each port is scored by T-SCORE's fixed quantization. The result is the \(k\)th largest quantized score, padded by zero, with all scores in the uncapped relation counted.

    State and cost. One graph-owned score field and cursor, bounded saturated count/direction, four inter-pass bits. The wrapper never copies the graph or completed score.

    Algorithm

    Requires. All legal score sinks admitted; total TOUR access; uncapped source relation.

    1. \((Q)\gets\) P-REPLAY\((\mathcal T,\mathrm{incoming\ graph},\mathrm{kind})\); take its fixed rank \(k\).
    2. For certificate places \(r=t\) and, if \(t>0\), \(r=t-1\), initialize one graph-owned payload \(q=2^r\) at the success sink and count \(c=0\).
    3. At each payload \(q\), make a full contour using repeated \((z)\gets\) P-TOUR\((G,\mathrm{forward})\); increment \(c\) at canonical initials, saturating at \(k\). Finish the contour and return to the same payload/sink.
    4. If \(c<k\) and \(q>0\), decrement this same payload and repeat. At the first \(c=k\), or at zero, record \(N_r=q\bmod16\) and erase the graph region.
    5. Return the signed decode of \(N_t-2N_{t-1}\pmod{16}\), or \(N_0\) at \(t=0\).

    What to prove

    Open proof obligation · §10.2

    Match the quantized ranks and zero padding to the finite reference. The graph owns the score payload and the scan must restore the same destination and payload before it advances.
