    P-RECIPROCAL
    Early-prefix reciprocal requests

    Manuscript: Algorithm P-RECIPROCAL, §11.2 Stream digits through bounded requests, p. 44.

    Input and output

    Explicit interface · Early-prefix reciprocal requests

    \(\Call{P-RECIPROCAL}(F,t,\kappa,s,a)\longrightarrow(s^+,o)\)

    \(F\) names \(x\in[a,b]\subset(0,1]\). Return a certificate residue for \(1/(Cx)\), where the fixed power of two \(C\ge\max(1,2/a,4/a^2)\) is part of the expression. The originating \(t\) is captured for the entire call. The outer client later undoes \(C\) only with a justified scale adapter.

    State and cost. Captured origin, fixed arithmetic path and four residue bits; coefficient rebuild words \(O(t)\) occur only at early requests. The coroutine retains all active primitive states and counts them.

    Algorithm

    Requires. Fixed positive interval and guards; D-NUMRECIPES projection scales and bounded reciprocal depth.

    1. Fix \(k=\lfloor t/2\rfloor+c_r\). A coefficient request rebuilds \(X=\sum_{j=0}^k x_j2^{k-j}\) using \(x_j\gets\mathrm{REQUEST}(x,j)\); keep this prefix only during that request.
    2. For coefficient digits use exact rational division for \(\alpha=2^k/(CX)\) and \(\beta=-2^{2k}/(CX^2)\), including the signed-floor remainder rule. Erase prefix, square, denominator and division words after returning the coefficient digit.
    3. The tail operand returns zero for \(j\le k\) and otherwise emits \(x_j\gets\mathrm{REQUEST}(x,j)\); it retains no coefficient word.
    4. Drive \((s\prime_2,o_2)\gets\) P-AFFINE\((\operatorname{clip}_{[0,1]}(\alpha+v),t+3,\kappa+3,s_2,a_2)\). For its \(v=\beta e\) digit request at \(j\), drive \((s\prime_1,o_1)\gets\) P-MULTIPLY\(((\beta,e),j,4,s_1,a_1)\) and, if \(j>0\), \((s\prime_0,o_0)\gets\) P-MULTIPLY\(((\beta,e),j-1,4,s_0,a_0)\); decode the difference of completed residues. Service their coefficient/tail requests by steps 1–3. New states start empty, answers \(\bot\); retain the originating \(t\).
    5. If their inner certificate is \(R\), return DONE\((\lfloor R/8\rfloor\bmod2^\kappa)\); otherwise return the pending external request and the complete state.

    What to prove

    Open proof obligation · §11.2

    Prove agreement with the finite equations for every primitive and client, including ties and scale shifts. Instantiate the resume transitions, then count the fields across each operand call. For a reciprocal, keep the originating place available while erasing the long early word before a late operand request.
