    Physical routine · Both modes

    P-MERGE
    Sum all new increments for one representative

    Manuscript: Algorithm P-MERGE, §8.1 Group arrivals under the chosen policy, p. 25.

    Input and output

    Explicit interface · Sum all new increments for one representative

    \(\Call{P-MERGE}(\mathcal T,c,\nu,t)\longrightarrow(b)\)

    Return a coordinate or size digit of the intermediate row at pool code \(c\), normalized by \(H_d\). A nonrepresentative has old default in coordinate one and zero in coordinate two. A new representative starts at the old default. Only new arrivals are grouped by the selected equivalence.

    State and cost. One representative code, one arrival frontier \(O(d)\), numerical state and bounded match/digit data. Old-to-new scale shift is charged in the child place; no full old value is stored.

    Algorithm

    Requires. Complete pool code; D-RECIPES gives list length, scale and guard for the full sum.

    1. \((v)\gets\) P-REPRESENTATIVE\((\mathcal T,c)\); choose the coordinate/size expression \(E\) with the appropriate default branch.
    2. Start \(s=\varnothing,a=\bot\); repeat \((s',o)\gets\) P-NUMSTEP\((E,t,\mathrm{digit},s,a)\); set \(s=s'\).
    3. For an OLD request use zero at the top; otherwise \((a)\gets\) P-RAWNUM\((\mathcal T[2d],p_{\rm old},\mathrm{coordinate\ or\ default},j+\lambda d)\), with the explicit scale adapter in \(E\).
    4. For a NEW\((h,j)\) request, \((u)\gets\) P-MATCH\((\mathcal T,c,h)\); if \(u=1\), \((a)\gets\) P-ARRIVAL\((\mathcal T,h,\nu,j)\); otherwise set \(a=0\).
    5. There is one NEW operand for every new code, whether or not it is representative. Never request another old representative's value.
    6. On DONE\((b)\) erase the state and return \(b\).

    What to prove

    Open proof obligation · §8.1

    Prove that the physical scan selects the same representatives and adds the same signed operands in the fixed order, for the selected policy.
