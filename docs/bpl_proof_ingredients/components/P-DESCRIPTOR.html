    P-DESCRIPTOR
    Generate a complete candidate description

    Manuscript: Algorithm P-DESCRIPTOR, §7.2 Average differences and expose ordered arrivals, p. 21.

    Input and output

    Explicit interface · Generate a complete candidate description

    \(\Call{P-DESCRIPTOR}(\mathcal T,c)\longrightarrow(D,b)\)

    Decode one fixed-width candidate code, not an iterator with a hidden consumer. Return its typed fields \(D\) and validity bit \(b\). This checks syntax and owner/family compatibility only; it does not test endpoint presence, hits, wraps or numerical value.

    State and cost. One \(C_{\rm desc}d\)-bit code and finite decode flags; public reconstruction scratch is erased. No graph query.

    Algorithm

    Requires. Dyadic slack in the task range; complete code.

    1. \((Q)\gets\) P-REPLAY\((\mathcal T,\mathrm{descriptor\ bounds},0)\).
    2. Check that \(c\) has exactly \(C_{\rm desc}d\) bits and decode fields in D-DESCRIPTOR order; reject negative zero and nonzero unused fields.
    3. For Base require \(l=0\), \(d=D\), a labelled base port and all word/budget fields zero.
    4. Otherwise require \(d\le h<2d\), \(h\le m-1\), \(\mu=m-h-\epsilon\ge0\), and the displayed family cost at most \(h\).
    5. Check the owner/tag table, copy symbols, ports, scale exponent, used word length and each letter/wrap range.
    6. Return \((D,1)\) if all tests pass, otherwise \((\bot,0)\).

    What to prove

    Open proof obligation · §7.2

    Identify the finite average with the valid word expansion and bound its bias and centered error. Verify that the physical descriptors give the same ordered records, including valid zero contributions.
