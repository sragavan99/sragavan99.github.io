    L-HIERARCHY
    The exact reward hierarchy

    Manuscript: Algorithm L-HIERARCHY, §5.2 Compose the exact stages, p. 12.

    Input and output

    Explicit interface · The exact reward hierarchy

    \(\Call{L-HIERARCHY}(S,e,L,\Omega)\longrightarrow(w_L,z_L)\)

    The seed law and all constants are fixed once for the whole hierarchy. Each new \(\Omega_l\) is the same law evaluated on the new legal names, not a fresh randomness choice. Return the entire final reward and the all-primary descendant of the input start. The explicit input \(\Omega\) covers the finite name universe at every level; \(\Omega_l\) is only its stored subtable for level \(l\).

    State and cost. Logical arrays grow with the copy universe; exactly \(L\) stages. The algorithm is finite, not a low-space evaluator.

    Algorithm

    Requires. Paired base data and the simultaneous stage constants.

    1. Set \((C_0,w_0)=(S,e)\) and let \(z_0\) be the given start.
    2. For \(l=0,\ldots,L-1\), put \(f=16^{-l}\).
    3. \((g,u)\gets\) L-PILOT\((C_l,f,\Omega_l,K)\).
    4. \((E,D,w^+)\gets\) L-CORRECT\((C_l,w_l,f,g,K)\).
    5. \((C_{l+1},w_{l+1},P_l)\gets\) L-SPLIT\((D,w^+,f,u)\); set \(z_{l+1}=z_l0\).
    6. Return \((w_L,z_L)\).

    What to prove

    Open proof obligation · §5.2

    Iterate the projection identity and bound the remaining contribution at the primary copy using the shrinking entry bound and the active-vertex count.
