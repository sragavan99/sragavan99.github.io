    P-SCALARPREFIX
    Scalar prefixes for vector tasks

    Manuscript: Algorithm P-SCALARPREFIX, §7.3 Accumulate detector and reward vectors, p. 22.

    Input and output

    Explicit interface · Scalar prefixes for vector tasks

    \(\Call{P-SCALARPREFIX}(\mathcal T,d,t)\longrightarrow(b)\)

    Return a digit of the vector's clipped scalar prefix at slack \(d\), normalized by \(H_d\). The vector uses every scalar arrival and no endpoint grouping. At the top the old prefix is zero; active \(W_0\) is the exact base reward.

    State and cost. \(O(d)\) descriptor/list frontier plus numerical state; no endpoint list, representative code or retained matrix value.

    Algorithm

    Requires. Vector task and dyadic slack; full-sum normalization valid on all seeds.

    1. For inactive/source-failed tasks return zero. For \(W_0\) use the public reward expression; otherwise use the sum-and-clamp expression \(E_{\rm scalar}\).
    2. Start \(s=\varnothing,a=\bot\) and repeat \((s',o)\gets\) P-NUMSTEP\((E,t,\mathrm{digit},s,a)\); set \(s=s'\).
    3. For an OLD request, supply zero at the top; otherwise \((a)\gets\) P-SCALARPREFIX\((\mathcal T,2d,j+\lambda d)\) through the old-scale adapter.
    4. For a descriptor request \((c,j)\), \((a)\gets\) P-ARRIVAL\((\mathcal T,c,1,j)\), including every sign and zero-valued valid term.
    5. On DONE\((b)\) erase the state and return \(b\).

    What to prove

    Open proof obligation · §7.3

    Prove scalar-prefix correspondence and count the state held across each old-prefix or arrival request.
