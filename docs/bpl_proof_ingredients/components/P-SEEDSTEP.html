    Physical routine · Both modes

    P-SEEDSTEP
    One step of the conditional finite action

    Manuscript: Algorithm P-SEEDSTEP, §3.2 Walk on the conditioned seed set, p. 8.

    Input and output

    Explicit interface · One step of the conditional finite action

    \(\Call{P-SEEDSTEP}(\sigma,H,g,z,\mathrm{mode})\longrightarrow(\sigma^+,g^{-1},b)\)

    The 512 generator slots and conditional-factor layout are fixed in D-SLOTS. Modes RAW and TEST use a fixed wrap \(z\); RAW returns its full-space bijection without testing unknown endpoints, and TEST additionally returns its exact validity bit. Inverse mode uses the inverse affine map of that same fixed variant. Free auxiliary coordinates are selected by the public mask, never by their values.

    State and cost. Pure \(O(B)\) scratch; a returned seed lives only in the shared reconstruction buffer. No estimator query or saved per-frame seed.

    Algorithm

    Requires. \(H\) supplies public box sides and free-bit mask; TEST also supplies the endpoint names.

    1. Decode \(g\) as one of eight factors and one of 64 slots. Identity/absent factors leave the seed unchanged.
    2. For a channel slot obtain its explicit integer elementary matrix \(A\) and translation \(c\) from D-SLOTS; set \(a_1^+=Aa_1\) and \(a_0^+=Aa_0+c+Lz\pmod p\).
    3. In TEST mode compute \(w=a_0+va_1\bmod p\) for the designated endpoint and set \(b=\mathbf1\{w\in[0,L)^4,\ 0\le Aw+c+Lz<L\}\). In RAW mode set \(b=\bot\).
    4. For the auxiliary four-coordinate factor apply \(w\gets Aw+c\bmod2^{\ell_{\rm aux}}\); for a residual factor flip its designated bit on flip slots. Leave every frozen bit fixed.
    5. In inverse mode apply \(A^{-1}\) and subtract the same \(c+Lz\), or undo the auxiliary action. Return the new seed, inverse slot/variant data and \(b\).

    What to prove

    Open proof obligation · §3.2

    For use in the estimator, prove the exact word lift, weight preservation, and identification of the conditional law at each caller.
