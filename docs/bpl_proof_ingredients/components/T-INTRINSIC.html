    Terminal program · Both modes

    T-INTRINSIC
    Terminal schedules for primitive paths

    Manuscript: Algorithm T-INTRINSIC, §9.2 Expose a port and own its return path, p. 31.

    Input and output

    Explicit interface · Terminal schedules for primitive paths

    \(\Call{T-INTRINSIC}(\mathcal T,c,\mathrm{mode},\tau)\longrightarrow(b,\tau^+)\)

    Return or consume the intrinsic terminal trace of one descriptor. The trace records the family case, known copy symbols, and actual tokens, never the old source address. Scalar families reject endpoint modes. Product success owns one left token and one right trace.

    State and cost. \(O(d)\) descriptor, finite family/copy tags, one bounded left token and one right trace. The actual source vertex is never retained.

    Algorithm

    Requires. Both directions of every pair are validated before motion; common right tuple independent of old source. RETURN/DISCARD enter their trace branch directly, skipping fresh-request steps.

    1. \((Q)\gets\) P-REPLAY\((\mathcal T,\mathrm{terminal\ children},c)\); reject invalid/zero-budget cases.
    2. Base fresh request: \((z)\gets\) P-BASE\((x,\mathrm{forward},Q.p)\); unpack \(z=(b,r)\). Base RETURN: \((z)\gets\) P-BASE\((x,\mathrm{inverse},r)\); unpack \(z=(b,p\prime)\). DISCARD erases \(r\) at the endpoint.
    3. Direct/signal/subtraction: \((b,\tau_1)\gets\) T-FINAL\((Q.\mathcal T,Q.p,\mathrm{retain},\bot)\). For cleanup \(M\), call \((b,\bot)\gets\) T-FINAL\((Q.\mathcal T,Q.p,M,\tau_1)\).
    4. Copy: remove known \(\alpha\); \((b,\tau_1)\gets\) T-FINAL\((Q.\mathcal T,Q.p,\mathrm{retain},\bot)\); append \(\beta\) on success, otherwise restore \(\alpha\). RETURN removes \(\beta\), calls \((b,\bot)\gets\) T-FINAL\((Q.\mathcal T,Q.p,\mathrm{return},\tau_1)\), then appends \(\alpha\). DISCARD calls \((b,\bot)\gets\) T-FINAL\((Q.\mathcal T,Q.p,\mathrm{discard},\tau_1)\) at the endpoint.
    5. Product: \((b,r)\gets\) P-CAP\((Q.L,Q.p_1,\mathrm{forward})\); on success \((v,\bot)\gets\) T-FINAL\((Q.R,Q.p_2,\mathrm{presence},\bot)\); then \((b',p')\gets\) P-CAP\((Q.L,r,\mathrm{inverse})\).
    6. After successful reconnaissance, \((b,r)\gets\) P-CAP\((Q.L,Q.p_1,\mathrm{forward})\); \((v,\tau_2)\gets\) T-FINAL\((Q.R,Q.p_2,\mathrm{retain},\bot)\). Failure or RETURN calls \((v\prime,\bot)\gets\) T-FINAL\((Q.R,Q.p_2,\mathrm{return},\tau_2)\) if a trace exists, erases its link, then \((b\prime,p\prime)\gets\) P-CAP\((Q.L,r,\mathrm{inverse})\). DISCARD calls \((v\prime,\bot)\gets\) T-FINAL\((Q.R,Q.p_2,\mathrm{discard},\tau_2)\) and erases the left token.
    7. STEP's exact finite edits and restoration-safe portals remain U-CATALOG.

    What to prove

    Open proof obligation · §9.2

    Give the finite transition and field catalogue for the terminal programs. Check all presence, motion, return, discard, and failure cases, including synthetic states admitted to a probe.
