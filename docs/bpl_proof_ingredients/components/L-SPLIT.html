    Logical routine · Both modes

    L-SPLIT
    Weighted node splitting

    Manuscript: Algorithm L-SPLIT, §5.1 Divide the remaining large weights, p. 12.

    Input and output

    Explicit interface · Weighted node splitting

    \(\Call{L-SPLIT}(D,w^+,f,u)\longrightarrow(C^+,w^{++},P)\)

    The input \(u\) is the complete detector array from the pilot. A copied name is \(x\alpha\) with \(0\le\alpha<d_0\). Return complete copied arrays and the projection matrix \(P\); primary copies preserve the old target because their multiplier is one.

    State and cost. Complete copied arrays, with \(d_0\) fixed. Scalar cutoffs use exact rational arithmetic.

    Algorithm

    Requires. \(D,w^+\) are an L-CORRECT result with the matching pilot array and scale.

    1. For each \(x\), scan the detector rounds and let \(v_x=\max_hu_{h,x}\); set \(r_0(x)=1\) and \(r_\alpha(x)=\chi_{1/4,1/2}(v_x)\) for \(\alpha>0\).
    2. For each \(x\alpha,y\beta\), put \(h=\chi_{1/128,1/64}(D_{xy}/f)\) and \(s_\beta=1-(1-d_0^{-1})h\) if \(\beta=0\), otherwise \(h/d_0\).
    3. Set \(C^+_{x\alpha,y\beta}=r_\alpha(x)D_{xy}s_\beta\), \(w^{++}_{x\alpha}=r_\alpha(x)w^+_x\), and \(P_{x\alpha,x}=r_\alpha(x)\); all other entries of \(P\) are zero.
    4. Return \((C^+,w^{++},P)\).

    What to prove

    Open proof obligation · §5.1

    Check the projection identity, the new entry bound, and the count of active copies.
