    P-NUMSTEP
    Advance a numerical expression without calling its operands

    Manuscript: Algorithm P-NUMSTEP, §11.2 Stream digits through bounded requests, p. 45.

    Input and output

    Explicit interface · Advance a numerical expression without calling its operands

    \(\Call{P-NUMSTEP}(E,t,\mathrm{mode},s,a)\longrightarrow(s^+,o)\)

    \(E\) is one of the fixed expressions in D-RECIPES with named operand leaves; mode is DIGIT or CERT\((\kappa)\). START has \(s=\varnothing,a=\bot\); a resumed request receives its single bounded answer \(a\). Return a complete new state and either REQUEST\((\mathrm{leaf},j)\) or DONE\((b)\). DIGIT returns a signed digit; CERT returns a residue. These are different result types.

    State and cost. Complete primitive continuation, expression path, phase and four inter-pass bits belong to the client. No hidden heap or callback stack. Shared public scratch is erased before an external REQUEST.

    Algorithm

    Requires. Closed expression grammar, ranges valid on all seeds, complete resume state and matching answer type.

    1. On START obtain the expression tag/scales and public coefficients through \((Q)\gets\) P-REPLAY\((E.\mathcal T,\mathrm{expression},E.\mathrm{tag})\); explicit logical trees already carry these fields.
    2. For a rational leaf, use its declared signed-floor integer division and return its requested residue or digit. Otherwise choose the root node \(F\); a new primitive state is empty with answer \(\bot\).
    3. Advance the active primitive by \((s\prime_F,o_F)\gets\) P-NODESTEP\((F,t,\kappa,s_F,a_F)\). Save the returned state and inspect its request/done tag.
    4. For a strict-subtree digit request \((E\prime,j)\), drive \((s\prime_c,o_c)\gets\) P-NUMSTEP\((E\prime,j,\mathrm{digit},s_c,a_c)\). Return any external request to the client and resume from its answer; on child DONE pass its digit to the saved parent primitive. An external leaf is returned directly as REQUEST\((\mathrm{leaf},j)\).
    5. CERT returns the completed residue. DIGIT runs the root certificate passes at \(t\) and \(t-1\) sequentially, retaining four bits; at \(t=0\) run one pass. Decode the difference modulo 16 in \([-8,7]\) and return DONE\((b)\).

    What to prove

    Open proof obligation · §11.2

    Prove agreement with the finite equations for every primitive and client, including ties and scale shifts. Instantiate the resume transitions, then count the fields across each operand call. For a reciprocal, keep the originating place available while erasing the long early word before a late operand request.
