    L-FAMILY
    The finite sample expressions

    Manuscript: Algorithm L-FAMILY, §7.1 Form one sample term, p. 18.

    Input and output

    Explicit interface · The finite sample expressions

    \(\Call{L-FAMILY}(\mathcal T,\tau,r,\eta)\longrightarrow(F)\)

    \(\tau\) selects Base, direct, product, subtraction, copy, signal, detector, direct reward or product reward. Return the complete sample array and its ordered contributing records at child budget \(r\). The seed is already the common transformed seed for this sample. The family is zero when \(r\le0\), except the separately inserted Base term.

    State and cost. All child arrays, expressions and provenance records are materialized. Recursion decreases the statistical budget; matrix and rank helpers are finite.

    Algorithm

    Requires. Legal owner/family pair; the parent chooses \(r<m\) and the correct scale cost.

    1. If \(r\le0\) and \(\tau\ne\mathrm{Base}\), return zero with no records.
    2. \((Q)\gets\) P-CHILD\((\mathcal T,\tau,r,\mathrm{all})\); \(Q\) contains the child tuples and scalar coefficients, or INVALID.
    3. For each tuple \(q\) in the returned fixed list, \((R_q)\gets\) L-ESTIMATE\((q,\eta)\); retain its full array and expressions.
    4. For direct/subtraction/signal, multiply the indicated child array by its returned coefficient, entry by entry. For copy, multiply the routed array by the returned copy-detector cutoff at each source.
    5. For a row product or reward product, \((Z)\gets\) L-MATMUL\((A,B)\), where \(A\) is the left child with its midpoint mask and \(B\) the common right child; multiply by the returned coefficient.
    6. For detector, at each destination form the incoming score list and \((F_y)\gets\) L-RANK\((v,j_{\rm det},0)\). For direct reward use the returned lower reward and copy factor.
    7. Return these arrays with separate records for every contributing midpoint/port and the corresponding finite expression trees; Base uses the explicit \(S\) or \(e\) in \(\mathcal T\).

    What to prove

    Open proof obligation · §7.1

    Check each family's term and coefficient against D-ROWFAMILIES or D-VECTORS. Prove the conditional mean and the error transfer from child values. The product bound uses pointwise support counts and the common right tuple.
