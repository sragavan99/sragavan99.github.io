    Physical routine · Both modes

    P-VECTOR
    Final reward or detector vector query

    Manuscript: Algorithm P-VECTOR, §7.3 Accumulate detector and reward vectors, p. 23.

    Input and output

    Explicit interface · Final reward or detector vector query

    \(\Call{P-VECTOR}(\mathcal T,t)\longrightarrow(b)\)

    Return one digit of a reward or detector vector in \([0,1]\), with no port or motion mode. The effective task and seed fix one real value for all digit places. Inactive/source-failed inputs return the canonical zero stream.

    State and cost. One fixed clipping continuation and bounded digit; shared seed, cursor and shared mutable registers are not copied.

    Algorithm

    Requires. Vector owner, legal budget and canonical all-seed numerical ranges.

    1. Reject a nonvector or malformed request with zero; return zero if inactive or source-failed.
    2. For active \(W_0\), choose the pure public reward expression; otherwise choose \(E=\operatorname{clip}_{[0,1]}(H_1\cdot\mathrm{scalarprefix})\). Set \(s=\varnothing,a=\bot\).
    3. Repeat \((s',o)\gets\) P-NUMSTEP\((E,t,\mathrm{digit},s,a)\); set \(s=s'\).
    4. For a scalar-prefix request call \((a)\gets\) P-SCALARPREFIX\((\mathcal T,1,j)\), with the expression's declared scale adapter.
    5. On DONE\((b)\) erase state and return \(b\).

    What to prove

    Open proof obligation · §7.3

    Prove scalar-prefix correspondence and count the state held across each old-prefix or arrival request.
