    Physical routine · Both modes

    P-ENDPOINT
    Read a name bit or test endpoint membership

    Manuscript: Algorithm P-ENDPOINT, §9.3 Visit an endpoint and perform one action, p. 34.

    This component has full-space additions. Switch to Full space to show them.

    Input and output

    Explicit interface · A bounded action at the current endpoint

    \(\Call{P-ENDPOINT}(\mathcal T,a)\longrightarrow(b)\)

    READ-ID\((i)\) returns bit \(i\) of the padded current name (zero outside its public range). HIT\((c,r,s)\) tests channel \(c\) at rate \(r\) after appending suffix \(s\). WRAP\((i)\) tests the specified word variant at this endpoint. The result is bounded, the cursor is unchanged, and pure scratch is erased. These actions make no estimator query. Unknown or malformed actions return zero. Full space READ-KEY and FLIP-KEY delegate to P-ENDPOINT-KEY. Only FLIP-KEY intentionally changes one shared mutable registers cell.

    Algorithm

    Input/Output. D-API-P-ENDPOINT; the action's fields are complete before entry.

    1. \((Q)\gets\) P-REPLAY\((\mathcal T,\mathrm{action},a)\). Reject malformed action fields locally.
    2. For READ-ID\((i)\), read the requested padded bit at the cursor; return it after erasing pure scratch.
    3. For HIT\((c,r,s)\), \((b)\gets\) P-MEMBER\((Q.\sigma,c,\varphi_s(\mathrm{cursor}),r)\); return \(b\).
    4. For WRAP\((i)\), \((\sigma',b,\omega)\gets\) P-WORD\((Q.\sigma,Q.H,Q.w_{\le i},\mathrm{TEST})\); erase \(\sigma'\) and return \(b\).
    5. Full space For READ-KEY or FLIP-KEY, \((b)\gets\) P-ENDPOINT-KEY\((\mathcal T,a)\); return \(b\). Otherwise return zero.

    Distinct callees: 3 in exact mode; 4 over both modes.

    What to prove

    Open proof obligation · §9.3

    Prove that the actions are repeatable at the selected endpoint and that their paths and cleanup meet the restoration contract.
