    Physical routine · Both modes

    P-CHILD
    Construct a child task with explicit field resets

    Manuscript: Algorithm P-CHILD, §7.1 Form one sample term, p. 19.

    Input and output

    Explicit interface · Construct a child task with explicit field resets

    \(\Call{P-CHILD}(\mathcal T,\tau,r,\mathrm{side})\longrightarrow(Q)\)

    This pure constructor returns child task fields and exact scalar coefficients, never an estimator value. The complete output cases are in D-CHILD. A physical caller requests one field or one relative schema at a time; a logical caller may request the full fixed list. Invalid owner/tag/side or negative-stage requests return INVALID before any cursor change.

    State and cost. \(O(B)\) pure reconstruction scratch, erased before any estimator query. Returned physical schema is a relative view into a completed descriptor; its exact marked encoding remains U-CATALOG.

    Algorithm

    Requires. Complete task/descriptor, selected family, legal rates; no estimator access.

    1. Check the owner, family, scale offset, copy symbols and child budget against D-DESCRIPTOR and D-TASKS.
    2. For direct, subtraction or signal, copy the specified parent fields and overwrite owner, round, broad/usage rate and budget with the explicit D-CHILD row.
    3. For product, construct LEFT and RIGHT separately: set roles to \((\mathsf S,\mathsf M,\mathsf T)\) and \((\mathsf M,\mathsf T,\mathsf S)\); RIGHT gets source rate \(f_l\), source suffix empty, usage \(\min(a,b)\), and no old-source or port field.
    4. For copy or reward, require \(l>0\), decrement \(l\), prepend the known source/destination copy symbols to their suffixes, and set the residual route to the destination symbol. Detector children get intrinsic rate \(f_{l-1}\).
    5. For detector, construct the score tuple with roles \((c+1,c,c+2)\), rates all \(f_l\), source suffix empty and destination suffix \(s\).
    6. Compute \(w_b=(b/a)\pi_a/\pi_{\min(a,b)}\) and the other listed rational coefficients from public integers. Return the requested part of \(Q\) and clear scratch.

    What to prove

    Open proof obligation · §7.1

    Check each family's term and coefficient against D-ROWFAMILIES or D-VECTORS. Prove the conditional mean and the error transfer from child values. The product bound uses pointwise support counts and the common right tuple.
