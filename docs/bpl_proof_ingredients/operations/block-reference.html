    Operation · §8.3

    Use an exact reference within a fingerprint block

    Manuscript: §8.3, p. 29.

    This operation has 1 full-space-only component. Switch to Full space to show them.

    Logical reference

    • L-BLOCK Reference calculation for one hash block Full space only

    1 full-space-only component hidden. Switch to Full space to show it.

    For the full-space policy, analyze the change in grouping by an explicit calculation with exact name comparison in the current block. The computations below that block keep their specified comparison policy. This is a reference calculation for the accuracy proof.

    Logical routine · Full space only

    L-BLOCK Reference calculation for one hash block

    \(\Call{L-BLOCK}(\mathcal T,b)\longrightarrow(R)\)

    \(\mathcal T\) is a complete logical task including the seed and the actual grouping mode. Return its reference result with exact comparisons throughout block \(b\), including all structural decisions of same-block descendants. Below block \(b\) the actual hash policy remains in force.
