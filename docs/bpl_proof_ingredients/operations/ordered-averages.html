    Operation · §7.2

    Average differences and expose ordered arrivals

    Manuscript: §7.2, p. 20.

    Logical reference

    • L-AVERAGE Average successive improvements

    Physical queries

    • P-DESCRIPTOR Generate a complete candidate description
    • P-ARRIVAL One validated increment value

    At each lower budget average the difference from the preceding estimate. Earlier differences get longer walks. For a row, the grouped increment has both an aggregate value and an ordered list of contributing records. The list determines first representatives, multiplicities, and finite expression order in the next ingredient.

    Logical routine

    L-AVERAGE Average successive improvements

    \(\Call{L-AVERAGE}(F,H,G,M,c)\longrightarrow(\Delta,J)\)

    \(F_r(\sigma)\) is the materialized family at budget \(r\), including its contributing records and canonical expressions, with \(F_0=0\). \(H\) gives the endpoint conditions for each output slice and the public fixed-bit mask. \(G\) specifies the D-SLOTS action. Return the aggregate increment \(\Delta\) in each dyadic group, zero outside \(H\). For a row task also return \(J\), the ordered, signed arrival records for each group, seed, and source. Each record includes its complete D-DESCRIPTOR code, endpoint, and weighted expression. The full code order fixes the order within a row. Retain valid zero contributions and distinct codes with the same endpoint or effective seed. For vectors the aggregate is scalar at each source and the record-list output is empty.

    Physical routine

    P-DESCRIPTOR Generate a complete candidate description

    \(\Call{P-DESCRIPTOR}(\mathcal T,c)\longrightarrow(D,b)\)

    Decode one fixed-width candidate code, not an iterator with a hidden consumer. Return its typed fields \(D\) and validity bit \(b\). This checks syntax and owner/family compatibility only; it does not test endpoint presence, hits, wraps or numerical value.

    Steps and relationships →

    Physical routine

    P-ARRIVAL One validated increment value

    \(\Call{P-ARRIVAL}(\mathcal T,c,\nu,t)\longrightarrow(b)\)

    Return a signed digit of one complete signed arrival. Its candidate identity is retained even if another candidate has the same endpoint or effective seed. The canonical zero stream is returned for invalid descriptors and wrong coordinates.

    What to prove

    Open proof obligation · §7.2

    Identify the finite average with the valid word expansion and bound its bias and centered error. Verify that the physical descriptors give the same ordered records, including valid zero contributions.
