    Operation · §8.2

    Choose a default and retain exceptions

    Manuscript: §8.2, p. 25.

    Logical reference

    • L-COMPRESS Compress one completed increment group

    Physical queries

    • P-INTERMEDIATERANK Rank the row before compression
    • P-THRESHOLD Compute the two compression thresholds
    • P-COMPRESS One compressed coordinate as a digit stream
    • P-SELECT Regenerate a retained code one bit at a time
    • P-RAWNUM Row before gating presence, default and coordinate queries

    Use the grouped row to compute the two thresholds and the new common default. The compression formula clips each coordinate toward the default. A fixed finite test decides which representatives to retain. The ordered list, default, and coordinate expressions are used by the next prefix or by final assembly.

    Logical routine

    L-COMPRESS Compress one completed increment group

    \(\Call{L-COMPRESS}(W,z,d)\longrightarrow(C,z^+,O^+)\)

    \(W\) is the complete represented row after grouping, including a canonical expression for each coordinate and the old-default expression \(z\). Return the clipped row, new default, and the fixed selected representative list. Only present candidate representatives are tested, in pool-code order. The canonical expression trees must retain the same padded lists and tie orders as the physical expressions. Each returned representative in \(O^+\) carries its new value from \(C\) and the matching canonical expression, for the next L-GROUP call.

    Physical routine

    P-INTERMEDIATERANK Rank the row before compression

    \(\Call{P-INTERMEDIATERANK}(\mathcal T,\mathrm{kind},t)\longrightarrow(b)\)

    Return a digit of the magnitude rank \(n_d\) or first-coordinate rank \(k_{\rm row}\), at scale \(H_d\). The numerical list has one slot per pool code plus \(k\) copies of the old default. Nonrepresentatives also supply that default. These added operands are not graph ports.

    Steps and relationships →

    Physical routine

    P-THRESHOLD Compute the two compression thresholds

    \(\Call{P-THRESHOLD}(\mathcal T,\mathrm{kind},t)\longrightarrow(b)\)

    Return a normalized digit of \(u=\max(z,2^{-c_1d},\operatorname{rank}_{n_d}M)\) or \(q=\max(0,\operatorname{rank}_{k_{\rm row}}W^1)\). The first argument wins a numerical tie. Old values are adapted from scale \(H_{2d}\) to \(H_d\).

    Steps and relationships →

    Physical routine

    P-COMPRESS One compressed coordinate as a digit stream

    \(\Call{P-COMPRESS}(\mathcal T,c,\nu,t)\longrightarrow(b)\)

    Return one digit of the compressed coordinate at code \(c\), or the new default when \(c\) is not representative. The center inside the clipping formula is the unclamped \(z'=\max(u,\min(q,3u))\); only the final coordinate and default are clamped to \(R_d\).

    Steps and relationships →

    Physical routine

    P-SELECT Regenerate a retained code one bit at a time

    \(\Call{P-SELECT}(\mathcal T,p,\mathrm{mode},i)\longrightarrow(b)\)

    Return presence of retained ordinal \(p<n_d\), or bit \(i\) of its selected pool code. The selector uses one fixed finite test independent of later value precision. A missing ordinal returns zero. The caller must reserve the entire returned code before asking for any bit.

    Steps and relationships →

    Physical routine

    P-RAWNUM Row before gating presence, default and coordinate queries

    \(\Call{P-RAWNUM}(\mathcal T,p,\mathrm{mode},t)\longrightarrow(b)\)

    Modes are PRESENCE, COORDINATE\((\nu)\) and DEFAULT\((\nu)\). A hole coordinate is zero; DEFAULT is a distinct numerical request. Return one bit or signed digit with no endpoint motion. All zero cells reserved for the selected code count while SELECT is active.

    What to prove

    Open proof obligation · §8.2

    Bound the number of retained entries and the distortion of the later row functions. Prove that the physical tests and streams agree with the logical finite certificates, padded operand lists, and ties. A later digit request must leave the chosen list fixed.
