    Operation · §A.1

    Matrix products and padded ranks

    Manuscript: §A.1, p. 50.

    Logical reference

    • L-MATMUL Multiply explicit rational arrays
    • L-RANK Rank with an explicit padding value

    These operations take complete finite arrays or lists. Their physical clients use the query interfaces in the ingredient sections.

    Logical routine

    L-MATMUL Multiply explicit rational arrays

    \(\Call{L-MATMUL}(A,B)\longrightarrow(Z)\)

    \(A\) is an explicitly stored \(r\times s\) rational array and \(B\) an \(s\times t\) rational array; a vector is a one-column array. The result has \(Z_{ij}=\sum_{k=1}^sA_{ik}B_{kj}\). Empty inner dimension gives the zero array.

    Logical routine

    L-RANK Rank with an explicit padding value

    \(\Call{L-RANK}(v,k,z)\longrightarrow(r)\)

    \(v\) is a finite ordered rational list, \(k\ge1\), and \(z\) is the padding value. Return the \(k\)th largest member of \(v\) with \(k\) additional copies of \(z\). Equal values are ordered by their original list index. Padding is numerical data and never creates a graph port.
