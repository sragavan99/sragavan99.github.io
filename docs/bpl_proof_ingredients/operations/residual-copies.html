    Operation · §5.1

    Divide the remaining large weights

    Manuscript: §5.1, p. 12.

    Logical reference

    • L-SPLIT Weighted node splitting

    When a column's correction is restricted, some residual entries can still be large. Route those entries among copies, and apply the same projection to the reward. The copy sample in L-FAMILY and the copy branch of T-INTRINSIC implement the corresponding queries.

    Logical routine

    L-SPLIT Weighted node splitting

    \(\Call{L-SPLIT}(D,w^+,f,u)\longrightarrow(C^+,w^{++},P)\)

    The input \(u\) is the complete detector array from the pilot. A copied name is \(x\alpha\) with \(0\le\alpha<d_0\). Return complete copied arrays and the projection matrix \(P\); primary copies preserve the old target because their multiplier is one.
