    Operation · §9.4

    Compare names or fingerprints

    Manuscript: §9.4, p. 36.

    This operation has 3 full-space-only components. Switch to Full space to show them.

    Physical queries

    • P-MATCH Compare endpoints under the selected policy
    • P-KEY Short block key at a presented endpoint Full space only
    • P-ENDPOINT-KEY Read or toggle one fingerprint cell Full space only
    • P-MATCH-HASH Compare fingerprints using four restoring visits Full space only

    3 full-space-only components hidden. Switch to Full space to show them.

    The chosen policy gives a comparison predicate for L-GROUP. Exact mode compares name bits. In the full-space mode at tight allowance, a recomputed fingerprint indexes one bit in a shared array. A flip at the first endpoint changes the bit read at the second precisely when the fingerprints agree. The repeated flip and read recover the answer and restore the array.

    Physical routine

    P-MATCH Compare endpoints under the selected policy

    \(\Call{P-MATCH}(\mathcal T,c_1,c_2)\longrightarrow(b)\)

    The complete task and codes describe two repeatable endpoint visits. An absent endpoint never matches. Exact mode returns equality of the padded injective names and restores the cursor. Its live comparison state consists of two relative codes, one \(O(\log B)\) position counter, one pending bit and finite flags. These costs count in D-RESOURCE. The policy is fixed before the call. Full space The full mode uses the exact branch when \(d>2h_*\) and P-MATCH-HASH otherwise. It returns the policy's equality, which need not be endpoint equality.

    Physical routine · Full space only

    P-KEY Short block key at a presented endpoint

    \(\Call{P-KEY}(\rho,v,b)\longrightarrow(k)\)

    Return the block-\(b\) fingerprint bucket in \(\{1,\ldots,B\}\) for the supplied endpoint \(v\). The effective fair bits are those in \(\rho\); a physical caller presents \(v\) through the single cursor. No graph query is made. Unpermitted future block requests return INVALID.

    Steps and relationships →

    Physical routine · Full space only

    P-ENDPOINT-KEY Read or toggle one fingerprint cell

    \(\Call{P-ENDPOINT-KEY}(\mathcal T,a)\longrightarrow(b)\)

    The action is READ-KEY or FLIP-KEY, and the owner, effective seed and block are fixed by the complete task. A counted shared array \(V\in\{0,1\}^{B}\) is available. READ-KEY returns its indexed bit without mutation. FLIP-KEY toggles that bit and returns zero. Neither action changes the cursor or makes an estimator query; its parent owns the obligation to undo a flip.

    Steps and relationships →

    Physical routine · Full space only

    P-MATCH-HASH Compare fingerprints using four restoring visits

    \(\Call{P-MATCH-HASH}(\mathcal T,c_1,c_2)\longrightarrow(b)\)

    The codes have the same owner and effective block key. Endpoint existence, paths and the final comparison answer are independent of the incoming contents of the counted \(B\)-bit catalyst. A visit may fail, but a repeated visit to the same code has the same presence and endpoint. Every nested call restores the catalyst it receives. Return zero if either endpoint is absent; otherwise return equality of the two fingerprints. Restore both cursor and catalyst.
