    Operation · §4.1

    A dense threshold example

    Manuscript: §4.1, p. 10.

    Logical reference

    • L-DENSE Dense hard-threshold example

    A hard threshold illustrates the continuation-preserving update with full arrays. The estimator's reference uses the smooth cutoff in D-CUTOFFS.

    Logical routine

    L-DENSE Dense hard-threshold example

    \(\Call{L-DENSE}(C,w,f,\theta,K)\longrightarrow(D,w^+)\)

    Return one dense hard-threshold correction stage. The parameter \(K\) is supplied, not chosen from an asymptotic slogan. The procedure makes no detector or sampling calls; its role is to explain the value-preserving correction identity.
