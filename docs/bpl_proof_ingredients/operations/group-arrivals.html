    Operation · §8.1

    Group arrivals under the chosen policy

    Manuscript: §8.1, p. 23.

    Logical reference

    • L-GROUP Distribute increments without merging stored values

    Physical queries

    • P-REPRESENTATIVE Choose representatives without losing arrivals
    • P-MERGE Sum all new increments for one representative

    An old representative keeps its own old value. A class with no old representative takes its first valid arrival as representative. Every matching arrival contributes to the sum, even when that record is not the representative. For example, if two distinct new endpoints have equal fingerprints and there is no old representative, exchanging their arrival order can change which endpoint receives the class sum. This explains why the aggregate alone does not determine the row.

    Logical routine

    L-GROUP Distribute increments without merging stored values

    \(\Call{L-GROUP}(O,J,z,d,\eta)\longrightarrow(W)\)

    \(O\) is the ordered old representative list with values; \(J\) is the ordered list of new records \((\mathrm{valid},\mathrm{endpoint},\mathrm{increment})\). \(z\) is the old default. The policy \(\eta\) specifies the endpoint equivalence in D-POLICY. Every record carries its owner, seed and endpoint; comparison labels are constructed here. The result preserves old representatives separately.

    Steps and relationships →

    Physical routine

    P-REPRESENTATIVE Choose representatives without losing arrivals

    \(\Call{P-REPRESENTATIVE}(\mathcal T,c)\longrightarrow(b)\)

    Return whether pool code \(c\) is an old representative or the first valid new record in a equivalence class without an earlier record. Old representatives are kept separately even when the policy identifies their endpoints. This test does not decide whether a new arrival is added numerically.

    Steps and relationships →

    Physical routine

    P-MERGE Sum all new increments for one representative

    \(\Call{P-MERGE}(\mathcal T,c,\nu,t)\longrightarrow(b)\)

    Return a coordinate or size digit of the intermediate row at pool code \(c\), normalized by \(H_d\). A nonrepresentative has old default in coordinate one and zero in coordinate two. A new representative starts at the old default. Only new arrivals are grouped by the selected equivalence.
