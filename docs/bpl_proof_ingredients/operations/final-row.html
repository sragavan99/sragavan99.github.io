    Operation · §6.2

    Assemble final values and ports

    Manuscript: §6.2, p. 14.

    Logical reference

    • L-ASSEMBLE Assemble final tables from completed row before gatings

    Physical queries

    • P-RAWRANK Rank the completed row before gating
    • P-CLASS Fixed structural row classes
    • P-LOCAL Pre-incoming row functions
    • P-CAP Delete an entire overfull incoming column
    • P-INCOMING Incoming score rank without a saved endpoint
    • P-ROW Final numerical row query

    For the computed table, first finish all raw rows of the task. Their local scores define the incoming rank. A correction column that fails the port count loses the entire column of ports. These operations define the input relation for later products. The implementation exposes a row by port and digit queries.

    Logical routine

    L-ASSEMBLE Assemble final tables from completed row before gatings

    \(\Call{L-ASSEMBLE}(\mathcal T,C,z,O,\eta)\longrightarrow(R)\)

    \(C,z,O\) are completed raw arrays, defaults and lists for all rows of one task. Return final values and the fixed outgoing relation. This call performs no further raw-row construction. It may compute the strictly lower-budget detector vectors needed by a correction main.

    Steps and relationships →

    Physical queries

    The class test uses a fixed prefix of the raw value and rank. The incoming rank and its cutoff have separate roles. The rank is recovered by the walks in Section §10. The correction's paired port is used whenever a destination query has to return to its source.

    Physical routine

    P-RAWRANK Rank the completed row before gating

    \(\Call{P-RAWRANK}(\mathcal T,k,t)\longrightarrow(b)\)

    Return a digit of the completed raw first-coordinate rank at final slack 1, using \(k\) additional default operands. The raw port alphabet has fixed size \(2^{c_2}\). Final gates, column caps and detector multipliers are not consulted.

    Physical routine

    P-CLASS Fixed structural row classes

    \(\Call{P-CLASS}(\mathcal T,p,\mathrm{kind})\longrightarrow(b)\)

    Return the fixed structural membership bit for class \(A\) or \(A_I\). Choose the constant place \(P_*\) once with \(6H_1 2^{-P_*}\le\delta_0/10000\). Approximate raw value and rank by their complete signed prefixes at that place, rescaled by \(H_1\). Equality at a threshold rejects.

    Steps and relationships →

    Physical routine

    P-LOCAL Pre-incoming row functions

    \(\Call{P-LOCAL}(\mathcal T,p,\mathrm{kind},t)\longrightarrow(b)\)

    Return a digit of the specified local pre-incoming quantity: witness \(I\), preparation, pilot score, or main prevalue. The first three have scale one; main prevalue has scale \(H_*\). The denominator uses this owner's completed second coordinate before gating, not a fresh preparation call.

    Steps and relationships →

    Physical routine

    P-CAP Delete an entire overfull incoming column

    \(\Call{P-CAP}(\mathcal T,p,\mathrm{direction})\longrightarrow(b,r)\)

    Forward maps a present source port to its destination and actual incoming rank; inverse maps that destination/rank back to the source and port. Delete an entire column when its number of precursor initials exceeds \(k_c\). Count present zero-valued ports. Failure restores the starting cursor.

    Steps and relationships →

    Physical routine

    P-INCOMING Incoming score rank without a saved endpoint

    \(\Call{P-INCOMING}(\mathcal T,\mathrm{kind},t)\longrightarrow(b)\)

    Kinds are DETECTOR-RANK, I-RANK and GATE. Rank kinds return the corresponding incoming rank digit. GATE returns a digit of \(1-\chi_{1/4,1/2}(r)\) for the incoming-\(I\) rank \(r\). The rank scan and local gate arithmetic now have separate interfaces.

    Steps and relationships →

    Physical routine

    P-ROW Final numerical row query

    \(\Call{P-ROW}(\mathcal T,p,t)\longrightarrow(b)\)

    Return one digit of the final row value at public scale \(H_*\). Dense bins/scores have only their local factor. Correction preparations multiply by their incoming gate, and correction mains additionally multiply by the detector cutoff. Missing capped ports return zero.

    What to prove

    Open proof obligation · §6.2

    Show that the fixed classes cover the gated support, that the cap deletes only zero gated values, and that each query agrees with the corresponding finite test or value. Check that successful pairs are inverse and that failure and cleanup restore all required state.
