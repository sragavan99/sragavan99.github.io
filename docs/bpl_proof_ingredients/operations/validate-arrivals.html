    Operation · §3.3

    Validate a sampled arrival

    Manuscript: §3.3, p. 9.

    Physical queries

    • P-VALID Validate original hits and all deferred wraps

    First establish that the candidate endpoint exists. Then test the required hits and wraps at the original source and destination. The P-ENDPOINT hit and wrap modes perform the local tests during the visits from Section §9.

    Physical routine

    P-VALID Validate original hits and all deferred wraps

    \(\Call{P-VALID}(\mathcal T,c)\longrightarrow(b)\)

    Return the conjunction of syntax, intrinsic presence, original-owner source hit and all word-wrap tests. Destination tests use the descriptor's final endpoint; a signal uses the original narrow rate \(\tau\), while first-coordinate families use broad rate \(a\). Output precision is not an argument.
