    Operation · §11.2

    Stream digits through bounded requests

    Manuscript: §11.2, p. 42.

    Physical queries

    • P-AFFINE Finite-prefix affine arithmetic requests
    • P-MULTIPLY Product-band arithmetic requests
    • P-RECIPROCAL Early-prefix reciprocal requests
    • P-RANK Finite-prefix order-statistic requests
    • P-NODESTEP Advance one primitive numerical node
    • P-NUMSTEP Advance a numerical expression without calling its operands

    The arithmetic stepper either returns a bounded result or names the next operand digit it needs. The caller owns the resume state and handles the operand request. The primitive code and the client therefore have separate storage obligations.

    Physical routine

    P-AFFINE Finite-prefix affine arithmetic requests

    \(\Call{P-AFFINE}(F,t,\kappa,s,a)\longrightarrow(s^+,o)\)

    This coroutine implements a declared finite affine sum or continuous piecewise-affine formula \(F\) on normalized digit operands. A comparison request has a finite prefix length in \(F\) and returns its sign; a certificate request returns \(N_t(F)\bmod2^\kappa\). \(\kappa\) is a fixed program tag. It emits operand requests but calls no operand.

    Physical routine

    P-MULTIPLY Product-band arithmetic requests

    \(\Call{P-MULTIPLY}(F,t,\kappa,s,a)\longrightarrow(s^+,o)\)

    \(F\) names two normalized operands \(x,y\). Return a certificate residue for \(xy\) through the exact band recurrence in D-NUMRECIPES. The state carries the band continuation, finite loop position, residues and at most one pending digit. Operand requests are returned to the client, not executed here.

    Physical routine

    P-RECIPROCAL Early-prefix reciprocal requests

    \(\Call{P-RECIPROCAL}(F,t,\kappa,s,a)\longrightarrow(s^+,o)\)

    \(F\) names \(x\in[a,b]\subset(0,1]\). Return a certificate residue for \(1/(Cx)\), where the fixed power of two \(C\ge\max(1,2/a,4/a^2)\) is part of the expression. The originating \(t\) is captured for the entire call. The outer client later undoes \(C\) only with a justified scale adapter.

    Physical routine

    P-RANK Finite-prefix order-statistic requests

    \(\Call{P-RANK}(F,t,\kappa,s,a)\longrightarrow(s^+,o)\)

    \(F\) gives list length \(Q\le2^{Cd}\), rank \(k\), and explicit numerical padding/default operands. Return a certificate residue for its largest-first rank. Invalid ranks return the declared default before requesting an operand. A hole contributes its specified default, never an endpoint.

    Physical routine

    P-NODESTEP Advance one primitive numerical node

    \(\Call{P-NODESTEP}(F,t,\kappa,s,a)\longrightarrow(s^+,o)\)

    \(F\) is one normalized primitive node with its direct operands treated as named leaves. Return its complete primitive state and REQUEST or DONE result. This finite arithmetic dispatch does not evaluate a child expression or invoke an external leaf.

    Steps and relationships →

    Physical routine

    P-NUMSTEP Advance a numerical expression without calling its operands

    \(\Call{P-NUMSTEP}(E,t,\mathrm{mode},s,a)\longrightarrow(s^+,o)\)

    \(E\) is one of the fixed expressions in D-RECIPES with named operand leaves; mode is DIGIT or CERT\((\kappa)\). START has \(s=\varnothing,a=\bot\); a resumed request receives its single bounded answer \(a\). Return a complete new state and either REQUEST\((\mathrm{leaf},j)\) or DONE\((b)\). DIGIT returns a signed digit; CERT returns a residue. These are different result types.

    What to prove

    Open proof obligation · §11.2

    Prove agreement with the finite equations for every primitive and client, including ties and scale shifts. Instantiate the resume transitions, then count the fields across each operand call. For a reciprocal, keep the originating place available while erasing the long early word before a late operand request.
