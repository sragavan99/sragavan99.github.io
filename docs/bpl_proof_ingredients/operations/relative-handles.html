    Operation · §9.1

    Reconstruct a task from relative fields

    Manuscript: §9.1, p. 30.

    Physical queries

    • P-REPLAY Regenerate parameters in shared scratch

    A physical caller retains a short description of the child request and uses shared scratch to reconstruct its parameters. The starting point is the immutable root data. Each completed link specifies the seed transformation and task update needed for the next link.

    Physical routine

    P-REPLAY Regenerate parameters in shared scratch

    \(\Call{P-REPLAY}(\mathcal T,\mathrm{field},q)\longrightarrow(r)\)

    \(\mathcal T\) is a completed relative handle into the marked root-to-owner record chain, or its frozen bounded-edit view. Return the requested pure field, validity flag, child schema, coefficient bit, or expression tag. Full tuples exist only in the shared reconstruction buffer. Replay has no estimator, presence or terminal callback.
