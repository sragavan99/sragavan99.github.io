    Operation · §7.1

    Form one sample term

    Manuscript: §7.1, p. 18.

    Logical reference

    • L-FAMILY The finite sample expressions

    Physical queries

    • P-CHILD Construct a child task with explicit field resets
    • P-INTRINSICVALUE Answer one digit of a sample expression

    For one lower budget, the family specification gives direct, product, subtraction, copy, signal, detector, and reward contributions. The child constructor fixes the task fields and coefficients. A product uses two children under the same transformed seed, as in Section §1.1.

    Logical routine

    L-FAMILY The finite sample expressions

    \(\Call{L-FAMILY}(\mathcal T,\tau,r,\eta)\longrightarrow(F)\)

    \(\tau\) selects Base, direct, product, subtraction, copy, signal, detector, direct reward or product reward. Return the complete sample array and its ordered contributing records at child budget \(r\). The seed is already the common transformed seed for this sample. The family is zero when \(r\le0\), except the separately inserted Base term.

    Steps and relationships →

    Physical queries

    The child constructor has a materialized view for the logical algorithm and a relative view for the physical caller. The numerical query asks only for the operand digit it needs. Its right-factor excursion keeps the left edge's inverse token until the digit request returns.

    Physical routine

    P-CHILD Construct a child task with explicit field resets

    \(\Call{P-CHILD}(\mathcal T,\tau,r,\mathrm{side})\longrightarrow(Q)\)

    This pure constructor returns child task fields and exact scalar coefficients, never an estimator value. The complete output cases are in D-CHILD. A physical caller requests one field or one relative schema at a time; a logical caller may request the full fixed list. Invalid owner/tag/side or negative-stage requests return INVALID before any cursor change.

    Steps and relationships →

    Physical routine

    P-INTRINSICVALUE Answer one digit of a sample expression

    \(\Call{P-INTRINSICVALUE}(\mathcal T,c,\nu,t)\longrightarrow(b)\)

    Return one normalized digit of the complete descriptor contribution, with the coefficient and leaf expression specified in D-INTRINSIC. Wrong coordinates return the zero stream without changing presence. This interface assumes the caller has validated the outer descriptor; its own lower leaf accesses still validate their public ports.

    What to prove

    Open proof obligation · §7.1

    Check each family's term and coefficient against D-ROWFAMILIES or D-VECTORS. Prove the conditional mean and the error transfer from child values. The product bound uses pointwise support counts and the common right tuple.
