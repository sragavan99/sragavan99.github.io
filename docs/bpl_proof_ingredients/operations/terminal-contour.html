    Operation · §10.1

    Traverse a terminal computation graph

    Manuscript: §10.1, p. 38.

    Physical queries

    • T-SCORE Precursor and quantized-score terminal programs
    • P-PROBE Successor and predecessor access to a terminal program
    • P-TOUR Reversible contour around one success halt

    Regard an admitted terminal program state as a vertex of a finite graph. A probe tests or crosses a local incidence. A contour of the component of a success halt enumerates its marked initial states and returns to the halt. This implements incoming access without retaining the full source name.

    Terminal program

    T-SCORE Precursor and quantized-score terminal programs

    \(\Call{T-SCORE}(\mathcal T,p,\mathrm{mode},\tau)\longrightarrow(b,\tau^+)\)

    The graph kind is precursor, incoming-\(I\) score, or detector score. A score graph at precision \(t\) has sinks \(J(y,Q)\) for every \(0\le Q\le2^t\), including unrealized scores. The payload is owned by the graph exactly once. The score quantization is the clipped floor of the local signed prefix through \(t+8\).

    Physical routine

    P-PROBE Successor and predecessor access to a terminal program

    \(\Call{P-PROBE}(G,i,\mathrm{mode})\longrightarrow(b,e)\)

    \(G\) is one frozen raw graph view; \(i\) is a finite ordered incidence/certificate token. Modes TEST and CROSS inspect or cross one edge. TEST restores cursor and graph even after a paired candidate is rejected. CROSS repeats the validated transition and commits only its bounded edit after lower work is erased. This interface is conditional on the missing five STEP catalogues.

    Physical routine

    P-TOUR Reversible contour around one success halt

    \(\Call{P-TOUR}(G,\mathrm{direction})\longrightarrow(\mathrm{mark})\)

    \(G\) is the current graph/incidence state in the component of one specified success halt, with a sentinel at that halt. Return at the next canonical initial or sentinel in the requested contour direction. The graph state and cursor move together; no initial endpoint copy is retained.

    What to prove

    Open proof obligation · §10.1

    Show that the admitted incidence rules are consistent, that the contour directions are inverse, and that it visits precisely the required initials. Count the shared graph state and each probe's additional live fields.
