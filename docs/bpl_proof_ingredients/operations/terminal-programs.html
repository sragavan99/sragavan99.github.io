    Operation · §9.2

    Expose a port and own its return path

    Manuscript: §9.2, p. 30.

    Physical queries

    • P-INTRINSICVALID Check a candidate before outer wrap tests
    • T-INTRINSIC Terminal schedules for primitive paths
    • T-DESCRIPTOR Terminal program for a validated descriptor
    • T-RAW Terminal program for a raw-row port
    • T-FINAL Final table presence and terminal access

    The logical operation maps a present port to an endpoint. Its physical realization can leave the cursor at that endpoint and return a trace. The trace owns any retained child path. Returning consumes the trace and restores the source. Discarding consumes it at the endpoint. This distinction lets the reversible walk see the terminal program's own states.

    Physical routine

    P-INTRINSICVALID Check a candidate before outer wrap tests

    \(\Call{P-INTRINSICVALID}(\mathcal T,c)\longrightarrow(b)\)

    Return whether the descriptor has an intrinsic port, before its outer hit/wrap checks. The cursor and shared mutable registers restore on both answers. Scalar detector and direct-reward records are present after their local checks even when their numerical value is zero.

    Steps and relationships →

    Terminal program

    T-INTRINSIC Terminal schedules for primitive paths

    \(\Call{T-INTRINSIC}(\mathcal T,c,\mathrm{mode},\tau)\longrightarrow(b,\tau^+)\)

    Return or consume the intrinsic terminal trace of one descriptor. The trace records the family case, known copy symbols, and actual tokens, never the old source address. Scalar families reject endpoint modes. Product success owns one left token and one right trace.

    Steps and relationships →

    Terminal program

    T-DESCRIPTOR Terminal program for a validated descriptor

    \(\Call{T-DESCRIPTOR}(\mathcal T,c,\mathrm{mode},\tau)\longrightarrow(b,\tau^+)\)

    This terminal adds original-owner validity to intrinsic motion. It returns the same endpoint as the intrinsic descriptor, even for numerical value zero. RETURN and DISCARD use the recorded intrinsic trace; they do not rerun a destination-dependent validity test at the wrong cursor.

    Steps and relationships →

    Terminal program

    T-RAW Terminal program for a raw-row port

    \(\Call{T-RAW}(\mathcal T,p,\mathrm{mode},\tau)\longrightarrow(b,\tau^+)\)

    Public modes are PRESENCE, RETAIN, RETURN and DISCARD. RETAIN moves to a raw port endpoint and returns its owned trace; RETURN consumes that trace and restores; DISCARD consumes it at the endpoint. Failure restores with no trace. STEP is a separate proposed graph-transition mode whose missing label/slot catalogue is U-CATALOG.

    Steps and relationships →

    Terminal program

    T-FINAL Final table presence and terminal access

    \(\Call{T-FINAL}(\mathcal T,p,\mathrm{mode},\tau)\longrightarrow(b,\tau^+)\)

    Public terminal access to a final row. Dense rows use raw traces; corrections use the whole-column cap's actual paired token. No numerical row value is evaluated here. A vector or invalid port request fails before motion.

    What to prove

    Open proof obligation · §9.2

    Give the finite transition and field catalogue for the terminal programs. Check all presence, motion, return, discard, and failure cases, including synthetic states admitted to a probe.
