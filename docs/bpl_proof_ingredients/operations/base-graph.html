    Operation · §2.2

    Paired base graph and continuation values

    Manuscript: §2.2, p. 5.

    Logical reference

    • L-BACKWARD Exact continuation values

    Physical queries

    • P-SETUP Validate and choose finite root ranges
    • P-BASE Local access to the paired base graph

    The logical reference stores the base matrix \(S\) and reward \(e\). The physical graph represents an edge by a port, a bounded index among edges leaving or entering the current vertex. A forward or inverse operation returns the opposite port. The extra chain vertices in the base graph make both port sets bounded.

    Logical routine

    L-BACKWARD Exact continuation values

    \(\Call{L-BACKWARD}(S,e)\longrightarrow(p)\)

    An explicitly stored rational strictly forward matrix \(S\) and terminal indicator \(e\) determine one rational vector \(p\). The result is the complete continuation vector, not an entry oracle. Repeated labelled edges have already been added to the corresponding matrix entry.

    Physical routine

    P-SETUP Validate and choose finite root ranges

    \(\Call{P-SETUP}(x,\eta)\longrightarrow(\rho,\mathrm{ok})\)

    Return \(\rho=(x,n,n_0,z_0,L,N,r,B,M,p,k_{\max},\eta,q,\text{constant tags})\) as immutable root data, or \((\bot,0)\). The input \(x\) remains read-only, represented by access to its actual tape, not copied into \(\rho\). All variable integer fields have \(O(B)\) bits.

    Steps and relationships →

    Physical routine

    P-BASE Local access to the paired base graph

    \(\Call{P-BASE}(x,\mathrm{mode},p)\longrightarrow(r)\)

    The current cursor is an original vertex or a merging-chain name \((y,i)\). Modes are size, start, reward, weight, presence, forward and inverse. The last two return a success bit and the actual opposite port, and move the cursor only on success. Pure modes do not move it. Parallel labels remain distinct.

    What to prove

    Open proof obligation · §2.2

    Verify the probability-preserving base conversion, the name convention, and both directions of the port pairing. Check the setup ranges and halting behavior on malformed and zero-layer inputs.
