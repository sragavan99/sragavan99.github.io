    Operation · §9.3

    Visit an endpoint and perform one action

    Manuscript: §9.3, p. 34.

    Physical queries

    • P-ENDPOINT Read a name bit or test endpoint membership
    • P-VISITPOOL Visit one old or new representative and return
    • P-VISITINTRINSIC Visit an intrinsic candidate for its deferred tests
    • P-VISITRAW Visit a final raw-row port and return

    A restoring visit exposes a port, performs a bounded action at its endpoint, and returns. The endpoint action supplies the name bits and hit or wrap tests used by the other ingredients. In full space it can also access one shared fingerprint cell.

    Physical routine

    P-ENDPOINT Read a name bit or test endpoint membership

    \(\Call{P-ENDPOINT}(\mathcal T,a)\longrightarrow(b)\)

    READ-ID\((i)\) returns bit \(i\) of the padded current name (zero outside its public range). HIT\((c,r,s)\) tests channel \(c\) at rate \(r\) after appending suffix \(s\). WRAP\((i)\) tests the specified word variant at this endpoint. The result is bounded, the cursor is unchanged, and pure scratch is erased. These actions make no estimator query. Unknown or malformed actions return zero. Full space READ-KEY and FLIP-KEY delegate to P-ENDPOINT-KEY. Only FLIP-KEY intentionally changes one shared mutable registers cell.

    Physical routine

    P-VISITPOOL Visit one old or new representative and return

    \(\Call{P-VISITPOOL}(\mathcal T,c,\alpha)\longrightarrow(b,v)\)

    \(c\) is an old/new pool code at slack \(d\). Return presence \(b\) and the bounded action answer \(v\); on absence return \((0,0)\). Success visits its endpoint, executes only the declared endpoint action, and returns to the original cursor. The terminal trace is consumed on every branch.

    Steps and relationships →

    Physical routine

    P-VISITINTRINSIC Visit an intrinsic candidate for its deferred tests

    \(\Call{P-VISITINTRINSIC}(\mathcal T,c,\alpha)\longrightarrow(b,v)\)

    Visit the intrinsic endpoint of a descriptor before its outer owner wrap tests. Return presence and the action bit, restoring the cursor. This is needed because destination wrap validity can be tested only after the destination is known.

    Steps and relationships →

    Physical routine

    P-VISITRAW Visit a final raw-row port and return

    \(\Call{P-VISITRAW}(\mathcal T,p,\alpha)\longrightarrow(b,v)\)

    Visit a port of the current raw prefix, execute the bounded action, and return. This interface never silently changes slack to \(2d\). Missing ports return \((0,0)\) with no action and no motion.

    What to prove

    Open proof obligation · §9.3

    Prove that the actions are repeatable at the selected endpoint and that their paths and cleanup meet the restoration contract.
