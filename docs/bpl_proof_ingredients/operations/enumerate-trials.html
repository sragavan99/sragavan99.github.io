    Operation · §12.1

    Evaluate one trial for each admitted seed

    Manuscript: §12.1, p. 46.

    Physical queries

    • P-SEEDS Enumerate exactly the root conditional law
    • P-TRIAL Evaluate one seed on a fixed grid

    The finishing law conditions only on the hit at the primary start. Each admitted seed produces one grid numerator by streaming the final reward and clipping the result. The full-space seed enumeration retains the multiplicity of original fair-bit strings.

    Physical routine

    P-SEEDS Enumerate exactly the root conditional law

    \(\Call{P-SEEDS}(\rho,c)\longrightarrow(\sigma,c^+,b)\)

    \(c\) is the next fixed-length encoding index, initially zero. Return the next admitted seed \(\sigma\), its successor index \(c^+\), and \(b=1\); return \((\bot,\mathrm{end},0)\) when exhausted. Only channel 0 is conditioned at \(z_L\). The exact configuration has no auxiliary bits. Every valid encoding is emitted once; any auxiliary bit-string multiplicity is preserved.

    Physical routine

    P-TRIAL Evaluate one seed on a fixed grid

    \(\Call{P-TRIAL}(\rho,\sigma)\longrightarrow(a)\)

    Return the clipped numerator of the first ten signed digits of the same root reward estimator, using channel 0, suffix empty, source rate \(f_L\), stage \(L\) and budget \(M\). The seed and task do not change between digit requests.
