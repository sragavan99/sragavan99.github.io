    Operation · §7.3

    Accumulate detector and reward vectors

    Manuscript: §7.3, p. 22.

    Physical queries

    • P-SCALARPREFIX Scalar prefixes for vector tasks
    • P-VECTOR Final reward or detector vector query

    A vector task has one scalar per source. It adds each group of scalar increments to the preceding prefix and clamps the result before processing the next group. Detector rank is formed before averaging. The final vector query is the scalar branch of L-ESTIMATE.

    Physical routine

    P-SCALARPREFIX Scalar prefixes for vector tasks

    \(\Call{P-SCALARPREFIX}(\mathcal T,d,t)\longrightarrow(b)\)

    Return a digit of the vector's clipped scalar prefix at slack \(d\), normalized by \(H_d\). The vector uses every scalar arrival and no endpoint grouping. At the top the old prefix is zero; active \(W_0\) is the exact base reward.

    Physical routine

    P-VECTOR Final reward or detector vector query

    \(\Call{P-VECTOR}(\mathcal T,t)\longrightarrow(b)\)

    Return one digit of a reward or detector vector in \([0,1]\), with no port or motion mode. The effective task and seed fix one real value for all digit places. Inactive/source-failed inputs return the canonical zero stream.
