    Operation · §4.2

    Detect crowded correction columns

    Manuscript: §4.2, p. 10.

    Logical reference

    • L-PILOT Sampled detector and frozen multiplier

    The pilot asks which columns would acquire too many substantial incoming entries during correction. It returns a fixed multiplier for each column. These multipliers allow the next routine to restart with a single frozen choice.

    Logical routine

    L-PILOT Sampled detector and frozen multiplier

    \(\Call{L-PILOT}(C,f,\Omega,K)\longrightarrow(g,u)\)

    \(\Omega\) explicitly lists the independent channel seeds, their hit bits at every vertex, and their uniform multiplicities. This call returns all exact detector values and the final column multiplier. Every expectation below is computed by summing over the indicated nonempty sublist, including duplicate encodings.
