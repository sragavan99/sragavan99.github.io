    Operation · §11.1

    Define the finite arithmetic result

    Manuscript: §11.1, p. 41.

    Logical reference

    • L-CERT Evaluate a canonical certificate in the reference computation

    The logical computation fixes an integer certificate at each place. The chosen finite rules determine the later tests, so the two evaluators must agree on the certificate itself. The reference below evaluates the equations in D-NUMRECIPES with explicit storage.

    Logical routine

    L-CERT Evaluate a canonical certificate in the reference computation

    \(\Call{L-CERT}(E,t)\longrightarrow(N)\)

    \(E\) is a finite canonical expression tree with the normalized leaf streams and scales in D-RECIPES. Return the integer \(N_t(E)\) defined by D-NUMRECIPES and the specified score quantization for an incoming rank. The primitive formulas determine the rounding and ties.
