    Ingredient · §4

    Selective shortcutting

    Manuscript: §4, from p. 10.

    The big picture

    Map ingredient 1 · toy API

    Estimate column crowding; shortcut selectively to reduce edge weights.

    Input
    A forward transition graph with some large edge weights.
    Output
    Smaller residual weights at eligible destinations, preserving acceptance values after updating accumulated acceptance contributions.
    Upstream purpose
    Reduce transition weights where the correction can have controlled incoming degree.
    Approach
    Trial runs estimate column crowding and decide where to shortcut. Toy a weight-1/2 edge through a vertex with no immediate acceptance contribution and two weight-1/2 outgoing edges becomes two weight-1/4 shortcuts.

    Improves

    Large edge weights

    Introduces or worsens

    High-indegree vertices; Dense rows; Missing reverse access

    Used by tasks

    Task 1: Approximating matrix powers with a sequence of corrector matrices; Task 3: Compute an O(16ⁱ)-sparse Eᵢ in low space

    In the physical algorithm

    This ingredient has no physical routines of its own. Its corrections and copies enter the physical algorithm through the task families: the pilot and actual corrections and the residual copies in D-ROWFAMILIES and D-CHILD, whose fields P-CHILD returns and whose sample terms P-INTRINSICVALUE evaluates.

    §4.2 Detect crowded correction columns

    The pilot asks which columns would acquire too many substantial incoming entries during correction. It returns a fixed multiplier for each column. These multipliers allow the next routine to restart with a single frozen choice.

    Logical reference

    • L-PILOT Sampled detector and frozen multiplier

    What to prove

    Show that each enabled column has a bounded number of substantial candidates at its scale, and that the columns requiring copies can be counted from the total incidence bound.

    §4.3 Compute the exact correction

    At a fixed stage the correction uses the product of its preceding iterate and the transition matrix. The cutoff leaves a positive residual at corrected positions. This bounds the number of positions that can contribute to a path in the iteration argument. The exact correction is the reference for the common sampled estimator.

    Logical reference

    • L-CORRECT Correction with a frozen column multiplier

    What to prove

    Show that the fixed number of sweeps is sufficient, that the residual is nonnegative and substochastic, and that fully enabled columns meet the new entry bound.
