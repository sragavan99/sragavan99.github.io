    Ingredient · §10

    Reversible walks

    Manuscript: §10, from p. 38.

    The big picture

    Map ingredient 8 · toy API

    Enumerate predecessors and restore positions without saving vertex addresses.

    Input
    A halting forward neighbour-finding procedure, with a bounded number of incoming moves per destination.
    Output
    Incoming enumeration and forward/backward moves paired by small return tokens.
    Upstream purpose
    Visit destinations, inspect incoming contributions, and return without saving source addresses.
    Approach
    Construct local predecessor checks and traverse the procedure's computation graph reversibly. Toy if two source moves reach the same destination, one bit identifies which incoming move to undo.

    Improves

    Missing reverse access; Space footprint of addresses and walk descriptions

    Introduces or worsens

    None recorded.

    §10.1 Traverse a terminal computation graph

    Regard an admitted terminal program state as a vertex of a finite graph. A probe tests or crosses a local incidence. A contour of the component of a success halt enumerates its marked initial states and returns to the halt. This implements incoming access without retaining the full source name.

    Physical queries

    • T-SCORE Precursor and quantized-score terminal programs
    • P-PROBE Successor and predecessor access to a terminal program
    • P-TOUR Reversible contour around one success halt

    What to prove

    Show that the admitted incidence rules are consistent, that the contour directions are inverse, and that it visits precisely the required initials. Count the shared graph state and each probe's additional live fields.

    §10.2 Recover the padded incoming score rank

    An explicit reference enumerates the completed score column, quantizes the scores at the certificate place, and takes its padded rank. The physical version counts matching initials by traversing the score graph for each descending payload. The rank modes of P-INCOMING expose its digits, and its gate mode applies the cutoff after the rank has been defined.

    Physical queries

    • P-INCOMINGRANK Recover an incoming rank from score contours

    What to prove

    Match the quantized ranks and zero padding to the finite reference. The graph owns the score payload and the scan must restore the same destination and payload before it advances.
