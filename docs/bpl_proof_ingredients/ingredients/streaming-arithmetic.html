    Ingredient · §11

    Streaming arithmetic

    Manuscript: §11, from p. 41.

    The big picture

    Map ingredient 9 · toy API

    Compute digits without retaining full intermediate numerical values.

    Input
    Arithmetic expressions whose operands supply digits on demand, with known numerical bounds and divisors bounded away from zero.
    Output
    Result digits to the requested accuracy, with controlled memory retained across operand calls.
    Upstream purpose
    Evaluate averages, gates, and normalization without stacking full numerical intermediates.
    Approach
    Toy average two recursively computed numbers to 100-bit accuracy using signed digits, bounded carries, and recomputation. Account for retained data using the change in requested precision between caller and operand.

    §11.2 Stream digits through bounded requests

    The arithmetic stepper either returns a bounded result or names the next operand digit it needs. The caller owns the resume state and handles the operand request. The primitive code and the client therefore have separate storage obligations.

    Physical queries

    • P-AFFINE Finite-prefix affine arithmetic requests
    • P-MULTIPLY Product-band arithmetic requests
    • P-RECIPROCAL Early-prefix reciprocal requests
    • P-RANK Finite-prefix order-statistic requests
    • P-NODESTEP Advance one primitive numerical node
    • P-NUMSTEP Advance a numerical expression without calling its operands

    What to prove

    Prove agreement with the finite equations for every primitive and client, including ties and scale shifts. Instantiate the resume transitions, then count the fields across each operand call. For a reciprocal, keep the originating place available while erasing the long early word before a late operand request.
