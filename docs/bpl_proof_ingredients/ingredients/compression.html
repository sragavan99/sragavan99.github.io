    Ingredient · §8

    Compressing intermediate averages

    Manuscript: §8, from p. 23.

    The big picture

    Map ingredient 6 · toy API

    Represent intermediate averages using a default and bounded exceptions.

    Input
    A potentially dense intermediate vector, a storage budget, and queries that keep large entries only when the row is uncrowded.
    Output
    A shared default plus a bounded exception list, with controlled change in those downstream queries.
    Upstream purpose
    Averages and differences of sparse rows can involve many distinct destinations.
    Approach
    Use rank-based thresholds and smooth clamping. Toy (0.9, 0.2, 0.1, 0.08) becomes (0.9, 0.2, 0.2, 0.2), encoded by default 0.2 and one exception. Both vectors give the same answer to: "report entries above 0.8, provided the second-largest entry is below 0.25."

    The space bound counts address/value records. Each record needs address and precision bits, and the exception budget varies within the recursion. The guarantee concerns the specified downstream queries; arbitrary row sums and individual small entries can change.

    §8.1 Group arrivals under the chosen policy

    An old representative keeps its own old value. A class with no old representative takes its first valid arrival as representative. Every matching arrival contributes to the sum, even when that record is not the representative. For example, if two distinct new endpoints have equal fingerprints and there is no old representative, exchanging their arrival order can change which endpoint receives the class sum. This explains why the aggregate alone does not determine the row.

    Logical reference

    • L-GROUP Distribute increments without merging stored values

    Physical queries

    • P-REPRESENTATIVE Choose representatives without losing arrivals
    • P-MERGE Sum all new increments for one representative

    What to prove

    Prove that the physical scan selects the same representatives and adds the same signed operands in the fixed order, for the selected policy.

    §8.2 Choose a default and retain exceptions

    Use the grouped row to compute the two thresholds and the new common default. The compression formula clips each coordinate toward the default. A fixed finite test decides which representatives to retain. The ordered list, default, and coordinate expressions are used by the next prefix or by final assembly.

    Logical reference

    • L-COMPRESS Compress one completed increment group

    Physical queries

    • P-INTERMEDIATERANK Rank the row before compression
    • P-THRESHOLD Compute the two compression thresholds
    • P-COMPRESS One compressed coordinate as a digit stream
    • P-SELECT Regenerate a retained code one bit at a time
    • P-RAWNUM Row before gating presence, default and coordinate queries

    What to prove

    Bound the number of retained entries and the distortion of the later row functions. Prove that the physical tests and streams agree with the logical finite certificates, padded operand lists, and ties. A later digit request must leave the chosen list fixed.

    §8.3 Use an exact reference within a fingerprint block

    For the full-space policy, analyze the change in grouping by an explicit calculation with exact name comparison in the current block. The computations below that block keep their specified comparison policy. This is a reference calculation for the accuracy proof.

    Logical reference

    • L-BLOCK Reference calculation for one hash block Full space only

    1 full-space-only component hidden. Switch to Full space to show it.

    What to prove

    Prove current-key independence of the reference candidates and bound escaped candidates and propagated child errors. The fixed-pair collision estimate is used only with the stated conditioning.
