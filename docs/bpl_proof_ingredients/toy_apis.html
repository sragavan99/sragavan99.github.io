BPL proof ingredients
MapToy APIs

Toy APIs for each ingredient

These toy contracts isolate what each ingredient accomplishes. Output states the objective; Approach gives the mechanism and a small example. The examples use exact probabilities and simplified thresholds. The full construction adds the error, access, and space guarantees described elsewhere in this map and in the source notes.

1

Selective shortcutting

Estimate column crowding; shortcut selectively to reduce edge weights.

Input
A forward transition graph with some large edge weights.
Output
Smaller residual weights at eligible destinations, preserving acceptance values after updating accumulated acceptance contributions.
Upstream purpose
Reduce transition weights where the correction can have controlled incoming degree.
Approach
Trial runs estimate column crowding and decide where to shortcut. Toy a weight-1/2 edge through a vertex with no immediate acceptance contribution and two weight-1/2 outgoing edges becomes two weight-1/4 shortcuts.

Node splitting

Divide transition weights among new nodes with controlled growth.

Input
A graph whose remaining heavy edges enter a small set of flagged vertices.
Output
An equivalent graph with smaller individual weights and controlled node growth.
Upstream purpose
Handle heavy edges at destinations where shortcutting was suppressed.
Approach
Duplicate a vertex's future behaviour and divide incoming weights among its copies. Toy four copies turn an incoming weight of 0.8 into four weights of 0.2.

3

Vertex sampling and conditional mixing

Sample vertices; mix seeds while preserving required inclusions.

Input
A vertex set and a desired sampling rate.
Output
A seeded sampler and a rapidly mixing seed walk with constantly many choices per step. A fixed seed and rate give repeatable membership decisions without storing the sampled set.
Upstream purpose
Average sampled computations using short walk descriptions. The full construction also needs this mixing while designated end points remain sampled; the toy setting omits that conditioning.
Approach
Use a seed-homomorphic hash with a rapidly mixing walk on the seed space. Here, seed-homomorphic means that simple seed updates implement corresponding transformations of all hash outputs. Affine hashing supplies those transformations; relative property (T) establishes a spectral gap uniform in the seed-space size and sampling rate. Toy sampling 16 neighbours at rate 1/16 gives one neighbour in expectation, and walking between seeds varies that sample. Ingredient 5 decides how much averaging to perform.

4

Controlling WORST-case degree

Suppress crowded rows and columns; compensate for lost contributions.

Input
A sampled graph, a degree cap, and exact conditional retention probabilities bounded away from zero.
Output
Bounded row and column degrees on every seed, with the intended conditional entry means.
Upstream purpose
Guarantee bounded access and prevent one correlated error from being reused too often.
Approach
Suppress crowded rows and columns, then compensate using each contribution's own retention probability. Toy a contribution of 0.6 surviving with probability 3/4 becomes 0.8 when retained and zero otherwise; its mean remains 0.6.

5

Recursion-friendly sampling

Average successive accuracy improvements with decreasing averaging overhead.

Input
Successively more accurate recursive estimates, with shrinking errors, and the seed mixing operation supplied by ingredient 3.
Output
An accurate average for most seeds, with averaging overhead controlled across recursion.
Upstream purpose
Improve accuracy without paying for a large averaging description at every recursive level.
Approach
Write the fine estimate as coarse + (medium - coarse) + (fine - medium). Average the coarse term heavily and the smaller refinements less. Evaluate both terms of each difference on the same seed. Pay for its averaging description using the decrease in recursion budget; no independence between the terms is assumed.

6

Compressing intermediate averages

Represent intermediate averages using a default and bounded exceptions.

Input
A potentially dense intermediate vector, a storage budget, and queries that keep large entries only when the row is uncrowded.
Output
A shared default plus a bounded exception list, with controlled change in those downstream queries.
Upstream purpose
Averages and differences of sparse rows can involve many distinct destinations.
Approach
Use rank-based thresholds and smooth clamping. Toy (0.9, 0.2, 0.1, 0.08) becomes (0.9, 0.2, 0.2, 0.2), encoded by default 0.2 and one exception. Both vectors give the same answer to: "report entries above 0.8, provided the second-largest entry is below 0.25."

The space bound counts address/value records. Each record needs address and precision bits, and the exception budget varies within the recursion. The guarantee concerns the specified downstream queries; arbitrary row sums and individual small entries can change.

Pointer scheme for sparse rows

Navigate using one current vertex and short relative paths.

Input
Nested sparse-row queries, with operations to follow a selected neighbour and return.
Output
Access using one current vertex and short relative paths.
Upstream purpose
Avoid retaining a full vertex address in every suspended recursive call.
Approach
Store local neighbour choices and reconstruct locations when needed. Toy describing 20 binary forward choices takes 20 bits, while one current vertex address is shared across the queries. Ingredient 8 supplies the return operation; return tokens and other call metadata still need separate space accounting.

8

Reversible walks

Enumerate predecessors and restore positions without saving vertex addresses.

Input
A halting forward neighbour-finding procedure, with a bounded number of incoming moves per destination.
Output
Incoming enumeration and forward/backward moves paired by small return tokens.
Upstream purpose
Visit destinations, inspect incoming contributions, and return without saving source addresses.
Approach
Construct local predecessor checks and traverse the procedure's computation graph reversibly. Toy if two source moves reach the same destination, one bit identifies which incoming move to undo.

9

Streaming arithmetic

Compute digits without retaining full intermediate numerical values.

Input
Arithmetic expressions whose operands supply digits on demand, with known numerical bounds and divisors bounded away from zero.
Output
Result digits to the requested accuracy, with controlled memory retained across operand calls.
Upstream purpose
Evaluate averages, gates, and normalization without stacking full numerical intermediates.
Approach
Toy average two recursively computed numbers to 100-bit accuracy using signed digits, bounded carries, and recomputation. Account for retained data using the change in requested precision between caller and operand.

Median of multiple trials

Enumerate seeds; select a median without storing the estimates.

Input
An enumerable family of finite-precision estimates, with a strict majority within the desired error.
Output
A deterministic estimate with that error guarantee.
Upstream purpose
Remove dependence on selecting a good seed.
Approach
Recompute trials while counting values below candidate thresholds. Toy the estimates 0, 0.49, 0.50, 0.51, 1 have median 0.50; repeated scans find it without storing the list.
