    §2.1 Input and output

    The full-space and exact-name configurations use the same input and output convention. The workspace bound differs.

    Definitions

    • D-INPUT Explicit binary branching programs
    • D-TARGET The estimator output and counted memory
    • D-RELAXED-TARGET The same estimator with additional workspace

    §2.2 Paired base graph and continuation values

    The logical reference stores the base matrix \(S\) and reward \(e\). The physical graph represents an edge by a port, a bounded index among edges leaving or entering the current vertex. A forward or inverse operation returns the opposite port. The extra chain vertices in the base graph make both port sets bounded.

    Logical reference

    • L-BACKWARD Exact continuation values

    Physical queries

    • P-SETUP Validate and choose finite root ranges
    • P-BASE Local access to the paired base graph

    What to prove

    Verify the probability-preserving base conversion, the name convention, and both directions of the port pairing. Check the setup ranges and halting behavior on malformed and zero-layer inputs.
